CastLink Server 1.0.11

В режиме «Окно» главная картинка у кастера запрашивает верхний видеослой, в том числе без полноэкранного режима. Миниатюры получают слой по размеру, а OBS/vMix сохраняют собственную подписку.

В диагностике связи появился вывод о месте сбоя с участником и временем. Для получения обновления в CastLink Updater выберите установленный сервер Windows/WSL, проверьте обновления и примените версию 1.0.11. На Linux используйте штатное серверное обновление. Запланируйте применение между эфирами.
