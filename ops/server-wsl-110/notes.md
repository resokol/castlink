CastLink Server 1.0.10. В карточке каждого кастера виден битрейт видео и аудио, получаемый выходом OBS/vMix. Если открыто несколько выходов, отображается диапазон. При отсутствии свежего замера отображается прочерк. Обновление включает адаптивное превью студии и запрос камеры до 1080p60. Для обновления сервера Windows откройте CastLink Updater, выберите установленный WSL-сервер и нажмите «Проверить».
