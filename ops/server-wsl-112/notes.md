## Windows / WSL 1.0.12

В панели Windows-сервера нажмите **Обслуживание**. Откроется CastLink Updater с выбранным WSL-сервером. При первом запуске кнопка проверяет встроенный апдейтер и регистрирует его для текущего пользователя. Кнопка работает и во время фонового опроса статистики.

Открытие окна и проверка версии сохраняют работающий эфир. Для установки нажмите **Обновить…** и подтвердите действие вне эфира.

Обновление доступно через CastLink Updater со всех ранее выпущенных Windows/WSL-версий, включая публичные RC и 1.0.11.
