# Презентации временно недоступны

Управление презентациями временно отключено. Открытие локального PDF в CastLink, передача переключения страниц, подключение PowerPoint и загрузка помощников недоступны. Прежние инструкции по запуску помощников не применяются; поддержка PowerPoint не заявляется.

Для показа документа или окна программы можно использовать обычную **«Демонстрацию экрана»** с выбором источника в браузере. Это не включает удалённое управление слайдами.
