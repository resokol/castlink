# PDF, PPTX и управление презентацией

Текущие пакеты — **1.0.0-rc.8** (`92085508d54c`): [Windows Client, Server Setup и Linux](PRODUCTS.md). Для серверных функций обновляйте сервер, для встроенного интерфейса и родных панелей Windows — Client. Версии направлений независимы; прежние выпуски перечислены в [CHANGELOG](CHANGELOG.md).

## Подготовить и показать

1. Откройте панель презентации и нажмите **«Выбрать PDF / PPTX»**. Лимит каждого PDF/PPTX — **1 500 000 000 байт**.
2. PDF открывается в браузере. PPTX отправляется на ваш сервер и преобразуется в PDF изолированным конвертером; установленный PowerPoint для этого не требуется. Дождитесь предпросмотра.
3. Проверьте число страниц, шрифты и оформление, затем нажмите **«Показать презентацию»**. Документ передаётся отдельным видеопотоком без звука.
4. Используйте **«Назад»** и **«Вперёд»**. Кнопка **«Управление»** открывает меню передачи управления участнику. Владелец сохраняет возможность листать после передачи; только он передаёт, возвращает управление и останавливает показ. Одновременная устаревшая команда получает конфликт (409): проверьте текущую страницу и повторите действие явно. Это управление страницами, без доступа к мыши или клавиатуре компьютера.
5. Для завершения нажмите **«Остановить презентацию»** / **«ОСТАНОВИТЬ ПРЕЗЕНТАЦИЮ»**. Закрытие меню или панели не завершает активный показ. Если остановка не удалась, ошибка остаётся видна, действие можно повторить.

## Панель управления

Панель можно перемещать за заголовок. В поддерживаемых Chrome/Edge кнопка **«Поверх других окон»** открывает отдельное окно Document Picture-in-Picture после вашего действия; при отказе или отсутствии API управление остаётся на странице. В Windows-клиенте используется доступная родная панель. STOP остаётся доступным при открытом меню слайдов.

## Совместимость и ограничения

Для лимита 1 500 000 000 байт обновите сервер и конвертер одним актуальным серверным пакетом: конвертер использует лимит памяти 2 ГиБ и отдельный рабочий диск с не менее 8 ГБ свободного места. Лимит размера не гарантирует обработку любого документа; проверьте страницы, шрифты и задержку на своём оборудовании.

- PDF/PPTX показываются как статические страницы. Анимация, видео, музыка и интерактивные элементы PPTX в этом режиме не воспроизводятся.
- Поддерживаются обычные PPTX со стандартными SVG, диаграммами, встроенными данными диаграмм и ссылками. Полное совпадение с PowerPoint для каждого документа не гарантируется.
- Отсутствие исходных шрифтов может изменить переносы и оформление. Для точного вида экспортируйте PDF на исходном компьютере; встраивайте шрифты только при разрешающей лицензии.
- Зашифрованные документы и документы с паролем не принимаются. Сохраните незапароленную копию или экспортируйте PDF.
- Ошибки повреждённого файла, пароля, занятости и недоступности конвертера различаются. При занятости повторите позже; при недоступности обратитесь к владельцу сервера. PDF не требует конвертера.

Для живого PowerPoint с анимацией или видео запустите показ в PowerPoint и отдельно используйте **«Демонстрацию экрана»**, выбрав его окно и при необходимости звук в окне выбора источника. Подключение управления открытым PowerPoint — отдельный Windows-сценарий с установленным PowerPoint; его поведение зависит от рабочей среды и не заменяет проверку перед эфиром.
