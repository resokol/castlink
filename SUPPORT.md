## 20.10.2026 · 1.0.0-rc.8 · bdfe91a92b6b

- Обновлены оформление Windows-мастера сервера и многошаговый установщик Windows Client с выбором папки. Вариант установки сервера подписан «На Linux Ubuntu»; быстрый режим включён по умолчанию, расширенная настройка выбирается явно.
- На сайте загрузки идут в порядке Windows Client, Windows Server, Linux Ubuntu. В блоке Ubuntu выделен мануал с установкой из коробки и расширенным режимом; ссылка истории называется «Что нового в последних релизах».
- Исправлена синхронизация имени кастера при повторном подключении и продлении сессии. Видео кастера вписывается в доступную область с сохранением пропорций.
- Windows Client, Windows Server Setup и Linux выпускаются отдельными направлениями с собственными версиями и файлами.

Перед обновлением собственного сервера сделайте резервную копию и завершите подключения. Windows Client обновляется вручную: полностью закройте старый клиент и установите новый EXE. Автообновления EXE нет; EXE не подписаны. Страницы обновляйте вручную вне эфира. Физические PowerPoint, устройства и полный эфир отдельно не проверены.

## 20.10.2026 · 1472cd052d7e · Исправления кастера и окон управления

- Нативные окна Windows следуют выбранной теме CastLink; выбор источника экрана оформлен для светлой и тёмной тем.
- Галерея кастера использует доступную ширину, чат стал на 15% уже, кнопки центрированы. В режиме «только студия» сохраняется локальный предпросмотр камеры. Полноэкранная плитка скрывает элементы управления при бездействии.
- Персонал может удалить самостоятельный инвайт, пока он не привязан к слоту; связанные постоянные выходы сохраняются.
- Для отсутствующего профиля микрофона используется оригинальный звук без шумоподавления и эхоподавления. Явно сохранённый речевой профиль сохраняется.
- Crop мультивью маскирует края без сдвига, изменения масштаба и пропорций исходника.
- В браузерной плавающей панели появилась кнопка «Компактный размер». Нажмите её, если браузер восстановил увеличенное окно; общий размер учитывает независимую кнопку STOP. Браузер по-прежнему может выбирать начальный размер самостоятельно.

Обновите сервер и Windows-клиент. Полностью закройте старый клиент и запустите новый EXE; самообновления EXE нет. Страницы обновляйте вручную вне эфира. Перед обновлением своего сервера сделайте резервную копию и завершите подключения. EXE без цифровой подписи. Физические PowerPoint, устройства и полный эфир отдельно не проверены.

# Поддержать CastLink

CastLink можно использовать бесплатно. Если проект помогает вам проводить эфиры, вы можете поддержать его развитие любой удобной суммой. Спасибо за помощь с новыми возможностями и исправлениями!

При сообщении о проблеме укажите выпуск `1.0.0-rc.3-1472cd052d7e`, Windows-клиент или браузер, формат и размер файла, текст ошибки и шаги повторения. Для PDF/PPTX см. [инструкцию презентаций](PRESENTATIONS.md), для изменений — [CHANGELOG](CHANGELOG.md). Не публикуйте секреты сервера и личные документы.
