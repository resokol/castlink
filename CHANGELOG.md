# История изменений CastLink

Примечания относятся к готовым пакетам указанных выпусков. Новые функции появляются здесь после публикации сборки.

## 22.10.2026 · Server Setup / Linux · 1.0.0-rc.8-72b315b2d251

Исправлены карточка гостя и битрейт передачи в комнату, экспозиция/контраст, прозрачность выхода и SVG-смайлики. Обновляется самостоятельно установленный сервер; Windows Client остаётся на прежнем выпуске. Обновляйте в перерыв эфира.

## 21.10.2026 · Client / Server Setup / Linux · 1.0.0-rc.8-90135013f5b6

- Портретная мобильная «Плитка» показывает два столбца 16:9; длинный список прокручивается, видео остаётся смонтированным.
- «Показать презентацию» сразу открывает компактное управление. Доступная родная Windows-панель приоритетна; неподдерживаемый или отклонённый browser popout оставляет управление на странице. Закрытие не останавливает медиа.
- Добавлены 24 смайлика и семь временных реакций. Реакции видны в комнате две секунды, учитывают reduced motion, не добавляются в чат и чистые выходы; история и экспорт смайликов сохраняют Unicode.
- Студийные блоки, пять гостевых карточек в широком окне и четыре настройки 2×2 размещены компактнее; соседние кнопки и селекты согласованы по размеру.
- Повторное открытие того же приглашения сохраняет назначенный слот при действующем сохранённом подписанном разрешении. Вторая вкладка не стирает сессию первой; scope, generation и SID проверяются.
- Сервер и клиент выпускаются отдельно; обновляйте вне эфира через проверенный пакет и суммы выбранного направления. Установщик Client доступен через F10 → «Проверить обновления…» либо вручную; версии без этой команды обновляются вручную. EXE не подписаны.
- Реальные SFU, физические устройства, установленный Windows GUI и exclusive fullscreen PowerPoint для этих изменений не проверены. И прочие мелкие изменения.

## 21.10.2026 · Client / Server Setup / Linux · 1.0.0-rc.8-cb8a387b959f

- Исправлены чёрные camera/screen выходы назначенных слотов: выход теперь получает разрешённую подписку. Проверки подписанной ссылки, назначения и права только на чтение сохранены.
- Новая студия использует H.264 / 10 000 кбит/с / 60 FPS; кастер без сохранённого выбора — H.264. Добавлен VP9 при поддержке браузера; сохранённые настройки и гостевые битрейт/FPS не повышаются.
- Режимы названы «Окно» и «Плитка». На компьютере вертикальный разделитель работает и с основной камерой; прокрутка гостей, пропорции и мобильная раскладка сохранены.
- Уменьшены поля изображения и убран дублирующий поворот; карточки следуют за приглашениями, устройства студии сворачиваются. Диагностика устройств обновляется при позднем входе, reconnect и смене устройств.
- Владелец комнаты может адресно отключить её администратора/модератора; повторный вход возможен. Другие комнаты и основная студия защищены.
- Уточнены надписи управления и оранжевые акценты. Прямое управление открытым PowerPoint убрано из меню; загрузка PDF/PPTX и демонстрация экрана сохранены.
- Обновите сервер и Client. Для новой надписи родной Windows-панели нужен новый EXE: F10 → «Проверить обновления» или ручная установка. EXE не подписаны; обновляйте вне эфира, нужные данные сохраняйте самостоятельно.
- Физические устройства, PowerPoint, vMix и полный эфир отдельно не проверены. И прочие мелкие изменения.

## 21.10.2026 · 1.0.0-rc.8 · 92085508d54c

Обновите нужные направления из [PRODUCTS](PRODUCTS.md); для больших презентаций нужен полный серверный пакет с новым конвертером. EXE не подписаны. ## [Быстрая/расширенная установка и самостоятельный Linux helper](https://github.com/resokol/castlink-releases/releases/tag/easy-setup-31a402442fe1) · 2026-10-20

### Добавлено и изменено

- Windows Easy Setup предлагает «Быстрая» и «Расширенная». Доступны прямой HTTPS, HTTP и внешний HTTPS-прокси, отдельные адреса/порты сайта и медиа, явный список доверенных прокси. Мастер и управление поддерживают RU/EN/简体中文.
- Новый самостоятельный Linux helper: `init`, `validate`, `start`, `status`, `backup`, `update`. Состояние, секреты, UUID, сеть и имена томов хранятся в постоянном `--state-dir`.
- Исправлена упаковка Linux-скриптов при сборке пакетов на Windows: исполняемые программы сохраняют Unix-переводы строк.

### Действия при обновлении и ограничения

Сохраните данные и конфигурацию, обновляйтесь вне эфира: службы и медиа прерываются. Windows-мастер обновляет выбранную прежнюю установку; Linux helper использует прежний `--state-dir` и создаёт согласованную копию перед переключением. Он не подхватывает Windows/legacy-установки. Автоматического отката БД нет.

Для стандартной медиасхемы оставьте TCP 7881, UDP 7882, UDP 3478 и UDP 30000–30031; для расширенной — выбранные порты. HTTP по LAN/публичному IP не даёт безопасного контекста камеры/микрофона/экрана. Внешний прокси требует отдельной проверки HTTPS и медиасвязи. TURN/TLS остаётся процедурой прямого публичного HTTPS на 80/443 с отдельным TURN-доменом. Подробнее: [INSTALL](INSTALL.md), [Linux](LINUX_INSTALL.md), [TURN/TLS](TURN_TLS.md).
