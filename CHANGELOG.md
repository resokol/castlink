## [Unreleased]

### Кандидат: управление ПК через Windows-клиент

- Обычная демонстрация использует один выбор экрана или окна с доступным звуком. Браузерный показ сохраняет штатный сценарий.
- Встроенное управление текущим показом: передача участнику, запрос с разрешением/отклонением, отзыв и завершение с сохранением видео и звука. Получатель может использовать клиент или браузер.
- Ввод приостанавливается при потере фокуса или недействительной геометрии; возобновление требует клика по видео. Добавлено поле подтверждённого Unicode/IME-текста.
- Требуются обновлённый сервер и Windows-клиент управляемого ПК. Кандидат проходит приёмку упакованной версии; публикация ещё не выполнена. [Инструкция](docs/REMOTE_PC_CONTROL_RU.md).

### Кандидат 1.0.0-rc.8 — PR67

- Имя кастера при явном повторном входе берётся из нового ввода; переименование студией отображается у самого кастера. Фоновое продление токена сохраняет актуальное имя участника.
- Убрана длинная подпись под видео в гостевом интерфейсе; чат уменьшен ещё на 15%, освободившееся место используется видеозоной.
- Client, Server Setup и самостоятельный Linux имеют отдельные версии, ветки выпуска и ссылки. Текущий кандидат — `1.0.0-rc.8`; старт с 1.1 отложен. Публикуется только обновлённое направление.
- Обычная установка использует готовые параметры, технические вопросы вынесены в расширенный режим; Windows-клиент устанавливается для текущего пользователя одним действием. И прочие мелкие изменения.
- После выпуска серверного исправления загрузите страницы вне эфира; установка нового Windows-клиента нужна для изменений его установщика. Исходники PR сами не обновляют серверы, EXE и публичные пакеты. Совместимость произвольных сочетаний версий не заявляется.

### Интерфейс кастера, клиент и мультивью

- Windows-панели следуют теме CastLink; окно выбора экрана оформлено в общем стиле, переключатель называется «Передавать звук». Существующее ограничение звука приложением PowerPoint сохраняется.
- Расширена рабочая область кастера, чат уменьшен на15%, кнопки центрированы. Равные16:9 плитки вписываются по измеренной видеозоне; свой предпросмотр скрывается/показывается и при просмотре только студии, без изменения передачи камеры.
- В fullscreen плитки интерфейс скрывается через3секунды бездействия и возвращается при движении мыши или работе с клавиатурой.
- В браузерной плавающей панели добавлено восстановление компактного размера реальным кликом и запрос исходной геометрии вместо запомненного размера. STOP и слайды сохраняют независимый lifecycle; браузер может ограничивать автоматическое изменение размеров.
- Добавлено удаление инвайтов без слота с серверной проверкой прав и защитой от одновременной привязки. Прежняя ссылка перестаёт действовать.
- Без заданной настройки микрофона используется оригинальный звук без шумоподавления; явный выбор студии сохраняется.
- Кадрирование мультивью обрезает края без сдвига/масштабирования исходника.
- Для применения нужны обновление веб-сервера и новая Windows-сборка. Исходники сами не обновляют работающие установки; страницы загружать вне эфира.

## [1.0.0-rc.3-1de5b686d719] - 2026-10-20

### Понятный вход студии и кастера

- Обычный запуск Windows-клиента и сайта сначала предлагает «Я — студия» / «Я — кастер / гость». Формы и обслуживание сервера разделены; гостевые приглашения сразу ведут к подключению.
- Проверка перед входом объединяет имя, локальный предпросмотр и устройства. Передача начинается только после явного подключения; прежние серверные настройки и переносы сохраняются.
- Windows-клиент регистрирует `castlink:`. Приглашение может открыть приложение; браузерный вариант остаётся доступен, включая отсутствие установленного клиента или отказ запуска.
- Согласованный минималистичный графитовый дизайн с мятными действиями и светлым вариантом закреплён как основной эталон дальнейших интерфейсов.
- Требуется обновление веб-сервера и новая сборка Windows-клиента. Само изменение исходников не обновляет работающие установки. Существующий старый клиент не получает обработчик ссылок автоматически; после обновления страницы входа открывать вне эфира.


### Панели сайта и PR60

- Панели слайдов владельца и получателя перемещаются за заголовок. «Поверх других окон» использует Document Picture-in-Picture в поддерживаемых Chrome/Edge; при отказе управление остаётся внутри страницы. STOP и слайды совместно используют окно, скрытие не останавливает медиа.
- PR60: персонал задаёт размеры/FPS камеры в карточке гостя. Серверные настройки имеют приоритет; быстрые720/1080/default1080 сохранены. Выключенная камера, mic и screen не включаются и не меняются такой настройкой.
- Физическое fullscreen/focus поведение PowerPoint отдельно не проверено. Windows native панели требуют нового EXE; self-update клиента не включён.

### Камера и браузерный выход vMix

- Студия, администратор и модератор выбирают целевое разрешение камеры кастера720/1080; настройка применяется во время передачи и восстанавливается при переподключении. У кастера собственного выбора разрешения нет. Без заданного значения запрашивается1080 вместо прежнего скрытого720.
- Индивидуальные браузерные выходы сохраняют максимальное доступное качество источника и учитывают зум, сдвиг, поворот, кадрирование и отражение камеры. Экран остаётся отдельным источником.
- После установки web-исправления загрузите обновлённые страницы студии, кастера и входов vMix вне эфира. Новый Windows-клиент для этого исправления не нужен. Запрошенное разрешение зависит от возможностей камеры и браузера; измеренные размеры потока показываются отдельно.

- Установка: быстрый режим с готовыми настройками и расширенный режим с выбором HTTP/HTTPS/внешнего прокси, адресов и портов сайта, медиа и TURN.
- Сеть: явные доверенные прокси, исходные IP/протокол/host, сохранение медиадопуска и сетевых настроек при обновлении.
- Linux: самостоятельная установка из официального Compose-пакета, проверка файлов, резервная копия перед обновлением, стабильные секреты и тома.
- Переводы новых шагов и инструкции: русский, английский, упрощённый китайский. Возможности требуют нового полного пакета; работающие установки автоматически не меняются.

## [1.0.0-rc.3] - 2026-10-18

Сборка **776AF9**.

### Добавлено и исправлено

- Постоянные слоты участников сохраняют URL выхода камеры со звуком и демонстрации экрана при замене или повторном назначении кастера. Назначение слота не прерывает подключение.
- Кастеры входят в комнату напрямую. Выдача ссылок администратора и модератора доступна в прежнем интерфейсе студии без отдельного входа владельца сервера.
- Выбранные камера и микрофон автоматически включаются уже на экране проверки устройств до входа в комнату; отказ одного разрешения сохраняет работу другого устройства.
- В редакторе Мультивью можно включить вспомогательную сетку и выбрать размер ячеек от крупного до мелкого.
- И прочие мелкие изменения.

### Обновление

Сохраните резервную копию данных. Обновляйте существующую установку через новый мастер в перерыв эфира: полное обновление установщиком пересоздаёт медиасервисы и прерывает текущие соединения. После обновления проверьте собственные устройства, индивидуальные выходы, `/watch` и резерв. Постоянные URL слотов сохраняются. Ручные Linux-инструкции остаются закреплены на ранее проверенном пакете до отдельной проверки новых контрольных сумм.

### Добавлено и изменено

- В мультивью добавлен формат сцены 4:3 (1440×1080) и независимый выбор пропорций каждого слота: по источнику, 16:9 или 4:3. Выбранный формат сохраняется в сцене и при её экспорте.

- В студии появился экспериментальный редактор «Мультивью»: сетки и свободная раскладка, перемещение и изменение размеров слотов, привязка к направляющим, отдельное кадрирование, скругление углов и общая заглушка при отсутствии видео. Сцены можно копировать, удалять, экспортировать и импортировать. После импорта источники назначаются заново. Для вывода в Browser Source OBS/vMix предусмотрена отдельная ссылка с прозрачным фоном; изменения сцены публикуются кнопкой «Применить».
- В разделе «Кастомизировать комнату» можно задать параметры новых приглашений: вход с выключенным микрофоном, только звук без включения камеры при входе, запрет взаимного прослушивания кастеров. Сохранение настроек не меняет уже выданные ссылки и подключённые сессии; выдайте новые приглашения.
- Кадрирование кастера в студии меняется сразу и сохраняется автоматически: зум, сдвиг, поворот, отражение и кроп доступны ползунками и точным числовым вводом. Компактные элементы управления находятся рядом с видео. Преобразования применяются при отображении в студии и индивидуальном видеовыходе; исходный поток кастера не перекодируется. У слотов мультивью собственные настройки.
- Для Studio Return доступен чёрный фон вместо камеры. Отключение звука выхода действует также на `/watch` и демонстрацию экрана; аудиометр показывает сигнал с учётом этого отключения. Личный мониторинг остаётся отдельным.
- Перенос комнаты, аварийный резерв и серверы комнаты объединены в пункте бокового меню «Резервные сервера».
- И прочие мелкие изменения.

### Исправлено

- Переключение из студии в «Мультивью», статистику, участников или резервные серверы больше не останавливает демонстрацию экрана и её звук.

- Исправлено подключение новых кастеров после переноса комнаты между серверами.
- Свободные слоты мультивью сохраняют пропорции источника при изменении размера. Видео и заглушки обрезаются по границам сцены; скруглённые углы одинаково выглядят в редакторе и на выходе.
- В Easy Setup сокращено число публикуемых Docker UDP-портов. Прежние широкие диапазоны могли запускать тысячи процессов перенаправления Docker, исчерпывать память сервера и приводить к недоступности сайта с ошибкой 502.

### Обновление существующего сервера

1. До обновления разрешите **UDP 7882** в сетевом экране провайдера, системном firewall и, если сервер находится за роутером, настройте проброс этого порта. Сохраните **TCP 80/443/7881**, **UDP 3478** и разрешите **UDP 30000–30031**. SSH-порт должен оставаться доступным. Необязательный TURN/TLS использует **TCP 443** и отдельный TURN-домен.
2. Сохраните резервную копию данных и конфигурации. Полностью распакуйте новый Windows-пакет и запустите `EasySetup.exe`, выберите **«Обновить»** и существующую установку: прежнюю локальную папку или тот же VPS. Ручная Linux-инструкция пока закреплена на прежнем выпуске `easy-setup-8b02e2d4dc3c`: не заменяйте в ней тег и суммы на `latest`. Для перехода VPS на новую схему Easy Setup используйте новый Windows-мастер по SSH.
3. Выполняйте обновление в перерыв эфира: установщик пересоздаёт контейнер LiveKit для применения медиапортов, поэтому текущие медиасоединения прервутся. Обновление существующей установки сохраняет её данные; удалять установку и тома не требуется.
4. После обновления проверьте сайт, новое подключение кастера, звук и видео, индивидуальный выход, `/watch` и используемый резерв из ваших сетей. Откройте обновлённый интерфейс в браузере.

Новая схема Easy Setup: прямое медиа — **UDP 7882 / TCP 7881**; TURN — **UDP 3478** и relay **UDP 30000–30031**. Она заменяет прежние диапазоны **UDP 61000–61100** и relay **UDP 30000–30999**. Разрешения внешних сетевых экранов и проброс роутера устанавливаются отдельно от Docker; одного скачивания нового ZIP недостаточно.

Кнопка **«Обновить» в панели резервного сервера внутри студии обновляет только web-приложение**. Она не пересоздаёт LiveKit и не переводит существующую установку на новые медиапорты. Для этого перехода используйте обновление через новый установщик. Собственные конфигурации сверяйте с их фактическими настройками.

### Ограничения мультивью

Мультивью остаётся экспериментальной функцией: до 16 сцен и 32 слотов, без гарантии производительности для любого устройства. Начните с сетки 2×2. Сцены хранятся на текущем сервере и автоматически не переносятся на резерв; экспорт/импорт переносит композицию, а источники назначаются заново. Ссылку выхода передавайте только доверенным получателям эфира: она даёт доступ к медиа комнаты. Для звука браузеру может потребоваться нажатие пользователя. Перед настоящим эфиром проверьте собственные камеры, сеть и принимающее ПО.

## [1.0.0-rc.1] - 2026-09-30

Release candidate для финальной проверки CastLink 1.0.

### Основные изменения
- multi-tenant модель Account → Organization → Studio → Room;
- node scheduler и signed heartbeat;
- удалённые media nodes без прямого доступа к central PostgreSQL;
- tenant-aware server transfer/failover с переносом Studio assignment;
- PostgreSQL room storage, migration/import и backup/restore;
- TURN/TLS path через HAProxy/LiveKit;
- production install/update/rollback foundation;
- observability, health, diagnostics и structured logging;
- безопасное разбиение критического Studio monolith перед RC.

### Статус RC
- кодовый CI зелёный на `1.0-integration`;
- production/VPS ещё не переведён на этот RC;
- обязательны реальные acceptance-проверки перед `1.0.0`: production deploy/rollback, browser/device flows, TURN relay, VPS↔Home failover и PostgreSQL restore;
- soak/stress (#5) выполняется последним.

### Release foundation
- Добавлена единая схема product version + build id.
- Подготовлен CI для TypeScript, стабильных тестов и production build.
- Добавлена release policy для ветки CastLink 1.0.
