# Выпуски CastLink

- Основной репозиторий `resokol/studiolink` хранит исходники, актуальные сборки, контрольные суммы и инструкции. Доступ определяется текущими настройками GitHub. Изменение видимости само по себе не меняет [LICENSE](../LICENSE).
- Публичный `resokol/castlink-releases` — зеркало проверенных и одобренных владельцем пакетов и пользовательских инструкций. Наличие новой сборки в основном репозитории не означает разрешение публиковать её в зеркале.
- Направления `client`, `server-setup`, `linux` независимы. Версии и назначенные ветки задаёт `release-tracks.json`; `main` — интеграционная ветка. Перед сборкой сверяют фактическую ветку и source SHA. Название в конфигурации не доказывает, что ветка содержит нужный код.
- Выпуск обозначается точным тегом `<track>-v<version>-<12-char-sha>`. Общий `releases/latest` не определяет все три продукта. [Каталог продуктов](PRODUCTS.md) хранит отдельные ссылки, build/source ID и SHA256SUMS.
- Перенос существующего выпуска сохраняет точные байты всех assets, имена, теги и контрольные суммы. Он не является пересборкой, новой проверкой бинарного пакета или обновлением установленного сервера. Исходные build/source ID внутри старых архивов не переписываются; соответствие текущей истории указывается отдельно.
- Сначала подготавливают проверяемый draft и полный набор assets: пакет, manifest, SHA256SUMS и обязательные материалы сторонних компонентов. Только после сверки состава и SHA256 выпуск становится доступным. Источники copyleft-компонентов и уведомления распространяются вместе с соответствующим выпуском.
- Клиент собирается через `windows-desktop-client.yml`, Server Setup/Linux — через выбранное направление `easy-setup-packages.yml`. Фактический репозиторий публикации определяет конфигурация инструмента: существующие publisher/workflow настройки публичного зеркала не становятся приватным каналом от одной правки документации. Проверяйте назначение перед запуском и не публикуйте новый пакет в зеркале без отдельного одобрения.
- Server Setup содержит собственный `CastLink-Linux.tar.gz` как транспортную зависимость для установки на VPS. Нельзя заменять его архивом независимого Linux-выпуска без проверки соответствующего Server Setup пакета.
- Пользовательские примечания описывают добавления, изменения, исправления и действия при обновлении. Непроверенные функции не объявляют готовыми; приватные журналы разработки не копируют в release notes.
- Инструкции синхронизируются на русском, английском и упрощённом китайском: RU — `distribution/`, EN — `distribution/docs/en/`, 简体中文 — `distribution/docs/zh-CN/`. В статьях сохраняются ссылки выбора языка. Команды, суммы и реквизиты не переводят. Лицензии и оригинальные уведомления не заменяют переводами.
- Опубликованные архивы не заменяют ради уточнения документации. Фиксированные теги сохраняют ссылки скачивания и исходную provenance. Ветки с уникальными коммитами не удаляют как часть выпуска.
