# Диагностика основной студии

[English](docs/en/STUDIO_DIAGNOSTICS.md) · [简体中文](docs/zh-CN/STUDIO_DIAGNOSTICS.md)

В сборках с этим исправлением шкалы громкости обновляются в своих компонентах. Обновление шкал больше не обновляет список участников на каждом кадре.

После обновления сервера заново откройте основную студию в браузере или Windows Client. Во вкладке **Статистика** раскройте **Диагностика основной студии**. Последние полученные данные обновляются вместе со статистикой примерно каждые15секунд; сервер получает замеры примерно каждые2секунды. При отсутствии свежих замеров отображается предупреждение.

Доступны состояние видимости вкладки, задержка её основного потока и максимум с начала сессии, счётчики ошибок JavaScript и rejected promises, доступные браузеру память JavaScript и длительные задачи. Недоступное API означает отсутствие значения, а не нулевую нагрузку. Фоновое ограничение таймеров не считается зависанием видимого интерфейса. Память JavaScript — не вся память вкладки и не GPU.

**Диагностика студии → JSON** скачивает историю с выбранными периодом/днём/участником/сессией. Для основной студии выберите роль «Студия». Лимит выгрузки —50000замеров или20МиБ; неполный файл отмечается как partial. Просмотр доступен владельцу студии/администратору комнаты, платформенная история — действующему super-admin.

**Журнал этой вкладки → JSON** работает независимо от сервера статистики. Вкладка хранит ограниченный снимок текущей и предыдущей сессии в sessionStorage, обычно раз в10секунд и при изменении видимости/завершении. После перезагрузки страницы предыдущая запись сохраняется в той же вкладке, если браузер разрешает хранилище. Закрытие вкладки может удалить журнал. Нужна исходная вкладка и тот же origin. Хранилище недоступно — сбор/экспорт текущих доступных данных продолжает работать в памяти.

Сервер сохраняет диагностику в существующие hourly JSONL-файлы: `${STUDIOLINK_STATS_DIR}` либо `${STUDIOLINK_DATA_DIR}/stats/<room-hash>/<hour>.jsonl`; старые часы сжимаются в `.jsonl.gz`. Умолчания:30дней и общий лимит512МиБ. Лимит диска может сократить период. Существующие безопасные ошибки браузера отмечаются `browser.crash` в журнале web-службы (`docker logs` или штатный журнал установки). Не публикуйте весь серверный журнал без проверки его содержимого.

Новые runtime-поля не содержат запись медиа, пароли, токены, полные URL, имена устройств или произвольный текст ошибок. Выгрузка серверной статистики содержит существующие имена/идентификаторы участников; передавайте её только тем, кто разбирает инцидент.

Полный сбой renderer/GPU или завершение процесса может не оставить последней записи. Пропуски замеров и последние показатели помогают сузить причину, но не доказывают её. После сбоя скачайте серверный JSON за время инцидента и локальный журнал той же вкладки, укажите время и вид экрана.

Timeweb обновляется отдельно от самостоятельных серверов. Установка новых Windows/Linux серверных пакетов нужна для других установок; обновление одного Client EXE не обновляет их серверный код. Клиент, открывающий уже обновлённый сервер, получает новую веб-студию после перезагрузки.
