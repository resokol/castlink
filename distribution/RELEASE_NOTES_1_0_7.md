# CastLink 1.0.7 — стабильная версия сервера и web

Стабильный выпуск сервера и web на основе принятой версии castlink.ru. Точные пакеты, версии и контрольные суммы перечислены в [каталоге](PRODUCTS.md). Старые архивы и теги не изменяются.

## Что входит

- **Диагностика видео:** в статистике студии «Диагностика видео → JSON» сохраняет историю отправки и приёма, доступные FPS, битрейты, потери, счётчики кадров и зависаний. Сохраняются выбранные период, участники и сессии; неполная выгрузка отмечается как `partial`.
- **Диагностика звука:** история различает mute публикации, SDK-трека, MediaStreamTrack и плеера. Доступны фактические параметры захвата/обработки, подстановка тишины и коррекция темпа декодером. Старые записи и недоступные браузеру поля остаются неизвестными; диагностика не исправляет искажения автоматически.
- **Сеть за последние 10 секунд:** текущая оценка и потери разделены по аудио/видео и направлениям кастер → сервер и сервер → студия. История сохраняется; поддерживаются кастеры без камеры.
- **Поток студии в vMix:** устранена ошибка `AbortSignal.any is not a function` в затронутых встроенных браузерах, включая конфигурацию vMix 28. После обновления сервера обновите браузерный источник vMix. Исправление не означает отдельной проверки реального эфира в vMix.
- **Windows Server на WSL2:** установка без Docker Desktop, родная панель Windows для запуска/остановки, открытия сервера, статистики и экспорта за 24 часа. Средства обслуживания позволяют выбрать установку, проверить обновление, удалить с архивом, восстановить архив и завершить прерванную операцию. Сервер работает внутри WSL2; это не Windows-служба.

Подробности диагностики: [инструкция](STUDIO_DIAGNOSTICS.md). Требования, сеть и обслуживание: [Windows/Ubuntu](../README.md) · [сервер](SERVER_INSTALL.md).

## Как обновить

Обслуживание **1.0.7** поддерживает обновление существующей установки **1.0.6-rc.1** с точным тегом `server-wsl-v1.0.6-rc.1-dad063393b53`. Используйте новое обслуживание 1.0.7, выберите прежнюю установку и проверьте адрес, папку и целевую версию перед обновлением вне эфира.

1. Выберите точный пакет **своего направления** в каталоге и проверьте его `SHA256SUMS`. Windows/WSL2 и Linux выпускаются отдельно; не используйте общий `releases/latest`.
2. Обновляйте существующий сервер **вне эфира**, сохраняя прежнюю установку и данные. Для WSL2 используйте инструмент обслуживания соответствующего выпуска и проверьте выбранные адрес и папку; для Linux — штатный `update` с прежним каталогом данных (`--state-dir`). Повтор команды первоначальной установки не обновляет завершённую Linux-установку.
3. После запуска обновлённого сервера перезагрузите страницы студии и кастеров, включая открытые в Windows Client. Новые диагностические поля появляются только у обновлённых страниц; прежняя история ими не дополняется.
4. Проверьте подключение с другого устройства, звук, камеру, отдельные ссылки OBS/vMix и экспорт диагностики.

**Windows Client остаётся 1.0.1:** существующий клиент получает web-интерфейс выбранного обновлённого сервера после перезагрузки страницы. Переустановка клиента для этих серверных изменений не нужна.

**Windows/Docker Server Setup остаётся Legacy 1.0.4.** Новый пакет этого направления не выпускается. Автоматический перенос Docker → WSL2 не поддерживается; сохраните старые данные. Архив удаления WSL2 содержит пароли и ключи: храните всю папку приватно, отдельно от ZIP статистики.
