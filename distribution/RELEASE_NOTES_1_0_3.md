# CastLink Server и Linux 1.0.3 · Windows Client 1.0.1

Под карточками гостей в студии видны фактические битрейты приёма видео и
микрофона, а также состояние сети. Маленькая стрелка рядом со статусом открывает
памятку с порогами «Хорошая», «Средняя» и «Плохая» и текущими исходными числами.
Она доступна также при отсутствии данных; закрывается крестиком, Escape или
нажатием вне памятки. Меню не меняет размеры карточек и не перезапускает видео.

Формула оценки сохранена: действует худший показатель накопленных потерь пакетов,
джиттера и RTT. Это не измерение скорости интернета. При отсутствии или устаревании
замера отображаются прочерки. Обновление метрик не перезагружает страницу;
одинаковые замеры не обновляют весь список гостей.

В этот же серверный выпуск входит единый тумблер шумоподавления и эхоподавления в меню микрофона кастера и его карточке у студии. Новые микрофоны начинают с выключенной обработкой; явный сохранённый выбор сохраняется. Студия получает подтверждённый результат переключения без ручного согласия кастера. Переключение сохраняет mute, камеру и приватное обращение.

## Обновление

- Server Setup и Linux: обновите прежнюю установку до 1.0.3 вне эфира, сохранив
  прежние данные и настройки. Затем вручную обновите страницы студии и участников.
- Windows Client 1.0.1: установите новый пакет через встроенную проверку обновлений
  либо вручную. Клиент показывает интерфейс выбранного сервера: для этой функции
  сервер тоже должен быть обновлён. Клиент не содержит отдельную копию web-студии.
- Источники, Client, Server Setup и Linux готовятся из одного проверенного коммита
  main с независимыми номерами продуктов. Экспериментальные WSL-пакеты этим
  выпуском не повышаются до стабильных.

Выпуск включает прежние исправления актуальной main; ранее опубликованные архивы
и их контрольные суммы сохраняются. Новые ссылки и точный source/build ID
появляются в [каталоге продуктов](PRODUCTS.md) после проверки публикации.
