# Обработка микрофона — 1.0.3

[Русский](RELEASE_NOTES_1_0_3.md) · [English](docs/en/RELEASE_NOTES_1_0_3.md) · [简体中文](docs/zh-CN/RELEASE_NOTES_1_0_3.md)

Шумоподавление и эхоподавление по умолчанию выключены. Явный сохранённый выбор сохраняется. В настройках микрофона обе функции объединены в один тумблер. Основная студия может переключать его в карточке кастера без ручного подтверждения кастера; приложение автоматически сообщает результат. Переключение сохраняет выключенный микрофон и приватное обращение.

Сохранены измеренные битрейты приёма видео, аудио и оценка сети в карточках кастеров.

Обновите Windows Server Setup или Linux вне эфира, выбрав прежнюю установку, затем перезагрузите страницы студии и кастеров. Windows Client остаётся на 1.0.0 и отображает интерфейс выбранного сервера. Старые установленные серверы обновляются явным действием владельца.

Пакеты Windows/WSL2 остаются отдельными кандидатами; этот выпуск не объявляет их стабильными.
