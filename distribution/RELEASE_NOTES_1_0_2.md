# CastLink Server 1.0.2

[Русский](RELEASE_NOTES_1_0_2.md) · [English](docs/en/RELEASE_NOTES_1_0_2.md) · [简体中文](docs/zh-CN/RELEASE_NOTES_1_0_2.md)

- В Super Admin добавлены графики комнат и подключений, CPU, памяти, диска и сети. История за последние 24 часа сохраняется на диске; сбор раз в 15 секунд работает при закрытой панели и продолжается после перезапуска.
- Добавлен структурированный журнал событий, предупреждений и ошибок с фильтром уровня и страницами. Хранение ограничено по времени и размеру: при большом потоке часть событий удаляется раньше суток. Пароли и токены исключаются из журнала.
- Новый Linux-выпуск включает самостоятельный `install-server.sh` с закреплённой версией и SHA256 архива. Точную ссылку выбирают из того же выпуска; [инструкция](SERVER_INSTALL.md). Повторный запуск сохраняет работающую установку; обновление — отдельная команда.

Для обновления используйте штатный механизм своего серверного пакета и тот же каталог данных. Затем перезагрузите страницы вне эфира. Доступ к серверной статистике остаётся только у платформенного администратора; права комнаты его не дают. Данные истории находятся в прежнем серверном каталоге данных, дополнительная служба БД не нужна. Windows Client остаётся 1.0.0.

Локальный Windows-сервер в обычном Server Setup 1.0.2 использует Docker Desktop с Linux-контейнерами. Windows без Docker через WSL2 остаётся отдельным кандидатом: установка на Windows11/WSL и внешний медиазвонок/HTTPS/TURN ещё не подтверждены. Этот кандидат не объявляется стабильным пакетом.
