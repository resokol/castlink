# CastLink Server Setup и Linux 1.0.5 · исходники 1.0.5

Примечания относятся к серверным пакетам и архиву исходников **1.0.5**. Windows Client остаётся **1.0.1** и показывает интерфейс выбранного сервера. Доступные выпуски, точные source/build ID, ссылки и контрольные суммы проверяйте в [каталоге продуктов](PRODUCTS.md). Ранее опубликованные архивы 1.0.4 и их SHA256 сохраняются без изменений.

## Изменения

Серверные пакеты включают последние сетевые веб-исправления, [описанные 16 ноября для текущих исходников](RELEASE_NOTES_1_0_4.md):

- Текущая оценка использует последние **10 секунд**; история потерь за сессию хранится отдельно. Процент выводится перед числом потерянных пакетов.
- Участки **кастер → сервер** и **сервер → студия** показываются отдельно. Для отправки учитываются и аудио, и видео; кастер с одним микрофоном тоже получает оценку. Счётчики и проценты разных участков не складываются.
- Общая оценка учитывает худший свежий показатель. «Хорошая» требует свежих данных всех активных участков; отсутствие обратной связи, первый базовый замер, устаревшие, повторные и запоздавшие сообщения не становятся свежими нулевыми потерями. Защита от старых сообщений сохраняется при переподключении сигнального канала.
- Свежесть приёма ограничена **6 секундами**, обратной связи отправки — **12 секундами**. Повтор старого RTCP-отчёта не продлевает её. История и текущий замер остаются раздельными при смене треков; новая сессия участника начинает собственную историю.
- Используются уже собранные WebRTC-отчёты и существующий цикл отправки. Дополнительных RTC-опросов и таймеров нет; обновление метрик сохраняет видео, меню и фокус.

Изменения веб-сервера не добавляются в уже скачанный установочный архив от обновления сайта или документации. Windows Client не содержит отдельную копию web-студии; для этих исправлений нужен обновлённый сервер.

## Обновление

1. Выполняйте обновление **вне эфира**. Сохраните нужную резервную копию данных и конфигурации.
2. Для Windows Server Setup распакуйте новый пакет отдельно, запустите `EasySetup.exe`, выберите **«Обновить»** и прежнюю локальную установку либо тот же VPS. Для standalone Linux используйте `check-updates` и `update` из нового пакета с **прежним `--state-dir`**: [инструкция](INSTALL.md). Сохраняйте UUID, секреты, настройки и тома; переустановка с удалением данных не нужна. Публикация пакета сама не обновляет работающий сервер.
3. После проверки готовности вручную обновите страницы **и студии, и кастера**, включая страницы в Windows Client. Оба участника должны загрузить новый веб-код, чтобы студия получала показатели отправки кастера.
4. Проверьте звук, видео, кастера без камеры, индивидуальный выход и используемый `/watch`.

## Платформы

Обычный локальный Windows Server Setup использует **Docker Desktop**; standalone Linux и установка на VPS используют **Docker/Compose**. Windows/WSL2 без Docker остаётся отдельным экспериментальным каналом: этот выпуск не переводит его в стабильные продукты и не переносит в него данные Docker-установки.
