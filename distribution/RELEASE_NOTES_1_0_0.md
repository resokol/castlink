# CastLink 1.0.0

Русский · [English](docs/en/RELEASE_NOTES_1_0_0.md) · [简体中文](docs/zh-CN/RELEASE_NOTES_1_0_0.md)

Стабильный выпуск web/runtime и открытых исходников текущей боевой версии castlink.ru, без обозначения RC. Основан на установленной и проверенной сборке `9373537189123610c60ef52ec88eef40c6c158ff`.

## Добавлено и исправлено

- Компактная студийная консоль с монитором, управлением устройствами, кастерами и статистикой.
- Меню выбора микрофона и камеры кастера, проверка микрофона и настройки обработки звука.
- Исправлены мобильная компоновка, пропорции видео, график статистики и редактор мультивью.
- Обновление HTTP-сессии и диагностика ошибок браузера, соединения и аудио.
- И прочие мелкие изменения.

## Обновление

После обновления сервера перезагрузите страницы студии и кастера вне эфира. Существующие данные и настройки сохраняются; миграция базы для этого выпуска не требуется.

Этот выпуск содержит исходники web/runtime. Архив исходников не является готовым установщиком. Windows Client, Windows Server Setup и standalone Linux имеют независимые выпуски: их ранее опубликованные пакеты и контрольные суммы сохраняются. Проверенные установщики перечислены в [каталоге продуктов](PRODUCTS.md).

Собственный код CastLink распространяется по [MIT](../LICENSE); сторонние компоненты сохраняют свои лицензии.
