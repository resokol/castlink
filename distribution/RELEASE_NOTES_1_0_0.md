# CastLink 1.0.0

Русский · [English](docs/en/RELEASE_NOTES_1_0_0.md) · [简体中文](docs/zh-CN/RELEASE_NOTES_1_0_0.md)

Стабильный выпуск CastLink **1.0.0**, без обозначения RC: web/runtime, Windows Client, Windows Server Setup и standalone Linux. Windows Client собран из исходного коммита `93d9b93e17daced23b3eb4207c8464d6091bea0c`; Windows Server Setup и standalone Linux — из `1ea894bd94adb96f861398cc30addc93d1bf9d21`. Точные ссылки на три продукта и их `SHA256SUMS` — в [каталоге пакетов](PRODUCTS.md).

## Добавлено и исправлено

- Компактная студийная консоль с монитором, управлением устройствами, кастерами и статистикой.
- Меню выбора микрофона и камеры кастера, проверка микрофона и настройки обработки звука.
- Исправлены мобильная компоновка, пропорции видео, график статистики и редактор мультивью.
- Обновление HTTP-сессии и диагностика ошибок браузера, соединения и аудио.

## Обновление

Обновляйтесь вне эфира: серверные службы перезапускаются, а клиент закрывается для установки. Сначала сохраните нужные резервные копии данных и конфигурации.

- **Windows Client:** запустите встроенную проверку обновлений. Установщик скачивается и проверяется до отдельного согласия на закрытие клиента и установку. Если старый клиент не находит выпуск, один раз скачайте установщик 1.0.0 вручную из каталога и проверьте его SHA256 по `SHA256SUMS` того же выпуска. EXE не подписан.
- **Windows Server Setup:** распакуйте весь новый `CastLink-Windows.zip`, запустите `EasySetup.exe`, выберите «Обновить» и прежнюю локальную папку или тот же VPS.
- **Standalone Linux:** используйте команды `check-updates` и `update` с прежним `--state-dir`; при ручной установке используйте новый проверенный пакет. [Порядок обновления](LINUX_MANUAL.md#диагностика-и-обновления). Этот helper не принимает Windows/legacy-установки.

При обновлении существующей поддерживаемой установки сохраняются данные, настройки, UUID, секреты и сеть; новая настройка вместо выбора прежней установки не является обновлением. Миграция базы для этого выпуска не требуется. После обновления сервера перезагрузите страницы студии и кастера вне эфира и проверьте подключение, звук, видео и выходы OBS/vMix.

Три продукта имеют независимые каналы выпуска. Пакет и `SHA256SUMS` берите из одного выпуска одного продукта. Старые RC-архивы, встроенные manifests, лицензии и контрольные суммы сохраняются без изменений. Архив исходников не является готовым установщиком.
