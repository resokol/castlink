# CastLink 1.0.6 — диагностика видео

В статистике студии добавлена кнопка **«Диагностика видео → JSON»** рядом с историей аудио. Она скачивает сохранённые видеозамеры за выбранный период с текущими фильтрами участников и сессий. Для сравнения отправки студии и приёма кастеров выберите **всех участников**.

Файл содержит время UTC, кодек, размер, FPS, битрейт, потери, задержку и доступные счётчики кадров, кодирования/декодирования и зависаний. Записи видео и аудио не создаются. Это собственный журнал CastLink; внутренний дамп Chrome при необходимости скачивается отдельно через `chrome://webrtc-internals`.

Новые счётчики поступают после обновления страниц студии и кастеров. Старые замеры сохраняют только имеющиеся поля; отсутствие данных не означает ноль. При ограничении объёма выгрузка отмечается как частичная; выберите более короткий период или отдельную сессию. Диагностика не исправляет сетевые сбои или зависания автоматически.

## Обновление

Обновляйте существующую установку **вне эфира**, сохраняя прежние данные, UUID, пароли, адрес и сертификаты. После готовности сервера вручную обновите страницы студии и кастеров, включая страницы в Windows Client, затем проверьте звук, видео и скачивание JSON.

Linux использует своё направление выпуска **1.0.6**. Windows/WSL2 — отдельный предварительный выпуск **1.0.6-rc.1**, сохраняющий статус prerelease. Для него используйте штатный инструмент обслуживания и выбранную существующую установку; перенос данных из Docker не предусмотрен. Доступные точные пакеты и результаты проверок указаны на странице соответствующего выпуска GitHub.

Windows Client остаётся **1.0.1**: он показывает интерфейс выбранного сервера. Публикация пакета сама по себе не обновляет установленные серверы и открытые вкладки. Старые опубликованные пакеты и контрольные суммы не изменяются.
