# CastLink Updater 1.0.0

Подключите CastLink Updater **один раз на каждом компьютере** с CastLink. Затем используйте постоянный ярлык Windows или команду Linux: скачивать новый инструмент обслуживания для каждого выпуска вручную не требуется. CastLink Updater получает проверяемую версию собственного инструмента и выбирает отдельный стабильный канал нужного продукта.

Актуальные выпуски — **Windows Client 1.0.3** и **CastLink Server 1.0.11** для Windows/WSL2 и Ubuntu/Linux. Версия самого CastLink Updater — **1.0.0**. Подключение CastLink Updater не переустанавливает сервер, не меняет его версию и не перезапускает службы.

## С каких старых версий можно обновиться

Для Windows/WSL2 доступен прямой переход на 1.0.11 со всех ранее опубликованных версий сервера, включая RC. Для остальных продуктов условия приведены в таблице.

| Продукт | Условия |
| --- | --- |
| Windows/WSL2 Server → 1.0.11 | Все семь исходных версий: **1.0.5-rc.1, 1.0.5-rc.2, 1.0.5-rc.3, 1.0.6-rc.1, 1.0.7, 1.0.8 и 1.0.10**. Для каждой апдейтер предлагает сразу 1.0.11. |
| Windows Client | Нужен установленный официальный Client с читаемыми метаданными сборки. Обнаружение Client 1.0.0 и выбор 1.0.1 проверены; это не обещание поддержки любых старых или изменённых сборок. |
| Linux Server | Поддерживаются установки штатного standalone Linux/Compose-установщика с сохранёнными настройками и идентификатором. Установку нужно завершить или восстановить перед обновлением. Произвольные ручные установки не подхватываются. |
| Windows/Docker Legacy | Используйте прежнее обслуживание. Автоматического перехода на WSL2 или Linux нет. |

Сначала выполните **«Проверить»** или `castlink check-updates` для своей установки. Успешная проверка версии и файлов не заменяет резервную копию и проверку работы сервера после обновления.

## Windows: один ярлык для Client и WSL2

1. Скачайте [install-updater-windows.cmd](https://castlink.ru/general/downloads/updater/install-updater-windows.cmd) на **тот компьютер, где установлен Client или WSL-сервер**.
2. Запустите файл. Он получает и проверяет PowerShell-инструмент официального выпуска и подключает его для текущего пользователя. Node.js и отдельный Client для обслуживания WSL не нужны.
3. В меню **Пуск** найдите постоянный ярлык **Update CastLink**. Окно CastLink Updater называется **«Обновить CastLink»**; доступны русский, английский и китайский языки.
4. Выберите **конкретную локальную установку**: Client либо WSL-сервер. При нескольких серверах сверьте адрес и папку. Обновление выбранного продукта не означает обновление остальных.
5. Нажмите **«Проверить»**. Сверьте продукт, установку, текущую и доступную версии, прочитайте примечания. Для применения нажмите **«Обновить…»** и подтвердите действие. Во время эфира сервер не обновляйте.

**Проверять при запуске** можно отключить в окне; кнопка **«Проверить»** остаётся доступной. Проверка и отмена не останавливают сервер и не закрывают Client. Применение серверного обновления прерывает работу; клиентский установщик может закрыть приложение после подтверждения.

Если вы выбрали прямой PowerShell-файл `castlink-updater.ps1` из официального выпуска вместо CMD, сначала проверьте его по `SHA256SUMS`, затем один раз выполните в папке загрузки:

```powershell
powershell.exe -NoProfile -STA -ExecutionPolicy Bypass -File .\castlink-updater.ps1 -Install -Language ru
```

При нестандартной WSL-папке откройте CastLink Updater из панели этого сервера либо укажите его настоящий абсолютный путь параметром `-InstallRoot`. Не выбирайте чужую установку только потому, что она первая в списке.

## Linux: подключить существующий сервер

Нужны **bash и Python 3**, уже необходимые серверному окружению. Команды ниже выполняются на самом Linux-сервере с правами доступа к его установке. `/opt/castlink-server` — стандартный пример: замените его **реальной существующей папкой данных**, если сервер установлен в другом месте.

```bash
curl -fsSL https://castlink.ru/general/downloads/updater/install-updater-linux.sh -o install-updater-linux.sh
sudo bash install-updater-linux.sh --state-dir /opt/castlink-server --lang ru
```

Это однократное подключение, а не команда первоначальной установки сервера. По умолчанию для root создаются `/usr/local/bin/castlink` и приватный каталог CastLink Updater `/var/lib/castlink-updater`; серверные данные остаются на своём месте. Имеющаяся посторонняя команда `castlink` не перезаписывается: при конфликте сначала устраните неоднозначность `PATH`.

Проверить доступные обновления без их применения:

```bash
sudo castlink check-updates --state-dir /opt/castlink-server
```

Применить после просмотра текущей/целевой версии, примечаний и явного подтверждения:

```bash
sudo castlink update --state-dir /opt/castlink-server
```

Показать настройку проверки при запуске или изменить её:

```bash
sudo castlink updates --state-dir /opt/castlink-server
sudo castlink updates --state-dir /opt/castlink-server --auto-check off
sudo castlink updates --state-dir /opt/castlink-server --auto-check on
```

При единственной зарегистрированной установке `--state-dir` можно опустить. Для нескольких установок укажите нужный абсолютный путь; для подключения ещё одной один раз повторите установщик CastLink Updater с её `--state-dir`. Перемещённая папка или изменившаяся идентичность требуют явного разбора и регистрации настоящей установки — CastLink Updater не создаёт новый сервер вместо старого. Настройка не добавляет cron, системный таймер или фоновую службу.

## Проверки, ошибки и данные

- Выбираются стабильные совместимые выпуски **своего** продукта; общий GitHub `releases/latest` не определяет цель. Устанавливаемые файлы проверяются по manifest, размеру и SHA256 официального выпуска. SHA256 не является цифровой подписью издателя. [Каталог и контрольные суммы](PRODUCTS.md#updater).
- **«Обновлений нет»** означает отсутствие подходящей новой версии. Ошибка сети или проверки показывается как ошибка: исправьте соединение и повторите тот же ярлык или команду. Повреждённая загрузка не запускается.
- Обновление продукта всегда требует действия и подтверждения пользователя. Автономного применения, удалённого SSH-управления и обхода других компьютеров нет. Рабочую установку обновляйте вне эфира; затем перезагрузите страницы студии и кастеров.
- Используется штатное обслуживание выбранного продукта с прежними данными и идентификаторами. Храните отдельную резервную копию нужных данных. Прерванную WSL-операцию завершайте через **«Восстановить операцию…»** или штатное обслуживание; универсальный откат любых изменений базы не обещается.
- Windows/Docker Server Setup остаётся **Legacy 1.0.4** со своим прежним обслуживанием. CastLink Updater не переводит его в WSL2 или Linux автоматически. Опубликованные старые архивы не изменяются.
