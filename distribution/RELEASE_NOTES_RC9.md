# CastLink 1.0.0-rc.9

## Сервер: Linux и Windows Server Setup

- В дополнительных настройках входа кастера доступны разрешение камеры Авто/720p/1080p и FPS Авто/15/30/50/60. По умолчанию оба значения — Авто.
- В режиме «Окно» булавка закрепляет участника в большом окне только для текущего кастера. По умолчанию никто не закреплён.
- Добавлен выбор H.265 для поддерживающих его браузеров; для отправки и просмотра требуется соответствующая поддержка кодека. H.264 остаётся вариантом по умолчанию.
- Обновлена нижняя панель кастера: подписи на компьютере, только значки на телефоне, кнопка выхода в панели.
- Переключатели «Окно»/«Плитка» и настройки перенесены в шапку перед статусом «Онлайн». Служебный подвал доступен ниже рабочей области при прокрутке.
- Исправлена надпись STUDIO PLAYBACK.

## Обновления всех трёх продуктов

Исправлена проверка адресов файлов после переименования репозитория в `resokol/castlink`. Принимаются точные адреса этого репозитория и его прежнего имени `resokol/castlink-releases`; проверка тегов, состава и контрольных сумм сохраняется.

**Для старого Windows Client нужен один ручной переход:** скачайте установщик rc.9 из [каталога продуктов](PRODUCTS.md), проверьте SHA256SUMS и установите после завершения эфира. Старый клиент может сообщать, что обновлений нет. После перехода последующие обновления снова обнаруживаются штатной проверкой.

Для собственного сервера используйте новый Windows Server Setup или Linux-пакет и штатную команду обновления вашей установки. Если старая проверка не находит выпуск, скачайте новый пакет вручную. Само обновление клиентского EXE не обновляет сервер. Участники получают новый веб-интерфейс после обновления сервера и перезагрузки страницы.

Перед обновлением завершите эфир и сохраните необходимые данные. Установка выполняется только по действию пользователя. Прежние архивы, теги и контрольные суммы не заменяются.
