# 主演播室诊断

[Русский](../../STUDIO_DIAGNOSTICS.md) · [English](../en/STUDIO_DIAGNOSTICS.md)

音量表在各自组件内更新，不再每帧更新整个参与者列表。

更新服务器后，请在浏览器或 Windows Client 中重新打开主演播室。进入**统计 → 主演播室诊断**。统计视图约每15秒刷新，服务器约每2秒接收测量值；过期数据会显示提示。

指标包含标签页可见性、主线程定时器延迟及会话最大值、JavaScript 错误和未处理拒绝计数，以及浏览器支持的 JavaScript 堆内存和长任务。未知指标不等于零。后台定时器限速不算可见界面卡顿。JavaScript 堆不等于标签页总内存或 GPU 内存。

**演播室诊断 → JSON** 导出所选时间段、日期、参与者和会话的数据。查看主演播室时选择“演播室”角色。上限为50000个样本或20MiB；不完整文件标记为 partial。权限沿用演播室所有者/房间管理员规则，平台历史需要 super-admin。

**此标签页日志 → JSON** 不依赖服务器统计。当前和上一会话的有限快照约每10秒及可见性变化/结束时保存到 sessionStorage。存储可用时，同一标签页和 origin 刷新后可保留上一会话。关闭标签页可能删除日志。存储受限时，当前可用数据仍保留在内存中。

服务器沿用 `${STUDIOLINK_STATS_DIR}` 或 `${STUDIOLINK_DATA_DIR}/stats/<room-hash>/<hour>.jsonl`，较旧小时文件压缩为 `.jsonl.gz`。默认保留30天，总磁盘限额512MiB，容量限制可能缩短实际历史。现有经过清理的浏览器错误以 `browser.crash` 写入 web 服务日志（`docker logs` 或安装的常规日志）。分享完整服务器日志前请检查内容。

新增 runtime 字段不含媒体录制、密码、令牌、完整 URL、设备名称或任意错误文本。服务器统计导出沿用参与者姓名和标识，仅向事故调查人员提供。

完整 renderer/GPU 崩溃或进程退出可能无法留下最终样本。缺口和之前的指标有助于调查，但不能证明原因。事故后请导出对应时间的服务器 JSON、原标签页的本地日志，并记录时间和屏幕状态。

Timeweb 与独立服务器分别更新。其他安装需要新的 Windows/Linux 服务器包；更新 Client EXE 不会更新服务器。连接已更新服务器的客户端刷新后会获取新演播室网页代码。
