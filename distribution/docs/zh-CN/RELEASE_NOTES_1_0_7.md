# CastLink 1.0.7 — 稳定服务器与 Web 版本

以已认可的 castlink.ru 版本为基准的稳定服务器与 Web 发行版。准确软件包、版本及校验和见[产品目录](PRODUCTS.md)。现有归档及标签保持不变。

## 包含的变更

- **视频诊断：**演播室统计中的“视频诊断 → JSON”导出发送和接收历史，以及可用的 FPS、码率、丢包、帧与卡顿计数。保留所选时段、参与者和会话；不完整导出标记为 `partial`。
- **音频诊断：**历史区分发布、SDK 音轨、MediaStreamTrack 和播放器静音，记录可用的实际采集/处理设置、静音补偿与解码器速率修正。旧记录及浏览器不支持的字段仍为未知；诊断不会自动修复失真。
- **最近 10 秒网络质量：**当前等级及丢包区分音频/视频和参与者 → 服务器 / 服务器 → 演播室两个方向，保留会话历史并支持仅音频参与者。
- **vMix 演播室流：**修复受影响的嵌入式浏览器（包括 vMix 28 配置）中的 `AbortSignal.any is not a function` 错误。更新服务器后请刷新 vMix 浏览器输入。此修复不代表已单独验证真实 vMix 直播。
- **WSL2 Windows 服务器：**无需 Docker Desktop；原生 Windows 面板提供启动/停止、打开服务器、统计与 24 小时导出。维护工具支持选择安装、检查更新、带归档删除、恢复归档及完成中断的操作。服务器在 WSL2 内运行，并非 Windows 服务。

诊断详情：[指南](STUDIO_DIAGNOSTICS.md)。要求、网络与维护：[Windows/Ubuntu](../../../README.zh-CN.md) · [服务器](SERVER_INSTALL.md)。

## 更新步骤

**1.0.7** 维护工具支持更新现有 **1.0.6-rc.1** 安装，准确来源标签为 `server-wsl-v1.0.6-rc.1-dad063393b53`。请使用新版 1.0.7 维护工具，选择原安装，核对地址、文件夹及目标版本，并在停播时更新。

1. 从目录选择**对应渠道**的准确软件包并核对 `SHA256SUMS`。Windows/WSL2 与 Linux 分别发布，不要使用统一的 `releases/latest`。
2. 请在**停播时**更新原服务器，保留原安装与数据。WSL2 使用对应发行版的维护工具，核对所选地址及文件夹；Linux 使用正常 `update` 命令及原数据目录（`--state-dir`）。重复首次安装命令不会更新已完成的 Linux 安装。
3. 更新后的服务器启动后，刷新演播室及参与者页面，包括 Windows Client 内的页面。新增诊断字段需要刷新页面，旧历史不会补全这些字段。
4. 检查另一设备的连接、音频、摄像头、各 OBS/vMix 链接及诊断导出。

**Windows Client 保持 1.0.1：**现有客户端刷新页面后加载所选已更新服务器的 Web 界面。这些服务器变更无需重新安装客户端。

**Windows/Docker Server Setup 保持 Legacy 1.0.4。**此渠道不生成新软件包。不支持自动 Docker → WSL2 迁移，请保留原数据。WSL2 删除归档含密码与密钥，请完整、私密地保存整个文件夹，并与统计 ZIP 区分。
