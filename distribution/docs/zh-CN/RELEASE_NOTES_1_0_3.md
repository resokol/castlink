# 麦克风处理 — 1.0.3

[Русский](../../RELEASE_NOTES_1_0_3.md) · [English](../en/RELEASE_NOTES_1_0_3.md) · [简体中文](RELEASE_NOTES_1_0_3.md)

降噪与回声消除默认关闭，已明确保存的选择予以保留。麦克风设置通过一个开关控制这两项功能。主控演播室可在主播卡片中切换，无需主播手动确认；应用会自动报告应用结果。切换保留麦克风静音状态与私密通话。

参与者卡片保留实测视频、音频接收码率及网络等级。

请在停播时更新 Windows Server Setup 或 Linux，并选择原有安装，然后刷新演播室和主播页面。Windows Client 保持 1.0.0，显示所选服务器的界面。现有服务器需要所有者明确执行更新。

Windows/WSL2 软件包仍为独立候选版，本次发行不将其提升为稳定版。
