# CastLink Server 与 Linux 1.0.3 · Windows Client 1.0.1

参与者卡片现在显示摄像头和麦克风的实测接收码率及网络等级。等级旁的小箭头
可打开精简说明，列出“良好”“一般”“较差”的阈值及当前测量值。无数据时也可
打开；可通过关闭按钮、Escape 或点击外部关闭。说明不会改变卡片尺寸或重新创建视频。

保留原有评分规则：以累计丢包、抖动和 RTT 中最差的一项确定等级，不代表网速。
缺失或过期的测量显示为破折号。指标更新不会刷新页面，相同测量不会更新整个参与者列表。

同一服务器发行版还包含参与者麦克风菜单及演播室控制中的统一降噪与回声消除开关。新麦克风默认关闭处理，保留明确保存的选择。演播室无需参与者手动批准即可切换，并收到实际应用结果。切换保留静音、摄像头及私密通话状态。

## 更新

- 请在停播时将原有 Server Setup 或 Linux 安装更新至 1.0.3，保留数据和配置，
  然后手动刷新演播室及参与者页面。
- 通过客户端检查更新或手动安装 Windows Client 1.0.1。客户端显示所选服务器的
  界面，因此该服务器也需要更新；客户端不内置独立的网页演播室副本。
- 源代码、Client、Server Setup 和 Linux 均使用同一个已验证的 main 提交，
  产品版本独立。实验性 WSL 软件包不会因此升级为稳定版。

包含当前 main 已有的修复，不替换已发布的归档及校验和。验证发布后，可在
[产品目录](PRODUCTS.md)查看下载链接和精确的源代码与构建编号。
