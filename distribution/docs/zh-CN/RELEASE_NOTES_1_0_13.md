# 服务器 1.0.13 — 自动清理

[Русский](../../RELEASE_NOTES_1_0_13.md) · [English](../en/RELEASE_NOTES_1_0_13.md) · [简体中文](RELEASE_NOTES_1_0_13.md)

这是下一版 Windows/WSL2 和 Linux/Ubuntu 的准备说明，并不表示新软件包已经发布。
当前可用发行版请见[产品目录](PRODUCTS.md)。

- 安装程序注册后台维护任务，升级会更新维护程序，卸载服务器会移除相应任务。
  无需一直打开服务器面板。
- 保留当前和前两个成功启动的产品版本。同一版本的重复构建不会占用额外历史名额。
- 仅删除已确认属于本安装的过期材料。数据、设置、证书、其他安装和未完成操作均保留。
  历史共享缓存和未知记录需要单独检查。
- 清理兼容 Linux、旧 Windows/Docker 和受管理 VPS 的记录；相邻安装尚未启动容器时，
  其更新暂存镜像仍受到保护。
- Windows/WSL2 支持从已发布的 1.0.11 和 1.0.12 升级并保留身份、数据和设置；既有受支持升级路径不变。

现有服务器应在停止直播后使用正常工具升级。发布软件包不会自动升级服务器。
自动清理不会安装新版本，也不会创建自动数据备份。
