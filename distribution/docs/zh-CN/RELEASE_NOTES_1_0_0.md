# CastLink 1.0.0

[Русский](../../RELEASE_NOTES_1_0_0.md) · [English](../en/RELEASE_NOTES_1_0_0.md) · 简体中文

castlink.ru 当前生产版本的稳定网页运行时和开放源代码发布，不再使用 RC 标识。基于已部署并验证的构建 `9373537189123610c60ef52ec88eef40c6c158ff`。

## 新增与修复

- 紧凑演播室控制台，包含预览、设备控制、参与者及统计信息。
- 参与者麦克风和摄像头选择菜单、麦克风测试及音频处理设置。
- 修复移动端布局、视频比例、统计图表及多画面编辑器。
- HTTP 会话续期，以及浏览器、连接和音频诊断。
- 以及其他细微调整。

## 更新

服务器更新后，请在停播时刷新演播室及参与者页面。现有数据及设置将保留；此版本无需数据库迁移。

此版本提供网页运行时源代码。源代码归档并非可直接运行的安装包。Windows Client、Windows Server Setup 及独立 Linux 具有独立发行版本：之前发布的安装包及校验和保持不变。已验证安装包见[产品目录](PRODUCTS.md)。
