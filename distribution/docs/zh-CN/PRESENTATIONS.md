# PDF、PPTX 与演示控制

请选择[对应产品的软件包与校验和](PRODUCTS.md)。Windows Client 用于加入现有服务器；Windows Server Setup 与 Linux 用于安装服务器。普通参与者需要受支持的浏览器与 HTTPS。

## 准备文件

1. 选择**“上传 PPTX 或 PDF”**。每个文件上限为 **1,500,000,000 字节**。
2. PDF 在浏览器中准备；PPTX 上传至您的服务器，通过隔离转换器转为 PDF。此方式不需要安装 PowerPoint 应用。
3. 等待准备完成。文件名按钮打开**“由谁控制”**、**“显示演示”**及**“删除文件”**菜单。上传及选择控制者尚不会开始共享或授予远程访问权限。
4. 单独选择**“显示演示”**开始共享。文档以独立无音频视频流发送。如果界面提示，请先停止冲突的屏幕共享。

## 翻页与停止

实时演示中使用上一页/下一页及控制菜单。共享者可以委派翻页、收回控制并停止共享，自己的翻页按钮仍可使用。若页面已变化而命令冲突，请确认当前页面后明确重试。

停止操作结束实时共享，准备好的文件仍可再次显示或删除。关闭菜单或面板不等于停止。若停止失败，请检查状态并再次明确操作。

会议室内提供紧凑控制。受支持的浏览器浮动窗口需您主动打开；Document Picture-in-Picture 不可用或被拒绝时，请使用会议室内面板。Windows 客户端优先使用可用的原生面板。不要依赖大型红色浏览器窗口自动打开。

## 幻灯片、实时 PowerPoint 与电脑控制

准备的 PDF/PPTX 显示静态页面，此模式不播放原 PPTX 的动画、音乐或视频。需要原始 PowerPoint 的动画或音频时，请在电脑上运行放映，并在屏幕共享中选择其窗口及可用音频。直播前应测试实体 PowerPoint、全屏行为及音频。

幻灯片控制仅用于所选演示的翻页。Windows 客户端共享中的**“电脑控制”**在单独批准后提供整台电脑的鼠标与键盘访问，即使只显示一个窗口。上传文件不会把普通浏览器共享变成电脑控制。[请求、撤销与暂停原因](GUIDE.md#pc-control)。

## 兼容性与限制

- 服务器和转换器需通过对应完整服务器安装包更新，客户端单独更新。转换器内存上限为 2 GiB，工作磁盘建议至少预留 8 GB。文件大小上限不保证所有文档都能处理。
- 准备后检查页数、字体及排版。需要精确外观时，请在原电脑导出 PDF，仅在字体许可允许时嵌入字体。
- 不接受加密或带密码的文档。请使用未加密副本或导出 PDF。
- 转换器忙碌时请稍后重试；不可用时联系服务器所有者。PDF 不需要 PPTX 转换器。
