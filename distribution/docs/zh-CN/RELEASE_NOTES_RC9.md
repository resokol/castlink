# CastLink 1.0.0-rc.9

## 服务器：Linux 和 Windows Server Setup

- 嘉宾进入前的高级设置新增摄像头分辨率（自动/720p/1080p）和帧率（自动/15/30/50/60）。两项默认均为自动。
- 窗口模式中的固定按钮可将指定参与者显示在大画面中，仅影响当前嘉宾的视图。默认不固定任何人。
- 支持的浏览器可选择 H.265。发送端和接收端分别需要相应的编码和解码支持；默认仍为 H.264。
- 嘉宾底部工具栏在电脑上显示文字，在手机上仅显示图标，并包含退出按钮。
- 窗口/平铺切换及视图设置移至顶部在线状态之前。服务页脚可通过向下滚动访问。
- 修正 STUDIO PLAYBACK 标签。

## 三个产品的更新检查

修复仓库更名为 `resokol/castlink` 后的下载地址验证。仅接受该仓库及旧名称 `resokol/castlink-releases` 的精确文件地址；继续验证标签、文件清单和校验和。

**旧版 Windows Client 需要手动升级一次：**从[产品目录](PRODUCTS.md)下载 rc.9 安装程序，验证 SHA256SUMS，并在结束会话后安装。旧客户端可能错误地提示没有更新。升级后可恢复正常的更新检查。

自建服务器请使用新的 Windows Server Setup 或 Linux 软件包，按现有安装的更新步骤操作。若旧版检查程序找不到更新，请手动下载新软件包。更新客户端 EXE 不会更新服务器。服务器更新后，参与者刷新页面即可获得新界面。

更新前请结束活动会话并保存必要数据。安装必须由用户主动执行。既有归档、标签和校验和保持不变。
