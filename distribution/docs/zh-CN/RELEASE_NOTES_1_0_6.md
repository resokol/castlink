# CastLink 1.0.6 — 视频诊断

演播室统计中在音频历史旁新增 **视频诊断 → JSON**。它按所选时间段、参与者及会话筛选条件下载已保存的视频采样。请选择 **所有参与者**，以比较演播室发送与主播接收的数据。

文件包含 UTC 时间、编解码器、分辨率、FPS、码率、丢包、延迟，以及可用的帧、编码/解码和卡顿计数。不录制视频或音频。这是 CastLink 日志；Chrome 内部转储仍需通过 `chrome://webrtc-internals` 单独下载。

演播室和主播页面更新后才会发送新计数。旧记录仅保留原有字段；缺失值并不表示零。达到导出大小限制时会明确标记为部分导出，请选择较短时段或单个会话。诊断功能不会自动修复网络故障或视频卡顿。

## 更新

请在 **停播时** 更新原有安装，保留数据、UUID、密码、地址和证书。服务器就绪后，手动刷新演播室与主播页面，包括 Windows Client 内的页面，然后检查音频、视频及 JSON 下载。

Linux 使用独立的 **1.0.6** 发布通道。Windows/WSL2 使用单独的 **1.0.6-rc.1** 预发布版本。请通过维护工具选择原有安装进行更新；不支持从 Docker 迁移数据。确切软件包与验证结果见各 GitHub 发布页面。

Windows Client 仍为 **1.0.1**，显示所选服务器的界面。发布软件包不会自动更新已安装服务器或已打开页面。先前发布的软件包及校验值保持不变。
