# CastLink 1.0.0

[Русский](../../RELEASE_NOTES_1_0_0.md) · English · [简体中文](../zh-CN/RELEASE_NOTES_1_0_0.md)

Stable web/runtime and open source release of the current production castlink.ru version, without the RC label. Based on the deployed and verified build `9373537189123610c60ef52ec88eef40c6c158ff`.

## Added and fixed

- Compact studio console with playback, device controls, casters and statistics.
- Caster microphone and camera selection menus, microphone testing and audio processing settings.
- Mobile layout, video proportions, statistics graph and multiview editor fixes.
- HTTP session renewal and browser, connection and audio diagnostics.
- And other minor changes.

## Updating

Reload studio and caster pages off air after the server update. Existing data and settings are retained; this release requires no database migration.

This release contains web/runtime source code. The source archive is not a ready-to-run installer. Windows Client, Windows Server Setup and standalone Linux have independent releases: their previously published packages and checksums are retained. Verified installers are listed in the [product catalog](PRODUCTS.md).
