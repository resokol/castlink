# CastLink

Подключайте удалённых участников через браузер и получайте отдельные аудио- и видеопотоки для OBS или vMix.

**Нужен свой сервер? Выберите систему компьютера, на котором он будет работать:**

| Где устанавливаем | Что использовать |
| --- | --- |
| [Windows 11](#сервер-на-windows-11) | Полный установщик без Docker Desktop. Версия **1.0.5-rc.1** — предварительный выпуск. |
| [Ubuntu Linux / VPS](#сервер-на-linux-ubuntu) | Одна команда `curl`. Версия **1.0.5** — стабильный выпуск. |

Если нужно только подключиться к чужому серверу, достаточно браузера. [Windows-клиент](https://github.com/resokol/castlink/releases/download/client-v1.0.1-079fd0f9d4b1/CastLink-Client-1.0.1-079fd0f9d4b1-setup.exe) — отдельное приложение, он не устанавливает сервер.

## Перед установкой

- Компьютер сервера должен оставаться включённым, пока вы пользуетесь CastLink.
- Для работы через интернет приготовьте домен или публичный IPv4. Домен направьте на адрес сервера записью **A**. Для Windows также направьте `turn.ВАШ-ДОМЕН` на тот же IP.
- Если сервер стоит за роутером, настройте проброс на этот компьютер: **TCP 80, 443, 7881; UDP 3478, 7882, 30000–30031**. Эти же порты разрешите в сетевом экране VPS, если он есть. DNS и роутер установщик за вас не настраивает.
- Для проверки внутри одной сети можно использовать локальный IPv4 компьютера. Для HTTPS с локальным адресом потребуется доверие сертификату на устройствах участников.

**Нет публичного IP?** При CGNAT одного проброса портов недостаточно. Запросите публичный IPv4 у провайдера или установите сервер на Ubuntu VPS.

## Сервер на Windows 11

Нужны **Windows 11 x64, версия 22H2/build 22621 или новее**, включённая виртуализация и интернет. Установщик использует WSL 2 — Linux-среду внутри Windows. Docker Desktop, Node.js и PostgreSQL вручную устанавливать не нужно.

### 0. Подготовьте WSL

Откройте **Пуск → PowerShell → Запуск от имени администратора** и проверьте:

```powershell
wsl --version
```

Нужен **WSL 2.4.13 или новее**. Если WSL не установлен, команда предлагает `wsl.exe --install` или версия не выводится, выполните:

```powershell
wsl --install --no-distribution
```

После успешной установки **сохраните работу и перезагрузите Windows**. Затем снова откройте PowerShell от имени администратора:

```powershell
wsl --update
wsl --version
```

Если WSL уже установлен, достаточно обновить его и проверить версию; при запросе перезагрузки выполните её. Отдельно устанавливать Ubuntu не нужно — CastLink скачает свою серверную среду. Если любая команда завершается ошибкой, сначала устраните её; не продолжайте установку CastLink.

**Если раньше использовали CastLink через Docker:** остановите старый сервер в его панели. При переходе с Docker на WSL также закройте Docker Desktop через **Quit Docker Desktop**, если он запускает старый сервер после перезагрузки. Сохраните старые данные: новая WSL-установка не переносит комнаты и настройки автоматически.

**Нечитаемый красный текст с `wsl.exe --install`:** возможно, сообщение WSL выведено с неверной кодировкой. Проверьте WSL командами выше. Номер строки `742` сам по себе не определяет причину — это место вывода ошибки.

**Сообщение `Shared WSL settings saved. Restart Windows...`:** настройки сети сохранены, но ещё не применены. Сохраните работу, перезагрузите Windows и повторите запуск того же установщика из той же папки. Это может потребоваться отдельно от перезагрузки после установки WSL.

### 1. Скачайте установщик

**[Скачать install-server-windows.ps1](https://github.com/resokol/castlink/releases/download/server-wsl-v1.0.5-rc.1-085b087a2458/install-server-windows.ps1)**

Это полный установщик: необходимые серверные файлы он скачает сам. Hotfix, исходники и остальные архивы вручную скачивать не нужно.

### 2. Запустите его

Откройте папку со скачанным файлом. Нажмите на адресную строку Проводника, введите `powershell` и нажмите Enter. В открывшемся окне выполните:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\install-server-windows.ps1
```

Если двойной щелчок открывает текстовый редактор — это нормально: запускайте командой выше. Она задаёт разрешение выполнения только для этого запуска.

### 3. Ответьте на запросы

Некоторые вопросы появляются только при первой установке. В запросе `[y/N]` введите `y` и нажмите Enter, если согласны; Enter без ответа означает отказ.

| Запрос или этап | Что делать |
| --- | --- |
| Установить компоненты WSL? | Введите `y` и подтвердите запрос Windows. Если установщик просит перезагрузку — перезагрузите ПК и повторите ту же команду. |
| `Public hostname or IPv4 address` | Введите **свой** домен или IPv4 без `https://`, порта и пути. Например, `meet.example.com` — образец, замените его своим адресом. |
| Добавить `networkingMode=mirrored` и `hostAddressLoopback=true`? | Это настройки сети WSL. На выделенном для сервера ПК подтвердите `y`. Если программа просит перезапуск WSL/Windows — перезагрузите ПК и повторите команду. Уже работающие чужие WSL-системы установщик не остановит. |
| Добавить правила брандмауэра? | Введите `y` и подтвердите запрос администратора Windows. |
| IPv4 для медиа, если указан домен | Укажите IPv4 сервера, доступный участникам: для интернета — публичный, для локальной проверки — локальный. |
| Пароль создания комнат и его повтор | Придумайте отдельный пароль, сохраните его и повторите ввод. Символы при вводе **не отображаются** — это нормально. |
| Доверять сертификату этого сервера? | Вопрос появляется для локального сертификата. Подтверждайте только для своего сервера. На других устройствах локальный сертификат тоже потребуется добавить в доверенные. |
| Запускать сервер при входе в Windows? | `y` — автозапуск при входе **вашего пользователя**; `n` — ручной запуск. |

Загрузка и подготовка могут занять несколько минут. Не закрывайте окно до завершения. После перезагрузки повторяйте **тот же установщик** — он продолжит свою установку.

### 4. Проверьте результат

После успешной установки откроется **CastLink Server**. Дождитесь состояния **«CastLink работает»**, затем нажмите **«Открыть CastLink»**. Откроется адрес вашего сервера. Для создания комнаты используйте заданный пароль.

В этой же панели доступны запуск/остановка, статистика и **«Экспорт ZIP за 24 часа»**. Закрытие окна скрывает панель в трей; для остановки используйте **«Остановить службы»**.

Проверьте подключение с другого устройства. Для проверки интернета используйте, например, телефон с мобильной сетью, а не только Wi-Fi сервера.

**О выпуске:** это полный RC-установщик для нового ПК. Сборка, Windows-тесты и суммы файлов проверены; новая установка и перезагрузка именно этого пакета на отдельном чистом ПК не повторялись. Обновление поверх существующей установки другой версии не поддерживается. [Выпуск и SHA256SUMS](https://github.com/resokol/castlink/releases/tag/server-wsl-v1.0.5-rc.1-085b087a2458).

## Сервер на Linux Ubuntu

Поддерживаются **Ubuntu 22.04 или 24.04, x86-64/amd64**. Войдите на сервер через SSH под пользователем с правами `sudo`.

### 1. Выполните одну команду

```bash
curl -fsSL https://github.com/resokol/castlink/releases/download/linux-v1.0.5-732ad5fe7006/install-server.sh | sudo bash -s -- --install-runtime --lang ru
```

Команда скачивает закреплённый установщик **1.0.5**. Он проверяет серверный архив, устанавливает необходимые Docker Engine/Compose и Python, сохраняет установку в **`/opt/castlink-server`**.

Если получаете `curl: command not found`, сначала выполните:

```bash
sudo apt-get update && sudo apt-get install -y curl
```

Затем повторите команду установки.

### 2. Ответьте на запросы

| Запрос | Что вводить |
| --- | --- |
| Пароль `sudo`, если запрошен | Системный пароль пользователя Ubuntu. Символы не отображаются. |
| Внешний адрес сервера | Полный адрес, например `https://meet.example.com` или `https://ВАШ-IP`. Подставьте свой адрес. **Не оставляйте `127.0.0.1`**, если нужен доступ с других устройств. |
| IPv4 сервера для медиа, если запрошен | Реальный IPv4 сервера. Вопрос появляется, если его нельзя однозначно определить по адресу. |
| Пароль создания комнат и повтор | Новый отдельный пароль **8–256 символов**. Это не пароль SSH/sudo. Символы скрыты; сохраните пароль. |

В быстром режиме порты и способ HTTPS выбираются автоматически. Для локального адреса используется собственный сертификат; доверие ему на устройствах участников нужно настроить отдельно.

### 3. Дождитесь запуска

Установка завершена, когда появятся строки:

```text
CastLink setup completed: https://ВАШ-АДРЕС
Installation: /opt/castlink-server
```

Откройте показанный адрес в браузере. Создайте комнату с заданным паролем и проверьте подключение с другого устройства.

### 4. Управление сервером

Проверить состояние:

```bash
sudo python3 /opt/castlink-server/.castlink-package/scripts/linux-compose-setup.py status --state-dir /opt/castlink-server --lang ru
```

Запустить после остановки — замените `status` на `start`. Остановить с сохранением данных:

```bash
sudo docker compose -f /opt/castlink-server/compose.json stop
```

Повтор команды `curl` **не обновляет** завершённую установку. Для обновления замените `status` на `update` в команде выше и выполняйте её вне эфира; каталог данных оставьте прежним. После обновления перезагрузите страницы студии и кастеров.

## Если что-то не получилось

| Проблема | Что проверить |
| --- | --- |
| Windows просит перезагрузку или сообщает, что WSL уже работает | Закройте приложения, сохраните работу, перезагрузите ПК и запустите тот же установщик снова. Не удаляйте установленную систему или данные. |
| Виртуализация недоступна | Включите Intel VT-x / AMD-V в BIOS/UEFI. |
| Адрес не открывается | Проверьте IP/запись DNS A, состояние служб, брандмауэр и проброс портов на роутере. Для Windows-домена проверьте и адрес `turn.ВАШ-ДОМЕН`. |
| Страница открывается, но нет аудио/видео | Проверьте IPv4 медиа и UDP-порты из раздела «Перед установкой». Один открытый TCP 443 не доказывает работу медиа. |
| Браузер предупреждает о сертификате в локальной сети | Добавьте **публичный корневой сертификат своего сервера** в доверенные на каждом клиентском устройстве. Не отключайте проверки TLS. [Как экспортировать сертификат в Linux](distribution/LINUX_MANUAL.md). |
| Порт уже занят / обнаружена другая установка | Не запускайте два сервера на одних портах. Сначала остановите конфликтующий сервис; данные не удаляйте. |

Для диагностики Linux:

```bash
sudo docker compose -f /opt/castlink-server/compose.json ps
sudo docker compose -f /opt/castlink-server/compose.json logs --tail 100
```
