Windows Client — **1.0.0-rc.8**, сборка `90135013f5b6`; Windows Server и Linux Ubuntu — **1.0.0-rc.8**, сборка `72b315b2d251`: [пакеты и суммы](PRODUCTS.md). Пакет и `SHA256SUMS` берите из одного направления и выпуска.

В портретной мобильной «Плитке» два столбца с пропорциями 16:9. В чате доступны 24 смайлика; история и экспорт сохраняют обычный Unicode. Кнопка «Реакции» показывает одну из семи анимаций на две секунды, с учётом уменьшенного движения; реакции не записываются в чат и не попадают в чистые выходы.

При повторном открытии того же приглашения слот восстанавливается, если сохранилась действующая подписанная сессия. Другая вкладка изолирована; отказ её входа не очищает сессию первой. Просроченное или отозванное разрешение не восстанавливается.

Компоновка студии стала компактнее: управление воспроизведением и приглашения слева, исходящий поток и транспорт справа. В широком окне помещаются пять карточек гостей, четыре равных настройки под графиком размещены сеткой 2×2. Узкие окна сохраняют последовательный порядок блоков.

EXE Windows не подписаны. Обновление требует согласия пользователя и может перезапустить приложение или службы; запланируйте паузу эфира и самостоятельно сохраните нужные данные. Автоматические резервные копии пользовательского сервера не создаются. Физические устройства, PowerPoint и каждый тип документа проверяйте перед эфиром.

Бесплатная система удалённых подключений для эфиров. Кастер открывает ссылку в браузере, а студия получает его видео со звуком отдельным источником для OBS, vMix или другого режиссёрского ПО. Сервер работает на вашем Windows-ПК или Linux VPS.

- История чата комнаты за последние 24 часа с восстановлением и скачиванием текстового файла из статистики. В чате кастера сообщения прокручиваются внутри окна; поле ввода и отправка остаются видимыми при длинной переписке.
- Отдельная вкладка чата для студии, администратора и модератора с личной настройкой счётчиков новых сообщений и очисткой истории всей комнаты после подтверждения.
- Постоянные выходы слотов для OBS/vMix, обычный вход кастеров и автоматическая проверка камеры и микрофона до подключения.
- Экспериментальное мультивью с отдельным прозрачным выходом для OBS/vMix.
- Настройки новых приглашений и автоматическое кадрирование изображения кастера.
- Отдельный раздел «Резервные сервера» в боковом меню студии.
- Компактная карточка кастера с уровнем микрофона и основными показателями соединения.
- VP8, VP9, H.264 и AV1 для видео кастера при поддержке браузера.
- Запросы студии на смену устройств с подтверждением кастера.
- Отдельный видео- и аудиопоток каждого кастера.
- Просмотр студийного эфира по ссылке `/watch`.
- Ручной перенос комнаты и настраиваемый автоматический резерв.
- Статистика подключений для диагностики связи.
- Интерфейс на русском, английском и упрощённом китайском.

**Идёт публичное тестирование.** Перед рабочим эфиром проверьте устройства, сеть и резерв на своём оборудовании.


В окне кастера доступны «Окно» и «Плитка». На компьютере в режиме «Окно» вертикальный разделитель меняет размеры основной камеры или демонстрации и правой ленты. При нескольких источниках его можно двигать указателем и клавишами. Длинная лента прокручивается отдельно, видео сохраняет пропорции. На мобильном разделителя нет; компактные действия и меню «Ещё» сохранены. Экран отмечен мятной кнопкой, совместная презентация — голубой.

Для новой студии используются H.264, 10 000 кбит/с и 60 FPS; у кастера без сохранённого выбора кодека используется H.264. Явные сохранённые настройки не перезаписываются, битрейт и FPS кастера не повышаются. VP8, VP9, H.264 и AV1 доступны при поддержке браузера; интерфейс показывает выбранный и согласованный кодек. Это настройки запроса, а не гарантия измеренного качества.
## Windows-клиент и отдельные серверные пакеты

Если родная Windows-панель ещё показывает прежнюю надпись управления, обновите Client: F10 → «Проверить обновления» либо скачайте новый установщик вручную. Старые версии без проверки обновлений замените вручную. Обновление сервера не заменяет EXE; перед обновлением завершите эфир. EXE не подписаны.

Windows Client подключает студию или кастера к существующему серверу. Server Setup и Linux устанавливают собственный сервер и выпускаются отдельно.

[Установить клиент](https://github.com/resokol/castlink-releases/releases/download/client-v1.0.0-rc.8-90135013f5b6/CastLink-Client-1.0.0-rc.8-90135013f5b6-setup.exe) · [Переносимый клиент](https://github.com/resokol/castlink-releases/releases/download/client-v1.0.0-rc.8-90135013f5b6/CastLink-1.0.0-rc.8-90135013f5b6-Windows.exe) · [ZIP клиента](https://github.com/resokol/castlink-releases/releases/download/client-v1.0.0-rc.8-90135013f5b6/CastLink-Client-1.0.0-rc.8-90135013f5b6-win-x64.zip)

Клиент подключается к существующему серверу и отдельно проверяет канал клиента и сохранённые управляемые серверы. Можно проверить обновления вручную или отключить автоматические проверки. Загрузка проверяется по SHA256; закрытие клиента и установка новой версии требуют отдельного согласия. Версии без встроенной проверки обновлений замените новым пакетом вручную; обновление сервера не заменяет EXE клиента.

Обновлён интерфейс кастера и чата, исправлено вписывание целого кадра, добавлены встроенные шрифты PPTX, потоковая загрузка и дистанционное листание. Сохранены быстрый/расширенный режимы, настройки прокси и самостоятельный Linux helper. Есть отдельная настройка пароля создания комнат.

Для сервера используйте CastLink-Windows.zip или CastLink-Linux.tar.gz. Сохранённый управляемый VPS обновляется через Windows-мастер с необходимым SSH-доступом; обычная ссылка подключения таких прав не даёт. Для новых возможностей презентаций обновите и web, и конвертер полным подходящим серверным пакетом. Linux helper управляет только собственными установками. Перед обновлением завершите эфир.

Архивы сторонних исходников CastLink-ThirdParty-Sources.tar.gz и CastLink-ThirdParty-Office-Sources.tar.gz необязательны для установки. Клиент Windows пока без Authenticode-подписи; В каждом выпуске SHA256SUMS содержит суммы только его файлов.

## Новый установщик: быстро или с собственной сетью

В rc.8 быстрый режим включён по умолчанию. Для технических параметров явно включите **«Расширенная настройка»** в Windows-мастере; в самостоятельном Linux CLI добавьте `--advanced`. Быстрый режим использует обычный HTTPS и стандартные порты. Расширенный позволяет выбрать HTTP, прямой HTTPS или внешний HTTPS-прокси, адреса и порты сайта и медиа. Мастер и Linux CLI поддерживают RU / EN / 简体中文. [Режимы и примеры конфигурации](INSTALL.md).

На Linux helper `scripts/linux-compose-setup.py` поддерживает `init`, `start`, `status`, `check-updates` и `update` с прежним `--state-dir`. Он сохраняет UUID, секреты, сеть и имена томов, но не принимает Windows/legacy-установки. Команда `backup` удалена; нужные копии данных и конфигурации сохраняйте самостоятельно.

[Настройка режимов, прокси и резервных копий](INSTALL.md) · [Новый Linux helper и отдельная legacy-инструкция](LINUX_MANUAL.md). Обычный HTTP по LAN/публичному IP не даёт браузеру безопасный контекст для камеры, микрофона и демонстрации экрана; для удалённых участников используйте доверенный HTTPS. Прокси сайта не заменяет отдельные медиапорты.

## Начать работу

1. Установите сервер. На Windows распакуйте архив целиком и запустите `EasySetup.exe`. Для Linux используйте [отдельную инструкцию](LINUX_MANUAL.md) либо [установку по SSH из Windows-мастера](GUIDE.md#установить-на-linux-vps-из-windows).
2. Откройте CastLink, создайте студию и пригласите кастеров по ссылке.
3. Добавьте индивидуальные выходы кастеров в OBS/vMix и соберите эфир в привычном ПО.

Docker нужен только на сервере. Кастерам достаточно браузера, HTTPS и разрешений на камеру/микрофон.
