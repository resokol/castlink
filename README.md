## 20.10.2026 — Общий выпуск: PPTX, слоты и Windows-панель · 063e4967c05b

Обычные PPTX преобразуются в PDF изолированным конвертером, включая стандартные SVG, диаграммы и ссылки. Слоты кастеров показываются компактными строками со статусами и быстрым копированием ссылок. В Windows-панели меню оставляет STOP доступным, а ошибку остановки можно прочитать и повторить действие.

Обновите сервер и Windows-клиент вместе. Полностью закройте старый клиент и запустите новый EXE; автоматического самообновления EXE нет. Перед обновлением своего сервера сохраните резервную копию и завершите подключения. Страницы обновляйте вручную вне эфира. EXE без цифровой подписи.

Показ PDF/PPTX статический; оформление зависит от доступных шрифтов. Анимация, видео и документы с паролем этим режимом не поддерживаются.

## 20.10.2026 — Новый вход, панели сайта и камера PR60/PR61 · 1de5b686d719

PR61 включён: новый минималистичный вход «Я — студия» / «Я — кастер / гость», проверка имени и устройств перед явным подключением. Приглашения предлагают Windows-приложение или браузер; новый клиент регистрирует castlink: и спрашивает подтверждение перед заменой занятой комнаты. Гостю не нужен студийный токен доступа; сервер проверяет его приглашение/гостевой доступ.

Панели дистанционного управления слайдами можно перемещать за заголовок внутри страницы. Кнопка «Поверх других окон» в поддерживаемых Chrome/Edge открывает Document Picture-in-Picture; при отказе или отсутствии API управление остаётся на странице. STOP и слайды имеют независимые области общего окна. Закрытие панели не останавливает демонстрацию.

PR60 включён: студия, администратор и модератор задают размеры и FPS камеры в карточке гостя. Серверные настройки имеют приоритет; быстрый выбор 720/1080 и default1080 сохранены. Фактические размеры зависят от устройства и браузера. Выключенная камера, микрофон и экран не включаются этой настройкой.

Сохранены дизайн, презентации, native Windows-панели, качественные OBS/vMix-выходы и новые установщики Windows/Linux. Новый клиент скачивается и запускается вручную после полного закрытия старого: автоматического самообновления EXE нет. Страницы сайта обновляйте вне эфира. Физический fullscreen/focus PowerPoint отдельно не проверен; положение браузерного окна меняется за его рамку.

Перед обновлением своего сервера сделайте резервную копию и завершите подключения. EXE без цифровой подписи; дополнительные архивы исходников сторонних компонентов нужны для соблюдения лицензий, не для обычного запуска.

## 20.10.2026 — Камера и браузерные выходы · 1de5b686d719

Студия, администратор и модератор выбирают целевое разрешение камеры кастера 720/1080. Без заданного значения запрашивается 1080; фактическое разрешение зависит от камеры и браузера и показывается отдельно. Настройка применяется к текущей камере и сохраняется при переподключении.

Браузерные выходы OBS/vMix получают максимальный доступный слой источника и учитывают зум, сдвиг, поворот, кадрирование и отражение камеры. Демонстрация экрана остаётся отдельным источником. Сохранены общий дизайн, презентации, отдельный Windows-клиент и новые установщики Windows/Linux.

Вне эфира загрузите обновлённые страницы студии, кастера и браузерных входов vMix. Для этого web-исправления новый EXE не обязателен; новые клиентские пакеты доступны в этом выпуске. Перед обновлением сервера сделайте резервную копию и завершите подключения.

Новый выпуск объединяет актуальный сервер, новый установщик Linux и отдельный Windows-клиент.

Клиент подключается к существующему серверу. Он поддерживает презентации и отдельные плавающие панели управления владельца и получателя. Полностью закройте старый клиент перед запуском нового. Самообновление EXE пока не реализовано; кнопка обновления сервера запускает мастер для серверной установки.

Обновлён интерфейс кастера и чата, исправлено вписывание целого кадра, добавлены встроенные шрифты PPTX, потоковая загрузка и дистанционное листание. Сохранены быстрый/расширенный режимы, настройки прокси и самостоятельный Linux helper. Есть отдельная настройка пароля создания комнат.

Для сервера скачайте CastLink-Windows.zip или CastLink-Linux.tar.gz. Обновление подключённого VPS меняет только web и не обновляет текущий сервер через него самого. Linux helper обновляет только собственные установки. Перед обновлением сервера завершите эфир и сделайте резервную копию.

Архивы сторонних исходников CastLink-ThirdParty-Sources.tar.gz и CastLink-ThirdParty-Office-Sources.tar.gz необязательны для установки. Клиент Windows пока без Authenticode-подписи; SHA256SUMS содержит контрольные суммы всех пакетов.

## Новый установщик: быстро или с собственной сетью

Выпуск [easy-setup-31a402442fe1](https://github.com/resokol/castlink-releases/releases/tag/easy-setup-31a402442fe1) добавляет выбор **«Быстрая» / «Расширенная»** установка. Быстрый режим сохраняет обычный HTTPS; расширенный позволяет выбрать HTTP, прямой HTTPS или внешний HTTPS-прокси, адреса и порты сайта и медиа. Мастер и самостоятельный Linux helper поддерживают RU / EN / 简体中文.

На Linux теперь можно установить сервер без Windows: helper `scripts/linux-compose-setup.py` выполняет `init`, `start`, `status`, `backup` и `update`, сохраняя отдельный каталог конфигурации, UUID, секреты и имена томов. Он управляет только созданными им установками и не подхватывает Windows/legacy-развёртывания.

[Настройка режимов, прокси и резервных копий](INSTALL.md) · [Новый Linux helper и отдельная legacy-инструкция](LINUX_INSTALL.md). Обычный HTTP по LAN/публичному IP не даёт браузеру безопасный контекст для камеры, микрофона и демонстрации экрана; для удалённых участников используйте доверенный HTTPS. Прокси сайта не заменяет отдельные медиапорты.

## Начать работу

1. Установите сервер. На Windows распакуйте архив целиком и запустите `EasySetup.exe`. Для Linux используйте [отдельную инструкцию](LINUX_INSTALL.md) либо [установку по SSH из Windows-мастера](GUIDE.md#установить-на-linux-vps-из-windows).
2. Откройте CastLink, создайте студию и пригласите кастеров по ссылке.
3. Добавьте индивидуальные выходы кастеров в OBS/vMix и соберите эфир в привычном ПО.

Docker нужен только на сервере. Кастерам достаточно браузера, HTTPS и разрешений на камеру/микрофон.
