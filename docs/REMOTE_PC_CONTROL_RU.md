# Управление компьютером из браузера

**Обновление демонстрации от 23.10.2026.** Скачайте текущий установщик по ссылке ниже и запустите его повторно, если компонент установлен раньше. Обновление исправляет запуск из браузера в Windows и добавляет плавающую панель управления поверх презентации. Затем обновите страницу комнаты и нажмите «Начать показ». Полный клиент переустанавливать не нужно.

На Windows-компьютере, которым будут управлять, один раз установите [компонент демонстрации CastLink](https://castlink.ru/general/screen-share-component/CastLink-Screen-Share-Setup.exe). Получателю управления достаточно браузера. Владелец компьютера тоже может работать в браузере; локальный компонент выполняет команды Windows в фоне.

1. Нажмите «Демонстрация экрана». Если окно выбора не открылось, нажмите «Скачать компонент демонстрации», запустите установщик и подтвердите установку в Windows. Вернитесь в комнату и нажмите «Начать показ». Подтвердите открытие CastLink, если браузер попросит об этом.
2. В окне выбора укажите экран или окно программы. После начала показа поверх приложений появится компактная панель управления. Она остаётся доступной при переходе к PowerPoint или другой программе.
3. В плавающей панели выберите другого кастера и нажмите «Передать управление ПК». Управление включается без второго запроса или кнопки «Принять».
4. Получатель нажимает на видео, чтобы направить туда мышь и клавиатуру. Для отправки текста есть меню «Ввод ПК».

Для передачи и отзыва управления вкладка комнаты должна оставаться открытой и подключённой. При потере её связи панель отключает эти действия; локальная остановка показа остаётся доступной.

Местные мышь и клавиатура продолжают работать. Курсор общий. При показе отдельного окна видно только это окно; передача управления включает доступ к клавиатуре ПК. Для работы с несколькими программами выбирайте весь экран.

«Забрать управление ПК» отключает удалённый ввод и сохраняет показ. «Остановить показ экрана» завершает показ и управление. На управляемом ПК сочетание **Ctrl + Alt + Shift + F12** останавливает демонстрацию. При потере связи ввод приостанавливается; перед продолжением отпустите клавиши и кнопки мыши.

Открытый PowerPoint продолжает работать на компьютере владельца с его эффектами. Загружать или преобразовывать презентацию для полного управления ПК не требуется. Полный клиент для работы в браузере не требуется. Компонент запускается только для демонстрации и завершается после её остановки или отмены выбора. Автозагрузки и постоянно работающей службы нет. При недоступности сервера ввод отключается сразу по сроку разрешения, а через30секунд компонент завершает показ. Пока выбираете источник, действует предел ожидания120секунд. Установка не запускает демонстрацию автоматически; после неё нажмите «Начать показ».
