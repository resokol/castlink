# Управление компьютером из браузера

На Windows-компьютере, которым будут управлять, установите [компонент CastLink](https://castlink.ru/general/remote-pc-control-762f5c33af5c/CastLink-Client-1.0.0-rc.8-762f5c33af5c-setup.exe). Получателю управления достаточно браузера. Владелец компьютера тоже может работать в браузере; локальный компонент выполняет команды Windows в фоне.

1. Нажмите «Демонстрация экрана». Подтвердите открытие CastLink, если браузер попросит об этом.
2. В окне выбора укажите экран или окно программы. После начала показа откроется панель управления.
3. Выберите другого кастера и нажмите «Передать управление ПК». Управление включается без второго запроса или кнопки «Принять».
4. Получатель нажимает на видео, чтобы направить туда мышь и клавиатуру. Для отправки текста есть меню «Ввод ПК».

Местные мышь и клавиатура продолжают работать. Курсор общий. При показе отдельного окна видно только это окно; передача управления включает доступ к клавиатуре ПК. Для работы с несколькими программами выбирайте весь экран.

«Забрать управление ПК» отключает удалённый ввод и сохраняет показ. «Остановить показ экрана» завершает показ и управление. На управляемом ПК сочетание **Ctrl + Alt + Shift + F12** останавливает демонстрацию. При потере связи ввод приостанавливается; перед продолжением отпустите клавиши и кнопки мыши.

Открытый PowerPoint продолжает работать на компьютере владельца с его эффектами. Загружать или преобразовывать презентацию для полного управления ПК не требуется. Старому Windows-клиенту потребуется это обновление; сервер и компьютеры получателей переустанавливать не нужно.
