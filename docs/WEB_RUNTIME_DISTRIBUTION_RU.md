# Серверный образ для распространения

Dockerfile.web разделён на builder и runtime. В builder выполняются прежние pnpm install/Next build. В финальный образ копируются только Next standalone, браузерные static-файлы, необходимые операторские MJS, SQL-миграции и лицензии. Сервер запускается `node apps/web/server.js`, без pnpm. Версия берётся из прежнего BUILD_ID; пути `/app/scripts` и `/app/infrastructure` сохранены.

Next явно включает pg в трассируемые production-зависимости. Сборочный TypeScript-компилятор исключается из финального набора; исходные `apps/web/app`, `components`, `lib`, `tests`, конфигурация TS и локальные `.studiolink-data` не допускаются. Подготовка сохраняет сторонние LICENSE/NOTICE/COPYING рядом с трассируемыми зависимостями. Стандартный Node base и сторонний Next по-прежнему содержат собственные программы; их лицензии сохраняются.

Операторские файлы сохраняются без изменения байтов: миграции PostgreSQL/control-plane, seed, регистрация узла, import, legacy owner/observer/startup, heartbeat, backup/restore и их зависимости. Никаких migrations/seed или действий на пользовательском ПК/VPS эта подготовка не выполняет.

Локальные проверки: настоящий production Next build; независимый standalone вне checkout, без зависимости от его node_modules; Next/pg разрешаются, TypeScript не разрешается; `/`, `/api/setup`, `/api/version` отвечают HTTP200 с точным buildId. Подготовка/лицензии/операторские байты/отказ при наличии исходников или локальных данных проверены двумя тестами. Smoke финального Docker-образа добавлен в CI перед упаковкой: отсутствие исходных директорий, наличие зависимостей и операторских import-файлов, HTTP version/main, затем удаление только своего временного контейнера. Полная контейнерная сборка этого изменения ещё ожидает приватного CI; локальный Docker build не выполнялся из-за объёма vfs/свободного диска.

Скомпилированный JavaScript сервера, клиентский JavaScript, PowerShell установщика, операторские MJS и SQL остаются доступны получателю. Это исключение оригинального дерева разработки из образа, а не защита от анализа программы. Условия новых версий определяются отдельно; прежняя MIT-лицензия и выданные ею права не отзываются.
