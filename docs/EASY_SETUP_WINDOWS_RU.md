# CastLink Easy Setup для Windows 10–11

Один мастер устанавливает сервер CastLink на этот компьютер или на Linux VPS. Он загружает текущий опубликованный выпуск из публичного репозитория [resokol/studiolink](https://github.com/resokol/studiolink/releases). Учётная запись GitHub и токен не нужны.

## Состояние — 7 октября 2026

Новый упрощённый мастер находится в разработке. Описанный ниже сценарий — согласованное поведение продукта; полная установка этим мастером на Windows и Linux VPS ещё не подтверждена. Первый публичный выпуск с двумя пакетами ещё предстоит опубликовать. Проверки прежнего CLI не подтверждают работоспособность нового мастера.

## Скачать и запустить

1. Открой Releases и скачай `CastLink-Windows.zip` из актуального выпуска Easy Setup.
2. Распакуй всю папку и запусти `EasySetup.cmd`.
3. Выбери установку на этот компьютер или на Linux VPS.

Мастер проверяет контрольную сумму скачанного пакета по `SHA256SUMS`. Один выпуск содержит Windows-пакет мастера и Linux-пакет сервера `CastLink-Linux.tar.gz`; версии серверного приложения в них совпадают. Linux-пакет для VPS мастер получает сам.

Если выпуск отсутствует или загрузка не удалась, установка должна сообщить причину. Исходники ветки и артефакт незавершённой CI-сборки не считаются опубликованным выпуском.

## Установка на этот компьютер

1. Выбери доступ внутри локальной сети или через публичный IP.
2. Проверь обнаруженный IP компьютера, при необходимости измени его и укажи папку установки.
3. Мастер проверит необходимое ПО. Если Docker Desktop отсутствует, предложит скачать и установить его; установленный Docker запустит автоматически. Windows может запросить права администратора, включение WSL2 или перезагрузку. После перезагрузки снова открой мастер.
4. Мастер скачает пакет, подготовит настройки, запустит службы и базу данных.
5. В конце он покажет адрес сервера, доступ владельца и краткие инструкции. Для локального HTTPS предложит добавить сертификат этого сервера в доверенные на текущем ПК.

Белый IP для локальной сети не требуется. Открывай адрес сервера с устройств в той же сети. На других устройствах также потребуется доверие локальному сертификату, чтобы браузер разрешил камеру и микрофон. Импорт сертификата выполняется с подтверждением владельца устройства.

Для доступа из интернета нужен доступный извне адрес; если ПК находится за роутером, потребуется проброс портов. Выбор публичного режима сам по себе не создаёт белый IP и не меняет настройки роутера. Доверенный публичный HTTPS по домену требует корректной DNS-записи и доступности сервера для выпуска сертификата.

Docker нужен на компьютере, где работает сервер. Участники открывают CastLink в браузере и ничего не устанавливают. Мастер использует существующий Docker Desktop и сохраняет его данные и выбранное место хранения виртуальной машины.

## Установка на Linux VPS

1. Выбери внешний сервер и введи его IP, SSH-порт, логин `root` и пароль. Пароль вводится скрыто и используется в памяти во время подключения.
2. При первом подключении проверь показанный SSH fingerprint сервера.
3. Укажи домен. Файлы мастера сохраняются в выбранной Windows-папке; сервер размещается в отдельной собственной папке /opt/castlink-easy-<идентификатор>. Поддерживаемый первоначальный сценарий — Ubuntu 22.04 или 24.04, x86_64.
4. Мастер проверит доступ, предложит установить недостающие зависимости, загрузит Linux-пакет и развернёт приложение.
5. После успешной установки он покажет адрес сервера и доступ владельца. Docker Desktop на Windows для установки на VPS не требуется.

В DNS-панели создай A-запись домена на IP VPS. Мастер настраивает домен в сервере, но изменение DNS у регистратора требует доступа к его панели. Неверная AAAA-запись при неработающем IPv6 может мешать открытию сайта и выпуску сертификата.

Для HTTPS и прямого медиасоединения нужны TCP 80, 443, 7881 и UDP 61000–61100. Сохрани доступ к SSH. Если провайдер ограничивает входящие подключения, разреши эти порты в его панели. TURN пока не входит в этот сценарий: из некоторых сетей с ограничениями прямое медиасоединение может не работать.

## Настройки и доступ владельца

Настройки установки сохраняются в выбранной папке; внутренние файлы `payload/release.json` и `.castlink-install.json` мастер заполняет сам. Вводить профили, пути к манифестам и отдельные команды подготовки не нужно.

Приглашение владельца даёт доступ к управлению сервером, одноразовое и действует ограниченное время. Не публикуй приглашение, пароли или файлы настроек в GitHub и не отправляй их в чат. Сам факт открытой главной страницы не даёт посетителю права владельца.

## Если установка остановилась

Сохрани сообщение об ошибке и папку установки. Не удаляй данные Docker или существующий сервер ради повторного запуска. Если мастер просит действие Windows, DNS или панели провайдера, выполни указанное действие и затем продолжи установку. Сообщение о скачивании пакета или запуске Docker ещё не означает готовность CastLink.

## Проверка выпуска

Разработку и интеграцию ведёт GPT-6.1 Sol High. Фактический результат запуска на Windows, развёртывания служб, HTTPS и входа владельца фиксируется отдельно после выполнения проверок. Поддержка Windows 10–11 является целью нового мастера; проверка на одной версии Windows не заменяет проверку другой.
