# CastLink: руководство с нуля

Это руководство для человека, который умеет пользоваться компьютером, но ещё не программировал. Его можно читать по порядку, а можно открывать нужную главу перед конкретной работой.

**Область описания:** CastLink `1.0.0-rc.8`, актуализация 25.10.2026. Пользовательские пакеты и установка: [продукты](../distribution/PRODUCTS.md), [установка](../distribution/INSTALL.md), [standalone Linux](../distribution/LINUX_MANUAL.md). Подтверждённые версии web, Windows Client и серверных пакетов перечислены в [WORKING_STATE_RU.md](WORKING_STATE_RU.md); у направлений независимые сборки. У своего сервера сверяйте `/api/version`.

Наличие функции в руководстве или Git не означает, что она установлена на каждом сервере. Сопоставляйте исходники, опубликованный пакет и работающий runtime отдельно.

Глава [07 · Приёмка](manual/07_ACCEPTANCE_RU.md) и [аудит RC-2](RC2_RELEASE_AUDIT_RU.md) сохранены как исторические свидетельства той версии. Они не определяют текущую готовность или текущие ограничения.

## Самое важное правило

У проекта есть **код**, **работающие процессы** и **данные**. Это разные вещи. Изменение файла на GitHub не меняет запущенный контейнер. Перезапуск контейнера не обновляет таблицы PostgreSQL. Откат образа не возвращает вчерашнюю БД. Большинство опасных ошибок начинается с путаницы между этими тремя понятиями.

## Что это руководство не обещает

Оно не превращает шаблон установки в гарантированный запуск на любом компьютере. Браузер может не поддерживать захват экрана, устройство может не разрешить камеру, домашняя сеть может не пропускать входящие соединения. Эти ограничения нужно диагностировать, а не маскировать зелёным статусом.

Каталог охватывает файлы, входящие в данную версию репозитория, включая тесты, инфраструктуру, документацию и заготовки нативных приложений. Он не раскрывает реальные `.env`, приватные ключи, токены и содержимое production БД. Каталог импортов — статическая карта кода; отдельные связи по HTTP, событиям LiveKit и SQL разобраны в главе 03.

Старые датированные документы и разделы «планируется» остаются историей. При противоречии сначала смотрите текущий код, тест, номер сборки и это руководство, а не обещание из старого плана.

Новые операции нод и диагностика: [RC2_OPERATIONS_FEEDBACK_RU.md](RC2_OPERATIONS_FEEDBACK_RU.md). Сверка отложенных задач: [ISSUE_AUDIT_RC2_OPERATIONS_RU.md](ISSUE_AUDIT_RC2_OPERATIONS_RU.md).

Опубликованный standalone Linux-пакет использует `scripts/linux-compose-setup.py`: `init`, `start`, `status`, `check-updates`, `update` и `creation-password` с прежним `--state-dir`. Новый `init` скрыто спрашивает отдельный пароль создания комнат; для автоматизации предусмотрен `--room-creation-password-file`. Папку существующей установки нельзя заменять новым примерным путём. Исследовательский TypeScript [apps/cli](CLI_SELF_HOSTED_RU.md) — другой инструмент с собственными границами проверки; его старые milestone не описывают готовность опубликованного Linux-пакета.
