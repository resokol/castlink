# CastLink: руководство с нуля

Руководство объясняет устройство проекта и работу с его исходниками. Пользовательские пакеты описаны отдельно: [продукты](../distribution/PRODUCTS.md), [установка](../distribution/INSTALL.md), [standalone Linux](../distribution/LINUX_MANUAL.md).

Наличие функции в исходниках не означает, что она уже установлена на каждом сервере. У Windows Client, Server Setup и Linux независимые сборки; у своего сервера проверяйте `/api/version`.

## Код, процессы и данные

Git хранит **код**, сервер выполняет **процессы**, а комнаты и настройки находятся в **данных**. Изменение файла не обновляет запущенный контейнер. Перезапуск контейнера не применяет все миграции PostgreSQL. Откат образа не возвращает прежнюю БД.

Каталог файлов охватывает исходники, тесты, инфраструктуру и документацию. Он не содержит `.env`, приватные ключи, токены или данные работающих установок. Карта импортов статическая: связи по HTTP, LiveKit и SQL разобраны в главе 03.

## Linux и исследовательский CLI

Готовый standalone Linux-пакет использует `scripts/linux-compose-setup.py`: `init`, `start`, `status`, `check-updates`, `update` и `creation-password`. Для существующей установки сохраняйте прежний `--state-dir`. Новый `init` запрашивает отдельный пароль создания комнат; для автоматизации предусмотрен `--room-creation-password-file`. Recovery задаёт только отсутствующую настройку и не перезапускает службы.

Исследовательский TypeScript [CLI](CLI_SELF_HOSTED_RU.md) — отдельный инструмент. Его контракты и ограничения не описывают готовность standalone Linux-пакета.

## Границы руководства

Описания настройки не означают гарантированный запуск на любом оборудовании. Захват экрана зависит от браузера и ОС, камеры — от разрешений и устройств, подключение — от сети и HTTPS. Сопоставляйте документацию с кодом, тестами и номером фактически используемой сборки.
