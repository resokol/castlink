# CastLink: руководство с нуля

Это руководство для человека, который умеет пользоваться компьютером, но ещё не программировал. Его можно читать по порядку, а можно открывать нужную главу перед конкретной работой.

**Область описания:** исходный код CastLink `1.0.0-rc.2` с исправлениями обратной связи RC-2 в этой ветке. Наличие функции в руководстве или Git **не означает**, что она уже установлена на публичном сервере. Реальную сборку проверяют через `/api/version`. Проверки и ограничения этой итерации перечислены в [отчёте проверки](manual/07_ACCEPTANCE_RU.md).

Актуальная проверка RC-2, изменения и незавершённые issues: [отчёт перед совместным выпуском](RC2_RELEASE_AUDIT_RU.md).

## Самое важное правило

У проекта есть **код**, **работающие процессы** и **данные**. Это разные вещи. Изменение файла на GitHub не меняет запущенный контейнер. Перезапуск контейнера не обновляет таблицы PostgreSQL. Откат образа не возвращает вчерашнюю БД. Большинство опасных ошибок начинается с путаницы между этими тремя понятиями.

## Что это руководство не обещает

Оно не превращает шаблон установки в гарантированный запуск на любом компьютере. Браузер может не поддерживать захват экрана, устройство может не разрешить камеру, домашняя сеть может не пропускать входящие соединения. Эти ограничения нужно диагностировать, а не маскировать зелёным статусом.

Каталог охватывает файлы, входящие в данную версию репозитория, включая тесты, инфраструктуру, документацию и заготовки нативных приложений. Он не раскрывает реальные `.env`, приватные ключи, токены и содержимое production БД. Каталог импортов — статическая карта кода; отдельные связи по HTTP, событиям LiveKit и SQL разобраны в главе 03.

Старые датированные документы и разделы «планируется» остаются историей. При противоречии сначала смотрите текущий код, тест, номер сборки и это руководство, а не обещание из старого плана.
