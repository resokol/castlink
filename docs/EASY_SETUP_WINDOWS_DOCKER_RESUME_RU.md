# Easy Setup: продолжение после подготовки Docker — 12.10.2026

В исходном мастере выбор папки и адреса сохранялся только после подготовки Docker и загрузки выпуска. Запрос перезагрузки WSL/Docker превращался в обычный отказ без checkpoint; повторный запуск начинал вопросы заново. Установленный, но закрытый Docker уже проверялся отдельно от отсутствующего приложения, однако результат успешного установщика не сохранялся между запусками.

Теперь `.castlink-setup-pending.json` в выбранной папке сохраняет только локальные параметры, этап подготовки, согласие на Docker и признаки запроса перезагрузки. Пароли, SSH-данные и токены в формате отсутствуют. Указатель текущего незавершённого мастера хранится в пользовательском LocalAppData/CastLink; при обычном запуске предлагается продолжить. Отказ возвращает выбор действий и сохраняет checkpoint папки. Явный выбор внешнего сервера/удаления не использует локальный checkpoint.

Установщик с кодом 3010/1641 не запускается повторно до перезагрузки. После перезагрузки мастер проверяет уже установленное приложение и запускает закрытый Docker Desktop; отсутствие Linux engine не означает отсутствие установленного Docker. Pending-переход компонентов WSL/VirtualMachinePlatform требует перезагрузку отдельным состоянием. После успешного установщика и отсутствующего приложения повторная установка блокируется с пояснением. Подпись Docker и проверка Linux engine сохраняются. Официальный подписанный файл установщика можно повторно использовать без скачивания.
