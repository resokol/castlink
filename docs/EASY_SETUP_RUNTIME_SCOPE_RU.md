# Область видимости runtime в Easy Setup

`Find-Desktop` и другие функции runtime нужны не только при подготовке Docker, но и позже при учёте зависимостей. Загрузка helper внутри `Prepare-SimpleLocalInstall` оставляла их в локальной области функции. После её возврата установка отказывала с «Find-Desktop не распознано».

Исправление загружает helper с определениями функций в области входного скрипта. Сам импорт не запускает и не устанавливает Docker. Он доступен и в обычном запуске, и после перехода к текущему скачанному пакету.

Регрессия исполняет настоящий `Start-SimpleSetup` в свежем GUI runspace, до границы импорта образов. Системные и сетевые операции заменены безопасными заглушками; подготовка и последующий учёт зависимостей исполняются. Прежний входной скрипт воспроизводит отказ, исправленный доходит до ожидаемой границы. Проверяются прямой запуск и переход в скачанный пакет. Та же проверка включена в Windows PowerShell 5 job выпуска.

Запуск установки на пользовательском ПК этой проверкой не выполняется; комнаты, службы и данные не меняются.
