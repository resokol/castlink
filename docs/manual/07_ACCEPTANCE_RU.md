## Что проверено в этой итерации

Исходная установленная сборка при read-only проверке: `1.0.0-rc.2-368d65f75e19`. Исправления выполняются в отдельном worktree/ветке `fix/rc2-feedback`. Изменение ветки само по себе не является обновлением production.

Локальные проверки: TypeScript PASS; полный список стабильных тестов — 76/76 PASS (включая проверку ссылок и актуальности каталога) с Git Bash в PATH. Проверены математика поворота, тихий уровень -80 dBFS, плавное падение индикатора, суммарный бюджет simulcast, one-use access, отзыв, запрет платформенного входа обычным ролям и слияние topology без скрытого изменения assignment.

Production build локально выполнялся успешно. После последнего изменения исходников перед релизом требуется повторный build/CI именно конечного SHA. Изменять код во время сборки и затем приписывать её успех новому SHA нельзя.

## Что означает браузерная проверка

Firefox 157 выполнил 24 сценария на точных viewport 390×844 и 1440×900: 1/2/4 карточки, повороты 0/90/180/270. Использованы реальные CSS проекта/LiveKit и скомпилированный helper вписывания. Источник — синтетический canvas-видеотрек 720×1280 с метками краёв.

Проверены: отсутствие перекрытия области камер footer-ом, зазоры split-кнопок, отсутствие внутреннего scroll для одной карточки, сохранение целого повёрнутого кадра и отсутствие горизонтального scroll страницы.

Это DOM/CSS fixture, а не полноценный звонок на публичном сервере. Физическая камера, реальный RTT/битрейт, фоновые ограничения Android/iOS, акустика и обновление страницы в активном эфире этим тестом не проверяются.

Воспроизводимый fixture сохранён в `apps/web/tests/conference-layout-browser.py`; нужны Selenium и явно заданные пути Firefox/geckodriver через `CASTLINK_QA_FIREFOX_BINARY` и `CASTLINK_QA_GECKODRIVER`.

Chrome automation на этой Windows-машине не смогла создать сессию: DevToolsActivePort/renderer timeout. Поэтому Chrome не объявляется проверенным. Успешный Firefox-test не подменяет Chrome/Safari acceptance.

## PostgreSQL integration

В CI добавлен `platform-access-postgres.cjs`: миграция 004, пять конкурентных попыток принять одно приглашение, проверка срока, logout, глобальный отзыв и owner CLI с приватным файлом без токена в stdout. Результат нужно смотреть в GitHub Actions для конкретного commit SHA. Для code SHA `d106b14e866c35f5a1e8bd9b68591ff2a6a6098b` GitHub CI run `36934780734` завершился успешно: TypeScript, stable tests, PostgreSQL integration, production build и version API integration. Последующие изменения требуют проверки своего SHA.

Тест отказывается работать с произвольной БД и допускает только явно заданную локальную `castlink_test`. Production database для теста не использовалась.

## Наблюдение production, не исправление routing

Read-only проверка показала, что `studio-default` назначена в центральном реестре на отключённую домашнюю ноду, но на основной ноде есть node-local комнаты этой Studio. В node-local storage комнат больше, чем в центральном room registry.

Новая диагностика показывает observed nodes отдельно от assigned node и не теряет такие комнаты. Назначение в БД намеренно не менялось: это может затронуть маршрутизацию и должно разбираться отдельной проверкой, а не косметическим действием ради согласованной таблицы.

## Ручной release gate

| Сценарий | Ожидаемый результат |
|---|---|
| Обычный гость/модератор/admin/Studio owner открывает platform API | Данные и действия запрещены, bootstrap недоступен |
| Владелец сервера выдаёт первое приглашение | Не требуется Studio; ссылка в приватном файле, не в логах |
| Одну ссылку открывают два клиента одновременно | Входит только один |
| Истёкшая/использованная/старая bootstrap-ссылка | Отказ без SQL/секретов в ответе |
| Logout / глобальный revoke | Соответствующие сессии перестают работать серверно |
| Одна камера на телефоне | Уменьшенный блок без внутреннего scroll, toolbar под видео |
| Несколько камер и прокрутка | Toolbar остаётся под областью камер, не закрывает изображение |
| Portrait/landscape × четыре поворота × Studio/fullscreen/output | Все углы кадра видны, пропорции сохранены |
| Отмена screen share | Временная ошибка скрывается, камера и микрофон не меняются |
| 2500 → 5000 → 8000 кбит/с | Меняется encoder budget отправителя, отображается реальный замер; CBR не обещается |
| Тихий сигнал, речь, mute, republish | Нет ложного визуального gate; аудиометр не создаёт второй слышимый поток |
| Недоступная нода | Неизвестные значения и свежесть, а не выдуманный ноль |
| Новая комната вне центрального registry | Видна в node topology с правильной Studio/нодой |

Полный soak, живой перенос, аварийный Force Offline и измерение end-to-end задержки после этого патча остаются отдельными тестами. До их выполнения нельзя объявлять отсутствие всех регрессий или закрывать все медийные задачи только по unit-тестам.
