# Guided media: граница совместимости исходников CLI

Это описание исходников preview, а не подтверждение опубликованного образа или проверки медиа в браузере. Встроенный запуск guided media через `doctor`, доверенный браузерный probe и проверка Docker Desktop в этот срез не входят. Интеграция содержит серверные маршруты и библиотеки CLI для диагностической комнаты, приватных артефактов и фиксированного target transport.

Сервер и CLI используют `castlink-media-room-v2`: receipt содержит точные `creationId` и `revision`. Создание/удаление диагностической комнаты требует серверной авторизации и совпадающей revision. Изменение комнаты оператором сбрасывает diagnostic revision; последующая очистка отказывает и сохраняет комнату, её данные и управление студией. Старый receipt из трёх версий доступа не принимается. Приватные cookie, приглашения и доказательства не предназначены для вывода в журнал.

Установочный контракт базы требует room migrations `[1,2,3]` и control migrations `[1,2,3,4,5]`. Миграция `003_diagnostic_room_revision.sql` сохраняет версии доступа обычных комнат и добавляет nullable diagnostic metadata. Её SHA256 — `a3e5269441170af5446bb36d034eaa79053cd141f5fdd0ee6832de3da750eeaa`; bootstrap manifest SHA256 — `60d91f93b3c09c1c970d07670db401860d189656a542c2b0c03cce47c4ef1a4f`; fingerprint фактической схемы — `9ac1882f21b90a315d2267155b703a4b1329528fd76623fdbd3438b6ac12a8b0`.

Завершённый bootstrap со старым manifest не становится совместимым от обновления CLI. Установочный helper и readonly observer отказывают при несовпадении сохранённого content hash или схемы. Этот preview не выполняет автоматическую миграцию завершённой установки, повторный seed, замену installation ID или восстановление доступа владельца. Изменение существующей установки требует отдельной согласованной процедуры обновления и подходящего образа. Новый полный образ этого среза здесь не собран и не проверен.

Фиксированные mutating transport helpers сохраняют frozen principal/scope/engine/endpoint/epoch и берут shared target lease до эффекта. Неизвестный исход сохраняет неопределённость и запрещает автоматический повтор. Диагностические измерения из внедряемого browser probe не дают media PASS: доверенный встроенный браузерный runner остаётся отдельной работой.
