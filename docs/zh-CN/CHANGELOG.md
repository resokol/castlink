# CastLink 更新日志

以下说明适用于所列版本的已构建安装包。新功能在相应构建发布后才会记录在此处。

## [快速/高级安装与独立 Linux 辅助程序](https://github.com/resokol/castlink-releases/releases/tag/easy-setup-31a402442fe1) · 2026-10-20

### 新增与调整

- Windows Easy Setup 提供快速与高级模式：直接 HTTPS、HTTP 或外部 HTTPS 代理，独立网站/媒体地址与端口，以及明确的可信代理列表。向导与管理窗口支持 RU/EN/简体中文。
- 新独立 Linux 辅助程序：`init`、`validate`、`start`、`status`、`backup`、`update`。持久化 `--state-dir` 保留状态、密钥、UUID、网络及卷名称。
- 修复在 Windows 上构建发行包时的 Linux 脚本打包，确保可执行程序保留 Unix 换行符。

### 更新操作与限制

请备份数据和配置，并在非直播时段更新：服务与媒体连接会中断。Windows 向导更新所选原有安装；Linux 辅助程序使用原有 `--state-dir`，切换前制作一致备份。它不接管 Windows/legacy 安装，不会自动回滚数据库。

常规媒体应保留 TCP 7881、UDP 7882、UDP 3478 和 UDP 30000–30031；高级模式使用所配置的端口。LAN/公网 IP 上的 HTTP 不提供摄像头、麦克风或屏幕共享所需的安全上下文。外部代理应另外验证 HTTPS 与媒体连接。TURN/TLS 仍仅按直接公共 HTTPS、80/443 和独立 TURN 域名的流程配置。详见 [INSTALL](INSTALL.md)、[Linux](LINUX_INSTALL.md)、[TURN/TLS](TURN_TLS.md)。

## [CastLink 1.0.0-rc.3 · 构建 776AF9](https://github.com/resokol/castlink-releases/releases/tag/easy-setup-451694566045) · 2026-10-18

### 新增与修复

- 固定参与者槽位：演播室、管理员或版主可创建槽位、关联邀请并分配已连接的嘉宾。带音频的摄像头输出和带音频的屏幕共享输出具有各自的固定链接，可提前添加到 OBS/vMix。
- 更改槽位名称、邀请或所分配的嘉宾会保留输出 URL。重新签发链接是独立操作；删除槽位后其输出不可用。
- 嘉宾正常进入房间，无需等待版主批准。分配槽位仅控制固定输出，不是入场条件；替换或清除分配不会断开嘉宾连接。
- 恢复按原有权限从演播室房间设置发出管理员和版主邀请。无需单独登录服务器所有者或设置新密码；这些角色仍仅作用于房间。
- 设备检查页会在加入房间前请求并启动摄像头和麦克风，同时遵守邀请设置及浏览器权限。拒绝一个设备不会阻止检查另一个；授予权限后会刷新设备列表。
- 修复短暂断线后恢复同一嘉宾会话，以及续期连接时保留会话设置的问题。已撤销邀请不能用于重新入场，被明确移除的参与者也不能通过重连绕过访问限制。
- 多画面编辑器新增用于放置单元格的辅助网格：可开启或关闭，并将间距从大格调整到小格。网格仅显示在编辑器中，不会出现在已发布的输出中。
- 保留实验性多画面的网格与自由布局、16:9/4:3 场景、独立槽位比例、导入导出及透明输出，以及新邀请默认设置、嘉宾取景和备用服务器区域。
- 以及其他细微调整。

### 更新与限制

备份数据和配置后，使用新的 Easy Setup 安装包更新原有安装。请安排非直播时段：安装程序会重新创建 LiveKit，当前媒体连接将中断。更新保留房间和数据；支持 PostgreSQL 和 JSON 存储，新增槽位结构时不会删除原有记录。历史兼容迁移仍然保留；请勿通过删除数据库表回退。若原构建早于 f120f6，请先遵守下文端口要求。演播室中仅更新 web 的操作不会更改这些端口。

将使用中的备用服务器更新到兼容版本，重新准备并测试迁移。更新后请在非直播时段重新打开界面，并用自己的设备及 OBS/vMix 测试邀请、重连和固定输出。自动化及浏览器检查不能替代这些测试；本版本不声称兼容所有实体摄像头、手机和接收软件。多画面仍为实验性功能；演示文稿暂时关闭，首次连接回声仍在调查中。

## [CastLink 1.0.0-rc.2 · f120f6](https://github.com/resokol/castlink-releases/releases/tag/easy-setup-f120f6442145) · 2026-10-17

### 新增与调整

- 工作室新增实验性多画面编辑器：支持网格和自由布局、移动和调整画面槽位、对齐辅助线、独立取景、圆角，以及视频缺失时的统一占位图。场景可以复制、删除、导出和导入。导入后需要重新分配来源。独立输出链接为 OBS/vMix Browser Source 提供透明背景；通过“应用”发布场景修改。
- “自定义房间”可以设置新邀请的入场选项：进入时关闭麦克风、仅音频且入场时不启用摄像头，以及禁止嘉宾相互收听。保存设置不会更改已发出的邀请链接或已连接的会话；请发出新邀请。
- 工作室中的嘉宾取景立即变化并自动保存。视频旁的紧凑面板提供缩放、位置、旋转、镜像和裁剪的滑块与精确数值输入。这些调整只影响工作室和独立视频输出的显示，不会重新编码嘉宾的原始视频流。多画面槽位使用独立设置。
- Studio Return 可以使用黑色背景代替摄像头。输出静音也会静音 `/watch` 和屏幕共享；音量表会反映该静音状态。个人监听独立控制。
- 房间迁移、紧急备用和房间服务器集中到侧栏的“备用服务器”项目。
- 以及其他细微调整。

### 修复

- 修复房间迁移到其他服务器后新嘉宾的连接问题。
- 自由布局的多画面槽位在调整大小时保持来源比例。视频和占位图按场景边界裁切，编辑器与输出的圆角显示一致。
- Easy Setup 减少了 Docker 映射的 UDP 端口数量。以前过宽的端口范围可能启动数千个 Docker 转发进程，耗尽服务器内存并导致网站出现 502 错误。

### 更新现有服务器

1. 更新前，请在云服务商网络防火墙和服务器系统防火墙中允许 **UDP 7882**。如果服务器位于路由器后，还需要转发此端口。保留 **TCP 80/443/7881**、**UDP 3478**，并允许 **UDP 30000–30031**。保持 SSH 端口可访问。可选 TURN/TLS 使用 **TCP 443** 和独立 TURN 域名。
2. 备份数据与配置。完整解压新的 Windows 安装包，运行 `EasySetup.exe`，选择“更新”并选中原有安装：相同的本地目录或 VPS。手动 Linux 指南仍固定使用较早的 `easy-setup-8b02e2d4dc3c` 版本：请勿将其中的标签和校验和替换为 `latest`。如需将 VPS 迁移到新的 Easy Setup 端口配置，请通过 SSH 使用新的 Windows 向导。
3. 请在非直播时段更新：安装程序会重新创建 LiveKit 容器以应用媒体端口，因此当前媒体连接会中断。更新现有安装会保留数据；无需删除安装或数据卷。
4. 更新后，请从实际使用的网络检查网站、新嘉宾连接、音视频、独立输出、`/watch` 和已配置的备用服务器，并在浏览器中打开更新后的界面。

新的 Easy Setup 端口配置为：直连媒体 **UDP 7882 / TCP 7881**，TURN **UDP 3478**，TURN relay **UDP 30000–30031**。它取代原来的媒体范围 **UDP 61000–61100** 和 relay 范围 **UDP 30000–30999**。外部防火墙和路由器转发需独立于 Docker 配置；仅下载新 ZIP 不会更新服务器。

**工作室中备用服务器面板的“更新”按钮仅更新 web 应用**，不会重新创建 LiveKit，也不会将现有安装迁移到新媒体端口。请使用新安装程序完成这次迁移。自定义安装请核对实际配置。

### 多画面的限制

多画面仍为实验性功能：最多 16 个场景、32 个槽位，不保证所有设备均能达到相同性能。建议从 2×2 网格开始。场景保存在当前服务器，不会自动迁移到备用服务器；导出/导入可转移构图，但需要重新分配来源。输出链接可访问房间媒体，请仅提供给可信的节目接收方。浏览器可能需要用户点击后才能播放声音。正式直播前，请测试自己的摄像头、网络和接收软件。

## CastLink 1.0.0-rc.2 · 构建 73feb7

### 修复
- 更新备用 VPS 时显示下载、校验和解压进度。读取清单不再需要完整解压大型压缩包。
- 改进了有关自动备用切换兼容性，以及更新后需要重新准备备用服务器的提示。
- 修复了 Windows 控制面板中启动和停止服务的计时器。
- 更新桌面图标时会考虑 Windows 缓存。
- 提高了构建安装包时对临时网络故障的容错能力。

### 新增与变更
- 可删除已保存的备用服务器或迁移目标服务器连接。这不会删除 VPS 上的 CastLink 和数据。
- 安装程序中明确区分了安装（«Установить»）、更新（«Обновить»）和卸载（«Удалить»）。
- 增大安装程序和控制面板窗口，显示的构建编号缩短为六个字符。

### 更新
更新本地 CastLink 和备用服务器，然后重新准备备用服务器。直播前请在自己的网络中测试迁移。音视频实际恢复时间取决于网络和浏览器；这些改进不代表保证在 60 秒内完成切换。

[版本文件](https://github.com/resokol/castlink-releases/releases/tag/easy-setup-73feb70deae3)

## CastLink 1.0.0-rc.2 · 构建 76bb47

### 变更
- 本地安装完成后，运行中的服务会交由 CastLink 控制面板管理，无需在最后一步强制停止。
- 关闭窗口会将控制面板隐藏到系统托盘，服务器继续运行。
- 控制面板提供独立的服务启动和停止按钮。停止并退出（«Остановить и выйти»）命令会停止服务并关闭控制面板。
- 启动安装程序和控制面板时会隐藏辅助 PowerShell 窗口；所安装的版本支持时，Docker Desktop 会在后台启动。

### 新增
- 安装程序和控制面板显示应用版本及构建编号。

### 更新
通过向导在现有安装上安装新包。CastLink 不会设置为随 Windows 登录自动启动：请使用 CastLink 快捷方式启动。停止服务会保留安装数据。

历史版本，下载已隐藏。

## CastLink 1.0.0-rc.2 · 构建 6b269d

### 新增
- 可从演播室控制面板的服务器区域更新已连接的 VPS。
- 更新前检查服务器状态及维护模式。
- 保留安装数据并验证更新结果；发生错误时，可恢复原配置。

### 使用方法
先更新用于管理服务器的电脑上的 CastLink。打开房间服务器（«Серверы комнаты»），选择服务器，然后点击更新（«Обновить»）。完成后重新准备备用服务器。

请在直播之外安排服务器更新。更新具体 VPS 时，需检查其资源、网络和当前连接。

历史版本，下载已隐藏。

## CastLink 1.0.0-rc.2 · 构建 81e386

### 新增
- 为 NAT 后的本地服务器准备自动备用切换：主服务器向备用服务器建立出站连接。
- 监控主服务器可用性，并传递已准备好的备用服务器状态。

### 变更
- 将自动备用切换测试分支的变更合并到主发布分支。
- 统一应用、网站和 Windows 安装包的图标。

### 测试前
在主服务器和备用服务器上安装兼容版本，重新准备备用服务器并启用自动切换。两台服务器及浏览器都需要访问互联网。单个 caster 断线不应触发整个房间迁移。

60 秒内恢复的目标需要在实际直播链路中测量；此版本并未确认所有网络都能满足该保证。

历史版本，下载已隐藏。

## CastLink 1.0.0-rc.2 · 构建 687e80

### 新增
- Windows 向导和备用服务器连接表单支持使用密码或私有 SSH 密钥连接 VPS。
- 可生成 SSH 密钥，将私钥文件保存在所有者手中，把公钥添加到 VPS，并验证新的连接。
- 网站下载链接旁显示构建版本。

### 配置时请注意
首次添加密钥时，需要有效密码或密钥，并验证服务器指纹。请单独保管生成的私钥，勿交给他人。VPS 现有的登录方式不会被删除。
