# 服务器角色与播出者固定输出

[Русский](../SERVER_ROLES_AND_SLOTS_RU.md) · [English](../en/SERVER_ROLES_AND_SLOTS.md)

播出者通过普通访客链接或个人邀请立即进入房间，保留原有访问验证。进入房间无需主持人批准，也无需分配槽位。

访客启用并允许使用的摄像头和麦克风会在入室前的检查页面自动启动。预览及麦克风电平仅在本地运行，不会自动加入房间。明确关闭的设备保持关闭。权限错误会显示并可手动重试；某一输入不可用不会阻止另一输入。离开检查页面后释放临时采集。

已恢复原有的管理员和主持人邀请功能：工作室 → 房间设置 → 创建管理员链接 / 创建主持人链接。使用房间原有的工作室登录即可。独立的服务器所有者登录、密码表单和服务器访问面板已移除。邀请及撤销沿用原有房间权限；房间管理员可以邀请本房间主持人。

工作室、管理员和主持人可以创建、重命名、分配、释放和删除槽位。每个槽位具有固定的播出者邀请链接，以及供 OBS/vMix 使用的摄像头和麦克风输出链接、屏幕及屏幕音频输出链接。

分配仅改变输出来源。替换、移动或释放播出者不会断开任何人的房间连接或停止发布。空槽位不会显示其他人的视频。同一经过验证的会话重新连接时恢复输出；新的身份需要重新分配。断开访客仍是独立操作，会移除参与者并清空其槽位。

改名、更换邀请绑定及分配其他播出者保留输出 URL。只有明确重新生成摄像头或屏幕链接才会改变对应 URL。重新生成邀请影响后续进入。删除槽位使链接失效；用同名重新创建会获得新链接。房间密码及删除房间的原有撤销规则保留。

ON AIR / OFF AIR 反映已确认的发布状态。摄像头和屏幕来源独立。输出使用原有只读媒体房间订阅；来源选择不是房间内部的保密边界。

首次安装服务器角色和槽位需要迁移 005/006。本次恢复直接进入的修正不新增迁移。更新前备份数据库和 web-data，并通过 /api/version 验证已安装版本。
