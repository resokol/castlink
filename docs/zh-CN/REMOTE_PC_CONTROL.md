# 屏幕共享与电脑控制

被控制的电脑需要更新后的 CastLink 服务器和 Windows 客户端；控制方可以使用浏览器或客户端。此功能已发布；当前安装包见[产品选择](../../distribution/docs/zh-CN/PRODUCTS.md)。

点击屏幕共享按钮，选择屏幕或窗口及可用的音频选项，即可开始共享并显示活动状态。再次点击可停止共享。浏览器使用其原生来源选择窗口。

音频选项取决于浏览器、操作系统和客户端。Windows 客户端支持所选 PowerPoint 应用的声音；此模式不传输系统声音或任意窗口的声音。交出控制权会保留已选择的视频和音频，无需再次选择来源。

## 交出或请求控制权

1. 在被控制的电脑上使用 Windows 客户端进入房间，通过普通按钮开始共享。
2. 在紧凑的悬浮工具栏中打开“控制”菜单，在“交出控制权”列表中选择参与者。参与者必须具有该房间相应的权限。菜单由您手动展开；面板会显示所选来源名称和独立的停止共享按钮。
3. 接收方点击视频本身以启用输入。同时只能有一名控制者；选择其他参与者后，原控制者的权限会关闭。

接收方也可以打开视频旁的“电脑控制”，点击“请求控制电脑”。共享者选择“允许”或“拒绝”。请求本身不会授予权限。批准后，接收方仍需点击视频。

此权限允许操作**整台电脑**的鼠标和键盘。共享单个窗口只限制传输的画面，不会将权限隔离到该应用。操作多个应用时，建议共享整个屏幕。共享者仍可使用本地鼠标和键盘，双方共用光标。

使用输入法、中文或其他文本时，先点击视频，再使用“确认的文本（支持输入法）”和“发送文本”。草稿不会发送。浏览器可能拦截系统保留快捷键。不支持 Windows 安全桌面和 UAC；本功能不包括剪贴板同步或文件传输。

## 暂停与结束

- 共享者的“收回控制权”和接收方的“结束控制”会停止远程输入，保留视频和音频。
- 失去焦点、隐藏标签页、断线或视频几何信息无效时，输入会暂停。恢复后，请松开按住的按键和鼠标按钮，再次点击视频。
- 暂停输入会保留服务器已授予的控制权限。只要共享者未撤销权限，且双方仍在同一会话中，就不需要重新批准。未按住鼠标按钮时将指针移到视频黑边上，以及正常的权限续期，不再重置输入。
- “停止共享”和 **Ctrl + Alt + Shift + S** 会结束共享及控制，通话的摄像头和麦克风保持不变。如果快捷键不可用，请使用按钮。
- 使用“收回电脑控制权”停止输入，使用“停止共享”结束共享。附加快捷键 **Ctrl + Alt + Shift + F8** 未通过自动检查确认触发，原因未知。请勿将其作为断开控制的唯一方式。内置模块结束后，需要停止共享并重新选择来源，才能再次交出控制权。
- 关闭悬浮工具栏只会隐藏它。可以通过“显示停止面板”重新打开。

请保持房间连接。旧客户端仍可普通共享；尝试控制时会说明需要更新。在 CastLink 中生成的 PDF/canvas 演示使用自己的停止控件；电脑控制绑定到客户端中实际选择的屏幕或窗口。
