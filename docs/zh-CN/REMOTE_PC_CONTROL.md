# 在浏览器中控制电脑

**安装程序修复 — 2026 年 10 月 23 日。** 如果已安装组件，但点击“开始共享”后没有任何窗口，请重新下载下方安装程序并运行。本次修复了从浏览器启动组件所需的 Windows 注册。完成后刷新房间页面，再点击“开始共享”。无需重新安装完整客户端。

在被控制的 Windows 电脑上安装 [CastLink 组件](https://castlink.ru/general/screen-share-component/CastLink-Screen-Share-Setup.exe)。控制方只需要浏览器。电脑所有者也可以使用浏览器；本地组件在后台执行 Windows 操作。

1. 点击“屏幕共享”。如果浏览器询问，请确认打开 CastLink。
2. 选择屏幕或应用窗口。共享开始后会打开控制面板。
3. 选择另一位参与者，然后点击“授予电脑控制权”。无需再次请求权限或点击“接受”。
4. 控制方点击视频，将鼠标和键盘输入发送到该电脑。可通过“电脑输入”菜单发送文本。

所有者仍可使用本地鼠标和键盘。双方共用一个光标。窗口共享只显示所选窗口；控制权限包含电脑键盘访问。需要操作多个应用时，请共享整个屏幕。

“收回电脑控制权”会关闭远程输入并保留视频。“停止共享”会同时结束视频和控制。在被控制的电脑上按 **Ctrl + Alt + Shift + F12** 可停止共享。连接中断时输入会暂停；恢复前请松开键盘按键和鼠标按钮。

PowerPoint 在所有者的电脑上继续运行并保留原有效果。完整电脑控制无需上传或转换演示文件。服务器和控制方电脑无需重新安装。

开始共享时，浏览器会提供“下载共享组件”。首次安装后返回房间并点击“开始共享”。下载和安装需要您的操作，无需完整客户端。组件仅在共享时启动，在停止或取消选择后退出，不设置开机启动或常驻服务。服务器授权连续不可用30秒后将结束共享；输入授权仍独立在750毫秒内到期。来源选择的启动等待上限为120秒。安装后不会自动开始共享。
