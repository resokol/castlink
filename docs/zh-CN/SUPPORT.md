# 支持 CastLink

CastLink 可免费使用。如果项目帮助您开展直播，欢迎以您方便的金额支持其开发。感谢您帮助我们新增功能并修复问题！

报告问题时，请提供实际服务器和 Windows Client 的版本（或浏览器名称与版本）、文件格式与大小、错误文本及复现步骤。当前软件包为 `1.0.0-rc.8-bdfe91a92b6b`；更新文档不会更改已安装版本。PDF/PPTX 使用方法请参阅[演示指南](PRESENTATIONS.md)，变更请参阅[更新日志](CHANGELOG.md)。请勿在公开报告中发布服务器密钥或私人文档。
