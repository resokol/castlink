# CastLink — 安装与使用指南

Windows Client 为 **1.0.0-rc.8**，构建 `90135013f5b6`；Windows Server 和 Linux Ubuntu 为 **1.0.0-rc.8**，构建 `72b315b2d251`：[软件包与校验和](PRODUCTS.md)。安装包和 `SHA256SUMS` 必须来自同一产品和版本。

移动端竖屏“平铺”采用两列 16:9 布局。聊天提供 24 个表情，历史与导出仍保存普通 Unicode。“反应”提供七种持续两秒的动画并支持减少动态效果；反应不写入聊天或纯净输出。

重新打开同一邀请时，若仍保存有效的签名会话，可恢复原槽位。第二个标签页相互隔离；其入场被拒绝不会清除第一个标签页的会话。过期或撤销的权限不会恢复。

演播室布局更加紧凑：播放与邀请位于左侧，输出流与传输控制位于右侧。宽窗口可容纳五张嘉宾卡片，图表下方四个等大设置以 2×2 排列。窄窗口保留顺序布局。

Windows EXE 没有数字签名。更新需要用户同意，可能重启应用或服务；请安排暂停直播，并自行保存所需数据。用户服务器不会自动创建备份。正式直播前请验证实际设备、PowerPoint 和文档。

CastLink 是基于浏览器的演播室，可连接 caster（远程嘉宾），在 vMix/OBS 中接收其音视频，并单独观看演播室直播。服务器安装在您的 Windows 电脑或 Linux VPS 上。caster 在浏览器中打开您的地址即可，无需在自己的电脑上安装 Docker。

这里发布官方安装包和使用指南。应用目前处于公开测试阶段：正式直播前，请测试自己的设备、网络和连接恢复。


主播界面提供“窗口”和“平铺”视图。桌面端“窗口”模式的垂直分隔条可调整主摄像头或屏幕与右侧列表的尺寸；有多个信号源时支持指针和键盘操作。嘉宾列表独立滚动，视频比例保持不变。移动端没有分隔条，保留紧凑控件和“更多”菜单。屏幕共享按钮为薄荷绿，共同演示按钮为蓝色。
## 安装模式与服务器地址

rc.8 默认使用快速模式。需要技术选项时，在 Windows 向导中明确启用**高级设置**；独立 Linux CLI 使用 `--advanced`。快速模式使用标准 HTTPS 和默认端口。高级模式支持 HTTP、直接 HTTPS 或外部 HTTPS 代理，以及网站和媒体的地址与端口设置。向导和 Linux CLI 支持 RU / EN / 简体中文。请参阅[安装模式与配置示例](INSTALL.md)。

更新时请选择原有安装：保存的模式、地址、端口、UUID 和密钥不会被新对话框的默认值覆盖。已完成安装的网络结构不会自动更改。快速安装完成后可再添加备用服务器。

代理模式下，浏览器访问外部 HTTPS；代理将所有路径（包括 `/rtc` 和 WebSocket）转发至 CastLink 内部 Caddy。仅信任 **Docker 内 Caddy 实际看到的代理 IP/CIDR**，该地址可能是网关。不要信任所有来源。若代理位于其他主机，应使用其可访问的私有绑定地址而非 localhost，并限制防火墙访问。内部 HTTP 成功并不证明外部 HTTPS 链路可用。

通过 LAN/公网 IP 使用普通 HTTP 不属于摄像头、麦克风或屏幕共享所需的安全上下文。本机 `localhost` 是浏览器的特殊例外，不适用于其他设备。请使用受信任的 HTTPS：公共证书，或在客户端导入自己的 CA。即使选择了非默认 ACME 端口，仍需提供可从外部访问的证书验证路径，详见 INSTALL。

默认媒体端口为 TCP 7881、UDP 7882、TURN UDP 3478 及 UDP 30000–30031。高级模式应开放实际配置的端口。网站 HTTPS 代理不能替代 LiveKit/TURN 或 NAT/防火墙配置；web:3000 与 PostgreSQL 不对外发布。

Linux 工具 `scripts/linux-compose-setup.py` 支持 `init`、`start`、`status`、`check-updates` 和 `update`，使用原有 `--state-dir`。UUID、密钥、网络与卷名保留；不接管 Windows/旧版安装。`backup` 命令已移除；请自行保存所需数据与配置副本。 [Linux](LINUX_MANUAL.md).

## 聊天历史、管理卡片与停止屏幕共享

房间消息在当前服务器保留 24 小时，重新加入或打开界面时会恢复。已有历史不会计为新的未读消息：徽标仅统计聊天关闭期间新收到的消息。打开聊天标签页会清除计数。在统计页面点击“下载聊天 · 24 小时”，即可将过去一天的消息保存为 UTF-8 文本文件。

管理员和版主面板将姓名、麦克风和扬声器置于顶部。嘉宾卡片宽度为 313 px，空间足够时每行可显示五张；窄屏布局会适应可用宽度。需要私密通话时，请使用相应嘉宾卡片上的“私下通话”。

开始屏幕共享后，支持 Document Picture-in-Picture 的 Chrome 或 Edge 会尝试打开红色停止共享面板。若未出现，请点击“显示停止共享面板”。拖动浏览器标题栏可移动窗口。关闭窗口只会隐藏面板，不会停止共享；可以重新打开面板。“停止共享”会结束捕获，使用其他方式结束捕获也会关闭面板。

面板依赖浏览器功能，其可用性、窗口最小尺寸和自动打开行为取决于浏览器；不能保证面板不会出现在捕获的视频中。正式直播前请测试所选捕获模式。如果不支持悬浮窗口，请使用 CastLink 中的常规按钮停止共享。

## 演播室聊天与消息计数

在演播室、管理员面板或版主面板中，从左侧菜单打开“聊天”。选中其他标签页时，聊天徽标显示新收到消息的数量。打开聊天会将其标记为已读，并清除未读计数。

聊天内提供个人“显示未读消息数”复选框，默认开启。选择保存在当前浏览器中，不会更改其他参与者或服务器的设置。

如需删除对话，请在演播室、管理员面板或版主面板中打开聊天，点击“清空聊天”，然后确认“为所有人清空”。这会删除房间内所有参与者（包括嘉宾）的全部当前消息，以及服务器保存的历史记录。此操作无法撤销；如需保留副本，请先从统计页面下载聊天。嘉宾无权清空聊天。延迟加载的历史不会恢复已删除的消息；清空后发送的新消息会保留。

更新服务器后，请在非直播时段重新加载此前已打开的所有演播室、管理员、版主和嘉宾标签页，以便所有参与者获得新的清空功能。

嘉宾聊天窗口的高度有上限：长对话在消息列表内滚动，输入框和发送按钮在电脑与手机上始终可见。

## 固定槽位与嘉宾入场

在演播室创建槽位，命名并关联嘉宾邀请。演播室、管理员或版主可分配已连接的嘉宾、替换或清除分配。将带音频的摄像头和带音频的屏幕共享各自的固定链接复制到 OBS/vMix。更改名称、邀请或嘉宾会保留输出 URL。只有单独重新签发才会更改链接；删除槽位后输出不可用。此类槽位与实验性多画面的布局槽位不同。

进入房间无需分配槽位或单独批准：嘉宾正常连接。更改分配不会断开其连接。加入前的设备检查会自动请求摄像头和麦克风，同时遵守邀请设置及浏览器权限。若一个设备不可用，可独立检查另一个。“加入”按钮仍负责连接房间。

按原有权限从演播室的房间设置发出管理员和版主链接。无需单独登录服务器所有者或设置新密码；邀请仅作用于房间。

## 视频编码与设备更换请求

新建演播室请求 H.264、10,000 kbit/s 和 60 FPS；未保存编码选择的主播使用 H.264。明确保存的设置不变，也不会提高主播的码率或 FPS。浏览器支持时可使用 VP8、VP9、H.264 和 AV1；界面显示所选及实际协商的编码。请求参数不保证实际测得的质量。

在演播室打开对应 caster 的设备控制，提出更换摄像头、麦克风或音频输出的请求。caster 必须在对话框中同意后才会应用，也可以拒绝。已关闭的摄像头或麦克风会保持关闭。选择音频输出需要浏览器支持。

## 演播室中的 caster 卡片

麦克风电平表位于视频下方。设置按网格排列，主要连接统计信息在旁边显示；帮助和硬件详情可单独展开。等待状态和错误仍保持可见。窄屏使用可纵向滚动的布局。

## 多画面、邀请与取景

- 工作室新增实验性多画面编辑器：支持网格和自由布局、移动和调整画面槽位、对齐辅助线、独立取景、圆角，以及视频缺失时的统一占位图。场景可以复制、删除、导出和导入。导入后需要重新分配来源。独立输出链接为 OBS/vMix Browser Source 提供透明背景；通过“应用”发布场景修改。
- “自定义房间”可以设置新邀请的入场选项：进入时关闭麦克风、仅音频且入场时不启用摄像头，以及禁止嘉宾相互收听。保存设置不会更改已发出的邀请链接或已连接的会话；请发出新邀请。
- 工作室中的嘉宾取景立即变化并自动保存。视频旁的紧凑面板提供缩放、位置、旋转、镜像和裁剪的滑块与精确数值输入。这些调整只影响工作室和独立视频输出的显示，不会重新编码嘉宾的原始视频流。多画面槽位使用独立设置。
- Studio Return 可以使用黑色背景代替摄像头。输出静音也会静音 `/watch` 和屏幕共享；音量表会反映该静音状态。个人监听独立控制。
- 房间迁移、紧急备用和房间服务器集中到侧栏的“备用服务器”项目。

多画面编辑器新增用于放置单元格的辅助网格：可开启或关闭，并将间距从大格调整到小格。网格仅显示在编辑器中，不会出现在已发布的输出中。

多画面仍为实验性功能：最多 16 个场景、32 个槽位，不保证所有设备均能达到相同性能。建议从 2×2 网格开始。场景保存在当前服务器，不会自动迁移到备用服务器；导出/导入可转移构图，但需要重新分配来源。输出链接可访问房间媒体，请仅提供给可信的节目接收方。浏览器可能需要用户点击后才能播放声音。正式直播前，请测试自己的摄像头、网络和接收软件。

## 设备检查、角色与私密通话

入场前可分别测试麦克风、摄像头和耳机／扬声器。空间足够时三项测试排列为一行，宽版加入按钮位于下方。Studio Return 可直接通过 ON AIR 开始发布，无需先完成测试，发布期间也可更换设备。同一会话的设置在当前服务器上保留至断开后 15 分钟。

管理员和版主邀请仅作用于本房间。已连接的主播接受角色邀请后，会先停止其嘉宾摄像头、麦克风和屏幕共享，然后在同一标签页中打开管理面板。

只有管理员或版主可发起私密通话；主演播室不提供这些控制。主播按住回复按钮时，仅自己的麦克风会从节目输出中移除。导播麦克风、节目、屏幕共享及其他参与者音频均保持不变。除非此期间又单独将麦克风静音，否则松开后恢复其原先状态。如果无法安全结束，麦克风会保持静音；请检查状态后手动开启。

选择不超过 **1,500,000,000 字节**的 PDF 或 PPTX，等待预览后点击“共享演示”。PPTX 在服务器转换，PDF 在浏览器打开。新上限要求更新服务器和转换器，转换器内存上限为 **2 GiB**，工作磁盘至少有 **8 GB 可用空间**。文档复杂度与浏览器能力可能带来更低的实际限制。[详情](PRESENTATIONS.md)。

## 准备条件

- **本地安装：** Windows 10/11 x64、与您的 Windows 版本兼容且使用 Linux 容器的 Docker Desktop、硬件虚拟化和 WSL2。若未安装 Docker Desktop，向导会提示安装；Windows 可能要求管理员权限和重新启动。
- **VPS：** Ubuntu 22.04/24.04 amd64、公网 IPv4、可使用 `root` 用户及密码或私钥通过 SSH 登录。向 VPS 安装时，Windows 上无需 Docker Desktop。
- 需要互联网以下载安装包和镜像。摄像头和麦克风需要受信任的 HTTPS 及浏览器权限；建议使用耳机通话。
- **首次测试的磁盘建议：** 至少 20 GB 可用空间，并为镜像、更新和备份留出余量。这是参考建议，并非实测的最小安装占用。

曾测试过一个使用 2 GB RAM、已配置 swap 并限制各服务内存的独立 VPS 配置。这不保证是标准安装或所有直播负载下的最低配置。caster 数量、观众数量和视频质量所需的资源应自行测试。向导使用预构建镜像，无需在 VPS 上构建应用。

Docker Desktop 有其自身的使用条款。VPS、域名及互联网连接的条款和费用由相应服务商规定。

## 在 Windows 上安装

以下步骤描述常规快速 HTTPS 场景。高级模式请先按 [INSTALL.md](INSTALL.md) 选择网络结构；证书和地址设置取决于所选结构。

1. 将**整个** `CastLink-Windows.zip` 解压到单独文件夹。运行 `EasySetup.exe`；`EasySetup.cmd` 也会打开图形向导。如需命令行对话界面，请使用 `EasySetup-Console.cmd`。
2. 在**在此计算机上**卡片中点击**在本机安装**，然后选择安装文件夹。默认为快速模式；如需高级设置，请在开始前明确启用。
3. 选择访问方式：同一网络中的设备使用 **LAN**；通过互联网连接使用**公网 IPv4**。请核对向导建议的地址。
4. 等待 Docker 准备完成。如果向导要求重启，请重启后再次打开向导：它会提示继续未完成的本地安装。请保留所选文件夹；无需删除此文件夹或 Docker 数据来继续安装。
5. 等待安装和 HTTPS 检查完成。本地服务器可通过向导中的按钮或桌面的 **CastLink** 快捷方式打开控制面板；服务启动后，点击**打开 CastLink（«Открыть CastLink»）**。
6. 对于本地安装，包括通过公网 IP 运行的 Windows 服务器，向导会提示信任该服务器的自签名证书。同一网络中的其他设备也需要安装该证书。向导会创建 `CastLink-Certificate` 工具包；对于另一台 Windows 电脑，请完整复制工具包并运行 `Install-Certificate.cmd`。只应信任您自己的服务器证书。导入后，请完全重启浏览器。

LAN 不需要公网 IP。要从互联网访问 Windows 服务器，需要公网地址、开放相应端口，并在必要时配置路由器端口转发：向导不会提供公网 IP，也不会配置您的路由器。

Windows 向导和管理窗口可选择 **Русский / English / 简体中文**。默认使用俄语；所选语言会为当前 Windows 用户账户保存。Windows 和 Docker 的详细技术消息保留原始语言。

本地安装成功后，桌面会出现 **CastLink** 快捷方式。打开快捷方式会启动该安装的控制面板和服务。控制面板显示 Docker、服务和网站状态；**打开 CastLink（«Открыть CastLink»）**按钮会在浏览器中打开网站。

**窗口关闭按钮和隐藏到托盘（«Скрыть в трей»）**会让服务器继续运行。**停止服务（«Остановить службы»）**按钮会停止该安装的服务，同时保持控制面板打开。**停止并退出（«Остановить и выйти»）**命令还会关闭控制面板。房间和设置会保留；Docker Desktop 和其他项目不会被关闭。控制面板不会添加到 Windows 开机启动项：请打开快捷方式启动服务器。电脑休眠或关机会使本地服务器无法访问。

## 通过 Windows 在 Linux VPS 上安装

以下步骤描述常规快速 HTTPS 场景。高级模式请先按 [INSTALL.md](INSTALL.md) 选择网络结构；证书和地址设置取决于所选结构。

1. 启动同一向导，在**在 Linux Ubuntu 上**卡片中点击**设置 Linux Ubuntu**。默认为快速模式；如需高级设置，请在开始前明确启用。
2. 输入 IP、SSH 端口和 `root` 用户名。选择密码登录，或指定私有 SSH 密钥文件（OpenSSH/PEM），必要时输入其口令。首次连接时，请将显示的**服务器密钥**指纹与服务商提供的信息核对。密码和口令仅用于当前连接。

   成功登录后，可创建新密钥：保存私钥文件，向导随后会把公钥添加到 VPS 并测试新的登录方式。仍然需要初始密码或有效密钥。服务器现有密钥会保留。请自行保管私钥文件：持有它即可访问 VPS。生成的文件不使用口令加密；向导会将文件访问权限限制为当前 Windows 用户。

3. 域名不是必需的。可使用公网 IPv4，或输入不带 `https://` 和路径的自有域名。使用域名前，请创建指向 VPS IP 的 A 记录；DNS 变更需在域名注册商面板中完成。
4. 使用域名进行全新安装时，可指定单独的 TURN 域名，例如 `relay.example.org`，其 A 记录指向同一 VPS。它用于通过 TCP/443 的备用媒体路径。留空会保留通常的 TURN/UDP。
5. 等待 Linux 安装包下载、依赖安装、服务启动和 HTTPS 检查完成。请保留向导工作文件夹，并保存显示的服务器安装路径。
6. 在浏览器中打开显示的地址。对于可访问的公网 IP 或域名，向导会配置公共 HTTPS 证书的获取和续期；客户端无需安装本地自签名证书。

签发公共证书需要外部能够访问服务器。选择公网模式无法解决 DNS 记录错误、端口关闭或地址位于 CGNAT 之后的问题。通过 IP 完成 VPS 安装后，可以再次针对同一服务器运行向导，稍后添加域名。

### 网络端口

标准安装需要在服务器防火墙和服务商面板中开放：

| 用途 | 端口 |
| --- | --- |
| HTTPS 和公共证书签发 | TCP 443；使用公共证书的 VPS 还需要 TCP 80 |
| 直接媒体连接 | TCP 7881、UDP 7882 |
| TURN/UDP | UDP 3478 和 UDP 30000–30031 |
| 可选 TURN/TLS | 同一服务器上的 TCP 443，需独立 TURN 域名 |

请保留 SSH 端口的访问权限。Windows LAN 需要相应的 Windows 防火墙规则；在路由器后方通过互联网连接时，还需端口转发。已安装的服务器可能配置了不同的媒体端口范围：请核对其配置及向导消息。

## 第一个房间与 caster

1. 在服务器主页选择**创建房间（«Создать комнату»）**。输入名称，并设置单独的**演播室密码**，长度至少八个字符。如有需要，可设置 caster 密码。
2. 在打开的演播室中选择摄像头、麦克风和监听设备。检查预览，然后启用 **ON AIR**，发送 Studio Return。
3. 在演播室控制面板中创建 caster 邀请，并私下发送给 caster。caster 密码和邀请不会授予演播室管理权限。
4. caster 在浏览器中打开链接，授权所需设备，并检查音视频。演播室再次登录时，使用**加入现有房间（«Войти в существующую»）**、房间名称和演播室密码。

请保存演播室密码。邀请和观看链接可访问您的房间或媒体流：请勿将其放入公开的错误报告中。

### vMix/OBS 的独立输出

在演播室中，复制目标 caster 卡片上的 URL，并在 vMix 中作为 Web Browser 添加，或在 OBS 中作为 Browser Source 添加。每个 caster URL 都提供单独、无界面叠加的摄像头画面和音频输出。屏幕共享使用单独的 **caster 屏幕（«Экран кастера»）**链接。请使用完整 URL，包括其中的秘密部分；无需根据 caster 名称猜测地址。

### 通过 `/watch` 观看演播室

演播室或房间管理员提供单独的 Studio Return 观看链接。同一链接可供多位观众同时打开；每位观众都会建立独立连接。观众只接收演播室视频和直播音频，不使用摄像头、麦克风，也没有控制权限或 caster 媒体流。浏览器可能要求点击**启用声音（«Включить звук»）**；观众开关声音和视频只影响自身。

为观众提供观看服务时，演播室向服务器发送一个额外媒体流，再由服务器分别传给每位观众。服务器出站流量随观众数量和码率增加。这里并不承诺无限连接数：容量取决于您的网络、服务器和视频质量。

## 通过 TURN 连接

通常请保留**自动（«Автоматически»）**：浏览器会选择可用路径，包括已配置的 TURN。如果首次媒体连接因符合条件的网络错误或超时而失败，CastLink 会强制使用 TURN 重试一次。这并不是每次丢包时都会持续触发的切换。

如果已连接的 caster 受到网络或 VPN 影响，演播室可以选择 **caster 音频和连接（«Звук и подключение кастеров»）→ caster 路径（«Маршрут кастера»）→ 备用 TURN（«Запасной TURN»）**。请等待应用成功的确认：只有选中的 caster 会重新连接。caster 无需单独输入 TURN 用户名和密码。

标准安装已启用 TURN/UDP。TCP/443 上的 TURN/TLS 对阻止 UDP 的网络有帮助；它需要独立域名和正确签发的证书。TURN 不保证能通过所有 VPN 或企业过滤器，也无法恢复已关闭的服务器。

## 额外服务器与备用切换

在**房间服务器（«Серверы комнаты»）**中，可在另一台 VPS 上安装 CastLink，或连接兼容的现有安装。直播前，请在 caster 设备上检查两个地址的 HTTPS 是否受信任且可访问。

- **计划迁移**由主演播室手动发起。如果目标服务器故障，正常的源服务器会继续工作。
- **应急备用服务器**需提前选择；当前 caster 组同时只能准备一台备用服务器。快照每 30 秒更新一次，有效期不超过五分钟。
- **自动应急迁移**默认关闭。启用时，需要主演播室已准备好的标签页保持打开，并获得备用服务器确认。标签页和备用服务器会独立确认源服务器持续故障；单个 caster 故障不会触发房间迁移。演播室标签页关闭或被浏览器暂停时，不会触发自动迁移。
- 已准备好且保持打开的 caster 和 `/watch` 标签页会跟随已确认的迁移。源服务器关闭后无法重新加载页面：故障期间请勿刷新其标签页。如果准备状态已过期，需要源服务器可访问才能更新。
- 切换可能中断音视频；浏览器可能要求重新授权设备、选择屏幕或启用声音。这不是无缝集群。返回已恢复的服务器始终需要手动操作。

只有备用服务器确认后，自动切换才算关闭完成。旧链接不会成为永久重定向：迁移后请给新的 caster 和观众提供目标服务器的链接。

### 演播室控制面板中的 SSH 密钥

连接备用服务器时，可选择使用密码或私有 SSH 密钥登录。在创建密钥区域中，先创建并下载私钥文件，再点击将已创建的密钥安装到 VPS（«Установить созданный ключ на VPS»）。这需要有效密码或已配置的密钥，并需另行验证服务器指纹。新登录方式测试成功后，选择下载的文件以安装或连接 CastLink。现有密钥和密码登录不会被删除。生成的私钥文件没有口令保护，请像服务器密码一样妥善保管。

## 更新与卸载

1. 更新前，请在云服务商网络防火墙和服务器系统防火墙中允许 **UDP 7882**。如果服务器位于路由器后，还需要转发此端口。保留 **TCP 80/443/7881**、**UDP 3478**，并允许 **UDP 30000–30031**。保持 SSH 端口可访问。可选 TURN/TLS 使用 **TCP 443** 和独立 TURN 域名。
2. 备份数据与配置。Windows 向导创建的安装应完整解压新的 Windows 安装包，运行 `EasySetup.exe`，选择**更新**及原本的本地目录或同一 VPS。独立 Linux 辅助程序创建的安装应从新解压的发行包使用原有 `--state-dir` 运行 `check-updates` 与 `update`：[步骤](LINUX_MANUAL.md)。`easy-setup-8b02e2d4dc3c` 旧版指南仍是独立流程，新辅助程序不会接管这种安装。
3. 请在非直播时段更新：安装程序会重新创建 LiveKit 容器以应用媒体端口，因此当前媒体连接会中断。更新现有安装会保留数据；无需删除安装或数据卷。
4. 更新后，请从实际使用的网络检查网站、新嘉宾连接、音视频、独立输出、`/watch` 和已配置的备用服务器，并在浏览器中打开更新后的界面。

新的 Easy Setup 端口配置为：直连媒体 **UDP 7882 / TCP 7881**，TURN **UDP 3478**，TURN relay **UDP 30000–30031**。它取代原来的媒体范围 **UDP 61000–61100** 和 relay 范围 **UDP 30000–30999**。外部防火墙和路由器转发需独立于 Docker 配置；仅下载新 ZIP 不会更新服务器。

**工作室中备用服务器面板的“更新”按钮仅更新 web 应用**，不会重新创建 LiveKit，也不会将现有安装迁移到新媒体端口。请使用新安装程序完成这次迁移。自定义安装请核对实际配置。

要卸载，请选择**卸载（«Удалить»）**，核对显示的服务器和路径，然后输入 **`DELETE`** 确认所选操作。对于 VPS，向导会在 SSH 连接后查找安装。

默认只删除所选安装的服务器容器，房间、设置和数据卷会保留。**连同房间和设置一起完全删除是单独选项，会造成数据丢失。** 已删除的数据只能从您自己的备份恢复。请保留工作文件夹和配置，以便使用保留的数据重新启动；删除下载的 ZIP 不等于卸载服务器。

## 如何协助测试

先创建一个小型测试房间：使用两个浏览器、麦克风/摄像头、vMix/OBS 中的 caster 输出和 `/watch`。然后测试其他设备和网络、重新连接、更新以及所选的备用服务器。不要在工作直播的唯一副本上测试卸载或服务器故障。

报告错误时，请注明：

- 界面或 `/api/version` 中显示的版本/构建标识、操作系统和浏览器。
- 服务器位置：本地或 VPS；连接类型，无需具体地址。
- 操作步骤、预期结果与实际结果，以及是否可复现。
- 已去除个人信息的错误文本或截图；媒体问题还需提供设备信息和其他网络中的测试结果。

一般错误可提交到[公开仓库的 Issues](https://github.com/resokol/castlink-releases/issues)，或通过 [Telegram](https://t.me/sklvmax) 联系作者。**请勿公开密码、令牌、cookies、邀请、个人 output/watch 链接、完整配置和日志、内部 IP 地址或 SSH 信息。** 发送截图前，请遮挡秘密字段，以及地址栏中的个人链接。发现安全漏洞时，请先通过 Telegram 私下联系作者，不要公开秘密信息和攻击方法。

向导面向 Windows 10/11；这不代表已测试每个操作系统版本、VPS、浏览器和实体设备。实际直播和长期负载需要您自行验证。作者联系方式： [Telegram](https://t.me/sklvmax) · [GitHub](https://github.com/resokol)。
