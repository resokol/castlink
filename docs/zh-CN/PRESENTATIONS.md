# PDF、PPTX 与演示控制

当前合并版本：[easy-setup-1472cd052d7e](https://github.com/resokol/castlink-releases/releases/tag/easy-setup-1472cd052d7e)，运行版本 `1.0.0-rc.3-1472cd052d7e`。请一起更新服务器与 Windows 客户端。

## 准备与共享

1. 打开演示面板并点击 **“选择 PDF / PPTX”**。PDF 最大 **100 MB**，PPTX 最大 **25 MB**。
2. PDF 在浏览器中打开。PPTX 发送到您的服务器，由隔离转换器转换为 PDF；此过程无需安装 PowerPoint。请等待预览。
3. 检查页数、字体和版式后点击 **“共享演示”**。文档作为独立的无声视频流共享。
4. 使用 **“上一页”** 和 **“下一页”**。在 **“远程控制”** 中明确将控制权授予指定参与者，并在需要时撤销或收回控制权。这仅控制页面，不授予电脑鼠标或键盘访问权限。
5. 完成后点击 **“停止演示”**。关闭菜单或面板不会停止正在进行的共享。停止失败时错误会保留显示，可再次尝试。

## 控制面板

可拖动面板标题移动面板。在支持的 Chrome/Edge 中，点击 **“置于其他窗口上方”** 可打开 Document Picture-in-Picture 窗口；API 不可用或被拒绝时仍在页面内控制。Windows 客户端在可用时使用原生面板。打开幻灯片菜单时仍可使用 STOP。

## 兼容性与限制

- PDF/PPTX 以静态页面显示。本模式不播放 PPTX 动画、视频、音乐或交互元素。
- 常规 PPTX 可包含普通 SVG、图表、内嵌图表数据和链接。不保证每份文档都与 PowerPoint 完全一致。
- 缺少原始字体可能改变换行和版式。需要固定外观时，请在原始电脑上导出 PDF；只有许可证允许时才可嵌入字体。
- 不接受加密或密码保护的文档。请保存无密码副本或导出 PDF。
- 损坏、密码保护、转换器忙碌或不可用会显示不同错误。忙碌时稍后重试；不可用时联系服务器所有者。PDF 不需要转换器。

如需显示 PowerPoint 动画或视频，请在 PowerPoint 中启动放映，再单独使用 **“屏幕共享”**，在来源选择器中选择其窗口并按需启用声音。连接已打开的 PowerPoint 控制属于另一个 Windows 流程，需要已安装 PowerPoint；其行为取决于工作环境，直播前应自行检查。
