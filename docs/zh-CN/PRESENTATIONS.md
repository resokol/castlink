# 演示文稿功能暂时不可用

演示文稿控制已暂时关闭。无法在 CastLink 中打开本地 PDF、转交翻页控制、连接 PowerPoint 或下载辅助程序。此前的辅助程序启动说明不再适用；目前不宣称支持 PowerPoint。

如需展示文档或应用窗口，可使用常规的**“屏幕共享”**，并在浏览器中选择来源。这不会开启远程幻灯片控制。
