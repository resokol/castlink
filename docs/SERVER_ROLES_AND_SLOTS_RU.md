# Серверные роли и постоянные выходы кастеров

[English](en/SERVER_ROLES_AND_SLOTS.md) · [简体中文](zh-CN/SERVER_ROLES_AND_SLOTS.md)

Кастер входит в комнату сразу по обычной гостевой или персональной ссылке с прежней проверкой доступа. Подтверждение модератора и назначение слота для входа не требуются.

Камера и микрофон гостя автоматически включаются уже на экране проверки перед входом в комнату, если их использование разрешено. Предпросмотр и индикатор микрофона работают локально, без автоматического входа. Явно отключённые устройства не включаются. При отказе разрешений показана ошибка и доступна повторная проверка; отсутствие одного устройства не блокирует другое. При выходе с проверки временный захват освобождается.

Выдача администратора и модератора восстановлена в прежнем виде: студия → «Настройки комнаты» → «Создать ссылку администратора» / «Создать ссылку модератора». Используется обычный вход в студию своей комнаты. Отдельного входа владельца сервера, отдельного пароля и блока «Доступ к серверу» больше нет. Ссылки и отзыв доступа работают по прежним комнатным правилам; администратор комнаты может выдавать комнатных модераторов.

Студия, администратор и модератор могут создать слот, изменить его имя и инвайт, назначить уже подключённого кастера, освободить или удалить слот. У слота три постоянные ссылки: вход кастера, камера с микрофоном для OBS/vMix, экран со звуком экрана для OBS/vMix. Скопируйте два выхода в режиссёрское ПО один раз.

Назначение меняет только источник выходов. Замена, перенос в другой слот и освобождение сохраняют подключения кастеров и их публикации в комнате. Свободный выход не показывает чужое видео. Переподключение той же подтверждённой сессии восстанавливает выход; новый вход с новой identity назначают отдельно. «Отключить гостя» остаётся отдельной командой и действительно отключает участника, освобождая его слот.

Имя, привязка инвайта и назначение сохраняют URL выходов. Только явное «Перевыпустить ссылку камеры/экрана» меняет соответствующий URL. Перевыпуск инвайта меняет только последующие входы. Удаление слота отзывает его ссылки; создание слота с тем же именем выдаёт новые URL. Смена пароля комнаты или удаление комнаты сохраняет прежние правила отзыва доступа.

Кнопка эфира показывает подтверждённое состояние ON AIR / OFF AIR. Camera/microphone и screen/screen audio маршрутизируются раздельно. Выходы используют прежнюю подписку на медиакомнату без публикации и управления; выбор источника не является границей конфиденциальности внутри комнаты.

Миграции 005/006 нужны при первой установке серверных ролей и слотов. Коррекция прямого входа новых миграций не добавляет. До обновления сохраните БД и web-data. Установленную версию проверяйте через /api/version; описание кода само по себе не подтверждает обновление сервера.
