# Мобильная панель кастера без прокрутки — 08.11.2026

Владелец отклонил горизонтальную прокрутку и уточнил: реакции, демонстрация,
системные настройки и чат должны оставаться прямо в основном ряду; чат без подписи.
Использован Impeccable/Adapt: существующий graphite/mint, светлое оформление,
приоритет прямых действий, подписи только у второстепенных операций.

Основной ряд: микрофон, камера, чат, реакции, демонстрация, настройки, «Ещё», выход.
«Ещё» содержит только загрузку и фон/размытие камеры двумя подписанными строками.
Ряд не прокручивается и не переносится. Равные кнопки44px высотой; ширина гибкая:
44px на393px телефоне,40px на360px,35px на320px. Восемь44px кнопок физически
не помещаются на320px с отступами; доступ к указанным владельцем действиям имеет
приоритет. Иконки20–22px, клавиатурные имена и состояния mute/busy/disabled сохранены.

Слоты React переносят только триггеры загрузки и параметров камеры. Файловый input,
подготовленный viewer, camera-effects controller, активные owner/recipient controls
и независимые Stop поверхности находятся вне закрываемого «Ещё». Resize не меняет
видео/публикации. На desktop сохраняются прямые действия и стрелка параметров камеры.

Рассмотрено: прежняя прокрутка (отклонена), перенос большинства действий в «Ещё»
(уточнениями владельца исключены реакции/демонстрация/настройки/чат), окончательный
плотный ряд с двумя второстепенными действиями в меню. Реализация root/Codex и
GPT-6.1 Sol high mobile_ui; независимое ревью GPT-6.1 Sol high final_review.

Проверки до поставки: Chromium264 assertions/8 сценариев320/393/873-landscape/1440
в обоих оформлениях PASS. Проверены8 прямых кнопок, отсутствие прокрутки, меню
из2 действий, Escape/outside/focus, вложенные меню, сохранность9 video nodes/треков
при resize и смене режима, подготовленный file input/viewer вне «Ещё», настоящий
клик Stop с подтверждением остановки тестового трека. Скриншоты:
/workspace/caster-more-final/, results.json там же. Это продуктовые компоненты
