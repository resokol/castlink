# Easy Setup: необязательный TURN/TLS в мастере — 12.10.2026

Для новой установки внешнего HTTPS-сервера с доменом мастер предлагает отдельный домен TURN/TLS. Enter сохраняет обычный TURN/UDP; для IP-адреса сайта вопрос не появляется. Параметр CLI `-TurnDomain` позволяет явно задать выбор. Имя приводится к нижнему регистру, проверяется как отдельный от сайта домен; его A-запись должна указывать на выбранный IPv4 VPS. Явный неверный DNS останавливает мастер без цикла ожидания и до изменения текущей конфигурации.

У существующей установки новый вопрос отсутствует. Сохранённый `turnDomain` сохраняется, а старый сервер без него остаётся в режиме UDP. Загруженный текущий выпуск получает явный `TurnDomain`, включая пустую строку, поэтому вопрос не повторяется при передаче управления. Мастер проверяет наличие закреплённых ссылки и image identity `turntls` до обращения к конфигурации; запрос TLS с прежним пакетом из четырёх образов отклоняется. Пустой выбор сохраняет совместимость с четырьмя образами. Одновременное изменение домена сайта и добавление TURN/TLS требует двух отдельных шагов; локальный IP-сценарий TURN/TLS не предлагает.


Пароль SSH не входит в новый параметр и не сохраняется им. Доверие TLS, публичная доступность TCP/443 и работа медиа требуют отдельных сетевых проверок. Регрессионные сценарии мастера: `scripts/tests/simple-easy-setup-turn-domain.fixtures.ps1`.
