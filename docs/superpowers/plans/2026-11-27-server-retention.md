# Автоматическое обслуживание всех серверных установок CastLink

Поручение владельца 27.11.2026: очистка должна входить в пакеты установщиков
Windows и Linux и работать автоматически после установки/обновления.
Номера продукта (`1.0.11`, `1.0.10`, `1.0.9`) определяют сохраняемые версии;
хэши используются только для точной проверки принадлежности объектов.

## Согласованная политика

- Текущая версия и две предыдущие версии продукта. Повторная сборка той же
  версии не занимает отдельное место; сохранять последний успешный комплект.
- Установка регистрирует обслуживание, обновление обновляет его, удаление
  снимает задание. Windows/WSL: задание Windows обслуживает принадлежащие
  установщику файлы хоста. Linux/Compose и Legacy используют штатный scheduler.
- Аккаунты, данные комнат, настройки, сертификаты, Docker volumes и службы
  других установок сохраняются. Непроверенные истории и незавершённые операции
  сохраняются; отсутствие доказательств не означает разрешение на удаление.
- История обновляется только после успешной проверки нового сервера.
  При ошибке текущий сервер продолжает работать, обслуживание повторяет попытку.
- Для существующих внешних установок новая система приходит с новым пакетом:
  публикация исходников сама не меняет уже установленное ПО.

## Совместимость старых инструментов

Исторический общий Windows lifecycle-packages не удаляется автоматически:
выпущенные ранее инструменты не участвуют в новой координации. Новые загрузки
нативной панели размещаются в отдельном управляемом каталоге каждой установки.
Использование и удаление этих файлов защищены общим lease. Вручную выбранные
пакеты и независимый кэш постоянного обновлятора не присваиваются этой очистке.
Переход через старую панель должен включать обслуживание целевого пакета;
при откате незавершённого перехода его временное задание снимается.

## Проверки интеграции

Проверить numeric versions 1.0.9/1.0.10/1.0.11, повторный rebuild одной версии,
prerelease, неизвестную историю, failed update, повторный запуск, чужие файлы,
изменённые байты, pending journals, включение helper в package manifest,
повторную регистрацию и удаление задания вместе с установкой.
