# История показателей и журнал за 24 часа

Пользователь явно выбрал оба вида: история графиков и события/ошибки сервера.
Развиваем имеющийся мониторинг в той же рабочей ветке; production/публичные релизы
и пользовательский Windows не меняем.

Измерения выполняются раз в15секунд независимо от открытого браузера. Срок
хранения — последние24часа, включая восстановление после перезапуска. Используем
встроенный SQLite закреплённого Node22.23.3 без новой внешней службы/зависимости.
Приватная БД находится в каталоге данных сервера. Ограничены размер файла, WAL,
число записей событий и очередь записи. Старые записи автоматически удаляются.
При переполнении/недоступности запись деградирует явно; основной сервер не падает.

Существующий serverLog продолжает консольный вывод и сохраняет только очищенные
структурированные события. Токены, пароли, cookies, тела запросов и произвольные
секретные URL не сохраняются. Фоновая запись пакетами имеет ограниченную очередь;
потери из-за лимитов сообщаются владельцу, без рекурсивного логирования ошибок БД.

API и панели доступны только существующей платформенной сессии Super Admin.
История: 1ч/6ч/24ч; ответ не более720точек, длинные периоды показывают пики по
временным корзинам с явной подписью, значения RAM/диска остаются согласованными.
Текущие подписи берутся из последнего необработанного замера. Пропуски и устаревание
сохраняются. Таблица не создаёт тысячи DOM-строк при каждом обновлении.
Журнал: фильтр all/info/warn/error и страницы по50записей, свежие сначала.

Браузерный polling не запускает сбор и приостанавливается в скрытой вкладке.
Фоновый sampler запускается однократно через существующий instrumentation hook,
без перекрывающихся запросов и без фоновых задач на этапе сборки.

Проверки: настоящие SQLite-файлы (сутки, restart, права, лимиты, повреждения),
очередь и фоновый цикл, права обоих API, пики/разрывы/периоды, SSR и браузерная
проверка desktop/mobile, TypeScript и production build. Оценку нагрузки уточняем
замерами объёма5760образцов и времени чтения/записи без обещания нулевой нагрузки.
