# Диагностика видео из студии

Пользователь выбрал встроенный JSON-экспорт вместо инструкции по ручному дампу Chrome.
В статистике рядом с историей аудио появляется «Диагностика видео → JSON».
Файл содержит каждый сохранённый видеозамер выбранной комнаты, периода,
участника/роли/сессии, с UTC-временем клиента и сервера. По умолчанию доступны
исходящий поток студии и входящие потоки кастеров; фильтры сохраняются.

Расширить существующий двухсекундный сбор getStats накопительными счётчиками
захвата, отправленных/кодированных, полученных/декодированных/пропущенных кадров,
зависаний и их общей длительности, encode/decode time, jitter buffer и NACK/PLI/FIR.
Сохранять ID публикации и состояние видеотрека для сопоставления замен источника.
Нет нового таймера, дополнительного чтения getStats или управления медиатреком.
Неподдерживаемые метрики — null; старые записи остаются без новых полей.

Варианты: внутренний дамп Chrome недоступен веб-странице; кнопка инструкции
оставляет ручной сбор на каждом компьютере. Выбран собственный экспорт: сервер
уже хранит базовые видеометрики участников и умеет выдавать точную историю аудио.
Добавить режим video к этому пагинируемому чтению, включая node-history relay.
История runtime по-прежнему отдельна.

Экспорт: фиксированное окно across pages, максимум 50 000 замеров/20 MiB UTF-8/
100 страниц, partial=true и -partial в имени при ограничении. Частичный результат
явно обозначен. Авторизация владельца/администратора комнаты сохраняется.
Лимит отправки телеметрии остаётся 100 000 байт UTF-8. При переполнении
дополнительные video-счётчики удаляются с конца списка до достижения лимита;
базовые видео/аудио/runtime сохраняются. videoDiagnosticsLimited=true явно
отмечает это в сохранённом замере и видеоэкспорте.
Только разрешённые поля, без SDP, IP-адресов, device IDs, токенов и медиазаписей.
Честное пояснение в интерфейсе: это собственный диагностический журнал, новые
счётчики появляются после обновления клиентов, отсутствующие данные не нули.

Проверка: RED→GREEN для сбора/санитизации, API/архива/изоляции, экспорта/кнопки;
регрессии аудио/runtime/relay, TypeScript и доступный штатный CI.
Публикация и обновление работающего сервера — отдельный этап, не часть изменения.
