# Дополнительные серверы и ручной перенос комнаты

Функция относится к self-hosted CastLink. Для комнаты можно подключить несколько серверов. Перенос запускает основная студия; потеря связи сама по себе не переносит участников.

## Подключение сервера

В конце EasySetup либо в студии, в разделе «Серверы комнаты», доступны два способа:

- **Установить CastLink на пустой VPS** — мастер скачивает совместимый текущий Linux выпуск из `resokol/castlink-releases`, проверяет SHA256, готовит Docker и разворачивает сервер.
- **Подключить установленный CastLink** — мастер обнаруживает существующую совместимую установку EasySetup. Её комнаты и службы сохраняются. Если установок несколько, нужен UUID выбранной установки.

Для первого выпуска поддерживаются Ubuntu 22.04/24.04 x86_64, публичный IPv4, SSH root и пароль. Сначала мастер показывает ключ SSH сервера: сверьте его с данными VPS и подтвердите доверие. Пароль используется только для текущей операции и не сохраняется. Веб-интерфейс не разрешает произвольный доступ к внутренней сети сервера; внутренние адреса требуют настройки владельцем установки.

Подключения из установщика доступны комнатам этой установки. Подключения из студии принадлежат только её комнате. Создатель комнаты не получает права управления другими комнатами или сервером-источником. Устаревшую установку без поддержки подключения резервов нужно обновить.

HTTPS каждого сервера должен быть доверенным на устройствах участников. При собственном сертификате доверие к первому серверу не означает доверия ко второму. Прямое соединение браузера с резервом проверяется до аварии; недоверенный сертификат или недоступный адрес не должны отображаться как готовый резерв.

## Плановый перенос

В разделе «Перенос комнаты» выберите доступный целевой сервер и нажмите «Перенести». Сначала цель проверяет LiveKit и возможность принять комнату. Занятая другой сессией комната не заменяется. При отказе цели текущая комната продолжает работать.

Переносятся подключённые участники текущей сессии: основная и дополнительные студии, гости и персонал комнаты. Их роли и сроки прав сохраняются. Новые посетители старой ссылки не перенаправляются автоматически.

## Аварийный резерв

Заранее выберите один сервер в разделе «Аварийный резерв». Для текущей группы участников одновременно подготовлен только один аварийный резерв. Остальные серверы остаются в списке доступных подключений. Смена аварийного резерва требует подтверждения прежнего сервера; при недоступности прежнего одновременно активные полномочия на другой сервер не выдаются.

Открытые вкладки получают собственные короткоживущие полномочия перехода и проверяют резерв напрямую. Снимок обновляется каждые 30 секунд; готовность действует не более пяти минут и не дольше исходных прав участника. Состояние и возраст снимка показываются в студии.

При отказе основного HTTPS-сервера и LiveKit основная студия нажимает «Перенести на аварийный резерв» в уже открытой вкладке. Подготовленные вкладки участников увидят подтверждённую операцию на резерве и перейдут туда. Без нажатия студии перехода нет.

Не перезагружайте вкладку основного сервера во время аварии: выключенный сервер не может выдать страницу заново. Для нового входа используйте адрес резерва. Если готовность истекла до запуска переноса, потребуется доступный основной сервер для повторной подготовки.

## Переподключение медиа

Во время перехода возможен перерыв звука и видео. Браузер может повторно запросить разрешения камеры, микрофона или выбор аудиовыхода на новом адресе. При невозможности однозначно восстановить выбранное устройство участник подтверждает его вручную. Для показа экрана требуется новый выбор окна или экрана.

При разделении сети некоторое время могут работать старые и новые медиасессии. Данная функция не является автоматическим кластером с гарантией единственного активного медиасервера. Недоступный резерв не останавливает исправный основной сервер. Отзыв прав на источнике во время разрыва связи не может мгновенно изменить уже выданные резерву полномочия; их срок ограничен готовностью снимка.
