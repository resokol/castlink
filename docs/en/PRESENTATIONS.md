# Presentations are temporarily unavailable

Presentation control is temporarily disabled. Opening a local PDF in CastLink, delegating page navigation, connecting PowerPoint, and downloading helpers are unavailable. The previous helper launch instructions do not apply; PowerPoint support is not claimed.

To show a document or application window, use normal **Screen sharing** and select the source in the browser. This does not enable remote slide control.
