# Студия CastLink: вход, серверы и исходящий поток

После ввода пароля студии выберите сервер. Текущий сайт, настроенные серверы переноса и сохранённые адреса доступны в списке. Новый сервер добавляется по имени и HTTPS-адресу, например `https://studio.example.ru` или `https://studio.example.ru:8443`.

Список ручных адресов хранится только в браузере на этом сайте. Пароли в нём не сохраняются. При переходе на другой сервер авторизация выполняется на его странице: пароль текущей студии туда не пересылается. На выбранном сервере можно войти в существующую комнату или создать новую с необязательным паролем для гостей.

Добавление адреса и перенос комнаты — разные действия. Адрес позволяет открыть другую студию. Кнопка «Перенести комнату» переводит текущую студию и гостей между заранее настроенными доверенными серверами. Настройка пары описана в [инструкции переноса](SERVER_FAILOVER_RU.md). Одних открытых портов недостаточно: нужны HTTPS, работающий CastLink, LiveKit и его доступность с устройств участников.

Монитор Studio Return и исходящая статистика находятся вверху студии. Кнопка «☰ Комната» в заголовке раскрывает выбор, создание и изменение комнаты. Выбор устройств и управление Studio Return находятся в компактной панели под монитором. Сворачивание меню комнаты не меняет устройства и не прерывает эфир.

Рядом со Studio Return отображается состояние эфира. Красная кнопка при активном эфире останавливает публикацию. Проверка Studio Return сама по себе эфир не запускает.

В блоке «Исходящий поток студии» находятся фактические показатели, график видеобитрейта, выбор FPS и лимита битрейта, а блок переноса комнаты находится внизу страницы. График обновляется по измерениям WebRTC каждые две секунды; выбранный лимит и фактическая скорость могут отличаться. История графика хранится только в памяти страницы и не заполняет диск.

Карточки гостей содержат видео, аудиоиндикатор и действия «Открыть» / «Копировать URL» для отдельного выхода. Эти ссылки могут содержать пропуск для просмотра комнаты; отправляйте их только тем, кому нужен доступ.

Если интерфейс старый, нажмите «Проверить обновления» или перезагрузите страницу. Версию можно проверить в консоли:

```bash
curl -fsS https://castlink.ru/api/version
```

После установки этого обновления ожидается `{"version":"0.9.23-panel-fixes"}`. Ошибка `curl` означает, что нужно проверить доступность сайта, DNS и HTTPS; успешный ответ с другой версией означает, что на этом адресе запущена другая сборка.


## Основная студия и модераторы

Первая панель в комнате становится основной студией и публикует Studio Return. Следующие панели с общим паролем подключаются дополнительными администраторами: они видят эфир основной студии и могут отправлять ей команды FPS, битрейта, усиления микрофона, проверки предпросмотра и ON AIR/OFF AIR. Выбор физических камер и микрофонов остаётся на компьютере основной студии. Перенос всей комнаты запускается с основной панели.

Основная панель имеет постоянную идентичность `studio-panel-main` внутри комнаты. Повторное соединение заменяет её старое соединение, а не создаёт нового участника. Роль подтверждается сервером. При потере основной панели другая может принять управление после окончания срока её активности (около 45 секунд). Новая основная панель начинает с выключенной публикацией: нужно проверить её устройства.

FPS и битрейт доступны во время ON AIR. Изменение применяется к существующему захвату и отправителю WebRTC без перепубликации трека. Если источник или браузер отклоняет настройку, интерфейс сообщает ошибку. Фактическая частота кадров может быть ниже выбранного предела. Шкала графика: 500, 1000, далее 2000–12000 кбит/с с шагом 1000.

## Гостевой вход и телефон

На экране входа гостя раскройте «Сервер подключения», чтобы открыть VPS, локальный или сохранённый сервер. Адреса сохраняются в этом браузере; пароль и приглашение текущей комнаты на другой сервер не отправляются.

Перед входом в конференцию можно выбрать «Войти без камеры» и/или «Войти без микрофона», затем нажать «Войти в конференцию». Для выключенных устройств разрешение на захват не запрашивается. Вход без обоих устройств позволяет смотреть и слушать эфир. Внутри комнаты устройства можно включить стандартными кнопками камеры и микрофона.

Если участники не помещаются в видеосетку, перелистывайте её горизонтальным свайпом либо кнопками страниц. Список имён прокручивается вертикально, таблица студии — горизонтально, когда ширины экрана недостаточно.

## Локальная сеть и внешний адрес

Если `https://79-120-36-254.sslip.io` открывается из интернета, но не из домашней сети, проверьте NAT loopback роутера или локальную DNS-запись этого домена на `192.168.53.68`. Это сохраняет HTTPS с правильным именем сертификата. Диагностика с компьютера в локальной сети:

```bash
curl -fsS --resolve 79-120-36-254.sslip.io:443:192.168.53.68 https://79-120-36-254.sslip.io/api/version
```

Успешный JSON с версией при ошибке обычного запроса к тому же домену указывает на проблему маршрута или DNS, а не на остановленное приложение. Эта команда не меняет настройки DNS компьютера или роутера.


Статистика основной студии обновляет токен с clientId и epoch действующего сеанса ведущего. При смене роли или сеанса старые запросы отменяются. Администраторы могут читать статистику своей комнаты и выгружать CSV; ограниченным модераторам статистика недоступна. Сброс списка отключившихся доступен только основной студии.


Модератор может отдельно включать прослушивание опубликованного Studio Return и менять личную громкость. Это воспроизведение полученного аудиотрека в его браузере, не изменение Gain или ON AIR основной студии. Для проверки используйте наушники; без опубликованного аудиотрека слышать нечего.


Исходящая статистика и график у администратора берутся из измерений основной студии, а не из исходящих треков администратора. Основная панель должна быть обновлена, чтобы отправлять эти измерения. Настроенный лимит битрейта и измеренный битрейт — разные величины. При отсутствии свежих данных отображается состояние ожидания.


Отдельному администратору можно выдать ссылку через «☰ Комната». Он управляет эфиром, комнатой и гостями без общего пароля студии и без захвата роли вещателя. Порядок выдачи, срок действия и отзыв описаны в [инструкции отдельной админки](ROOM_ADMIN_RU.md).


Временные ошибки опроса управления и продления сеанса показываются отдельно от ошибок применения настроек. Пустой или повреждённый ответ сервера выводится как понятное сообщение с HTTP-статусом. После успешного ответа соответствующая ошибка связи снимается автоматически и не пересылается модераторам как ошибка эфира.

Общий видеобитрейт Studio Return и `/watch`: 500, 1000, далее до 12000 кбит/с с шагом 1000. Для новых настроек выбран 12000. Сохранённые значения автоматически не повышаются; при необходимости выберите 12000 вручную. Основная студия и администратор меняют один общий предел, который применяется отдельно к каждому из двух исходящих потоков. Страница `/watch` позволяет зрителю независимо выключать звук и видео, не влияя на эфир и остальных зрителей.
