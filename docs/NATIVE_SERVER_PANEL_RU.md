# Статистика в окне Windows Server

Статус: исходники нового WSL-пакета. Выпуск и проверка настоящего автозапуска на
локальном ПК ещё не завершены. Опубликованные пакеты и неизменённый RC8 draft
этим документом не объявляются обновлёнными.

После успешной интерактивной установки нового пакета открывается штатное окно
управления CastLink: запуск, остановка, открытие сервера и скрытие в трей.
Компактная статистика находится в этом же окне. Отдельного веб-экрана статистики
Super Admin нет. Прежние одноразовые ссылки владельца продолжают работать через
небольшой экран принятия доступа с переходом к управлению серверами.

Окно показывает настроенные и активные комнаты, подключения и кастеров,
процессор, память, диск данных, входящий/исходящий трафик, время работы и память
процесса web. Ресурсы относятся к среде WSL сервера; это не монитор всех процессов
Windows. Неизвестное значение показывается прочерком, ноль означает настоящий
замер. При остановке или потере доступа данные помечаются устаревшими.

Показатели опрашиваются асинхронно раз в10секунд. Небольшие графики используют
суточную историю с сервера, до720точек; при агрегации сервер возвращает максимум
интервала. Пробелы в истории не соединяются выдуманными измерениями.

Кнопка «Экспорт ZIP за24часа» предлагает сохранить новый архив:

- `metrics.csv` — суточные показатели с московским временем;
- `events.jsonl` — журнал событий/ошибок CastLink с разрешёнными числовыми полями;
- `summary.json` — окно времени, агрегация, разрешение и состояние хранилища,
  а также признак неполной выгрузки при достижении ограничения.

Выгрузка не является копией системного journalctl, базы данных или секретов.
События недоступности служб входят в журнал CastLink. Если доступа или истории
нет, окно сообщает об этом; успешный пустой архив вместо ошибки не создаётся.
Start/Stop, текущий опрос и экспорт выполняются по очереди, интерфейс не ждёт
операцию в основном потоке; Stop имеет приоритет перед ожидающим экспортом.

Закрытие окна крестиком и «Скрыть» оставляют сервер работать в трее. Повторный
запуск приложения возвращает существующее окно. Явные «Остановить» и
«Остановить и выйти» останавливают только привязанную установку. При неудачной
остановке окно остаётся доступным и не утверждает, что службы остановлены.

Автозапуск при входе в Windows предлагается штатным установщиком. Для новых
установок задача запускает нативное приложение, которое вызывает тот же
закреплённый установщик для управления службами. Прежние задачи не преобразуются
автоматически. Если панель не подготовилась, сервер сохраняет рабочие службы,
установщик сообщает об ошибке; новая консольная задача вместо панели не создаётся.

Доступ к показателям выдаётся только владельцу локальной установки через
существующий защищённый API. Приглашения не открываются в браузере и не выводятся
в лог. Локальная сессия панели защищена DPAPI текущего пользователя Windows.
Проверка сертификата HTTPS и прав гостя/комнаты/студии не обходится.
