# Документация CastLink

Актуальность: 25 октября 2026 года. Этот указатель разделяет инструкции для
пользователей, сопровождение проекта и исторические материалы. Точные версии
готовых пакетов и ссылки на контрольные суммы находятся в
[каталоге продуктов](../distribution/PRODUCTS.md).

Онлайн-инструкции для пользователей публикуются в
[castlink-releases](https://github.com/resokol/castlink-releases): русский — в
корне, английский — в `docs/en`, китайский — в `docs/zh-CN`. Они могут уточняться
после выпуска. Документы внутри скачанного архива остаются снимком на дату его
сборки; опубликованные архивы и контрольные суммы не заменяются под тем же тегом.

попадают готовые пакеты, пользовательские инструкции и обязательные материалы
сторонних компонентов. Учётные данные, локальные конфигурации, технические отчёты
и исходники приложения туда не переносятся.
