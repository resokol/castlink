# CastLink Client для Windows

Тестовый настольный клиент для кастера и персонала. Открывает существующий HTTPS-сервер CastLink; не устанавливает сервер и не требует Docker у кастера. Windows 10/11 x64 — целевая платформа; фактически проверенные ОС и устройства перечисляются отдельно в `docs/testing/WINDOWS_DESKTOP_CLIENT_RU.md`.

## Разработка

Node.js 22.12+ (для текущих проверок используется Node.js 24), pnpm 9.15.0.

```sh
pnpm install --frozen-lockfile
pnpm desktop:test
pnpm desktop:dev
```

Выберите «Студия» или «Кастер». Кастер вставляет полную ссылку приглашения/постоянную ссылку либо адрес HTTPS-сервера: для одного адреса открывается вход в комнату по названию и гостевому паролю. Полные ссылки сохраняют свой маршрут и параметры. Студия открывает сервер как прежде.

Вставьте адрес HTTPS-сервера или полную ссылку приглашения. В настройках клиента сохраняется только origin, не секрет приглашения. При повторном входе используйте сохранённую сервером сессию или вставьте приглашение снова. HTTP loopback разрешён только в разработке; недоверенные сертификаты не обходятся.

Резервные серверы укажите заранее, по одному origin на строку. Неизвестные origins не получают native-мост или media-разрешения. Для смены сервера используйте меню CastLink → Сменить сервер. При закрытии рабочего окна запрашивается подтверждение; сворачивание сохраняет соединение. Автозапуска при входе в Windows нет.

При подключении клиент спрашивает разрешение камеры и микрофона. После согласия названия входов и выходов доступны сразу; запрос разрешения сам по себе не запускает захват. При отказе подключение продолжается, а доступ можно разрешить позже через запрос на странице. Согласие хранится только до закрытия/смены сервера; переходы внутри того же origin его сохраняют, другой origin требует нового согласия. Автокопирование ссылок разрешено доверенной основной странице; чтение буфера обмена запрещено. Экран/окно выбираются в отдельном picker. Системный звук в этой тестовой версии отключён: исключение приватного аудио из Windows loopback ещё не доказано.

Нативная STOP-панель и `Ctrl+Alt+Shift+S` требуют web-версии сервера с `desktop-stop-panel` adapter из этой ветки. Старый сервер продолжает использовать свою браузерную панель. Закрытие STOP-панели скрывает её; показ останавливается кнопкой или горячей клавишей. Конфликт горячей клавиши отображается в панели. PDF/PowerPoint в текущем серверном коде отключены и этим клиентом не включаются.

## Сборка кандидата

На Windows, из чистого закоммиченного private checkout:

```sh
pnpm desktop:package
```

Результат — `artifacts/desktop/<commit>/`: portable ZIP, NSIS installer, manifest и SHA256SUMS. Версия берётся из корневого package.json. Пакеты имеют отдельные имена `CastLink-Client-*`, чтобы отличаться от EasySetup. Автообновления и цифровая подпись не настроены; не менять клиент во время эфира. Скрипт не публикует release и не обновляет production.
